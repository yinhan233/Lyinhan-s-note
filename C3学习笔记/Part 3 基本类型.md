## 整数
C3 提供了有符号和无符号的整数类型。与 C 语言不同，C3 的基础整数类型具有严格定义的位宽（比如明确的 8 位、16 位、32 位等）。此外，还有与指针大小相关的 `iptr`/`uptr`，以及与内存大小相关的 `sz`/`usz`。  
**整数类型对照表：**

| 类型      | 有符号? | 最小值     | 最大值       | 位数        |
| ------- | ---- | ------- | --------- | --------- |
| ichar   | 是    | -128    | 127       | 8         |
| short   | 是    | -32768  | 32767     | 16        |
| int     | 是    | -2^31   | 2^31 - 1  | 32        |
| long    | 是    | -2^63   | 2^63 - 1  | 64        |
| int128  | 是    | -2^127  | 2^127 - 1 | 128       |
| iptr    | 是    | (随系统变化) | (随系统变化)   | (与指针一致)   |
| sz      | 是    | (随系统变化) | (随系统变化)   | (与指针差值一致) |
| char    | 否    | 0       | 255       | 8         |
| ushort  | 否    | 0       | 65535     | 16        |
| uint    | 否    | 0       | 2^32 - 1  | 32        |
| ulong   | 否    | 0       | 2^64 - 1  | 64        |
| uint128 | 否    | 0       | 2^128 - 1 | 128       |
| uptr    | 否    | 0       | (随系统变化)   | (与指针一致)   |
| usz     | 否    | 0       | (随系统变化)   | (与指针差值一致) |
> 在 64 位机器上，`iptr`/`uptr` 和 `sz`/`usz` 通常是 64 位的；在 32 位机器上则是 32 位的。
## 数字的书写
可以使用十进制、十六进制 (`0x`)、八进制 (`0o`) 和二进制 (`0b`) 来书写数字，并且可以用下划线 `_` 分隔数字以提高可读性（如 `1_000_000`）。如果没有显式指定类型，十进制数字默认是 `int`，其他进制默认是无符号类型。你也可以用后缀强制指定类型，大小写均可：
- `l` 或 `L` → long
- `ll` 或 `LL` → int128
- `u` 或 `U` → uint
- `ul` 或 `UL` → ulong
- `ull` 或 `ULL` → uint128
## 布尔值与字符
**布尔值 (`bool`)**：只有 `true` 和 `false`。虽然只占用 1 bit 的信息，但在内存中实际占用 1 个字节（byte）。
## 浮点数
C3 拥有标准的 `float`（32 位）和 `double`（64 位）。浮点数字面量默认是 64 位的。你可以使用科学计数法（十进制用 `e`，十六进制用 `p`）。  
例如：`-2.22e-21` 或 `-0x21.93p-10`。后缀 `f` 代表 float，`d` 代表 double。
## 数组、切片与向量
### 数组
格式为 `Type[size]`。数组是同一类型数据的连续内存组合。可以用 `Type[*]` 让编译器自动推断长度。
```c
int[3] abc = { 1, 2, 3 }; // 显式长度
int[*] bcd = { 1, 2, 3 }; // 隐式推断长度为 3
```
### 切片
格式为 `Type[]`。切片本身不存储数据，它是底层数组或向量的"视图"。切片包含两个属性：`.ptr`（指向数据的指针）和 `.len`（数据长度）。因为带有长度信息，在安全模式下切片会自动进行边界检查，这比 C 语言中单独传递"指针+长度"要安全得多。
```c
int[3] abc = { 1, 2, 3 };
int[] slice = &abc; // 获取数组 abc 的切片，长度为 3
```
### 向量
格式为 `Type[<size>]`。向量类似于数组，但仅限整数、浮点数和布尔值。核心区别：向量是基于硬件 SIMD（单指令多数据流）的，你可以对向量直接进行数学运算，底层会并行处理。它还支持类似图形学中的"混合赋值（swizzling）"。
```c
int[<2>] b = { 3, 8 };
int[<2>] c = { 7, 2 };
int[<2>] d = b * c; // 并行相乘，d 的结果是 { 21, 16 }
```
## 字符串与数据字面量
C3 中的字符串设计比 C 语言更现代：
- **常规字符串**：双引号 `""`，支持 `\n` 等转义字符。
- **原始字符串**：反引号 `` ` `` 包含，支持多行且不进行转义。如果要表示反引号本身，连写两个即可（` `` `）。
- **类型**：`String` 实际上是 `char[]`（字符切片）的别名，不包含结尾的 Null 字符。而 `ZString` 是 `char*`，兼容 C 语言以 Null 结尾的字符串。
**Base64 和 Hex 字面量：** 你可以直接在代码中写 Base64 或十六进制数据，编译器会在编译时将其转换成字节数组：
```c
char[*] hello_base64 = b64"SGVsbG8gV29ybGQh";
char[*] hello_hex = x"4865 6c6c 6f20 776f 726c 6421";
```
## 指针
指针语法与 C 保持一致 (`Type*`)。多级指针可以叠加（如 `Foo**`）。特殊关键字 `null` 表示空指针。`void*` 是一种特殊的通配符指针，它可以隐式转换为任何其他类型的指针。
## 打印输出
C3 使用 `std::io` 模块来进行打印，主要函数是 `io::print` 和带格式化的 `io::printf`（末尾加 `n` 表示自动换行）。  
**亮点功能：**
- **更智能的格式化**：在 C 语言中你需要用 `%lld`、`%u` 来区分不同的整数类型，而在 C3 中你只需要用 `%d`，它会自动处理所有有符号/无符号以及大至 128 位的整数。
- **万能的 `%s`**：`%s` 不仅能打印字符串，还可以直接将任意类型（比如整数、枚举、甚至是数组内容）转化为字符串并打印出来。
```c
import std::io;
enum Foo { ABC, BCD, EFG }

fn void main() {
    int a = 1234;
    Foo foo = BCD;
    // %s 可以直接打印整数 a 和 枚举变量 foo
    io::printfn("a: %s, foo: %s", a, foo);
}
```
