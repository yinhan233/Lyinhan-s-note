## 临时变量取地址
C3 中的表达式工作方式与 C 类似，但有一个例外：在 C3 中可以对"临时值/右值"取地址，使用的是 `&&` 运算符，而不是普通变量用的 `&`。  
在传统 C 语言中，如果一个函数的形参是指针（如 `void test(int* x)`），你不能直接传数字 `test(&1)`，因为 `1` 是字面量，没有内存地址。你必须显式声明一个临时变量：
```c
// in C
int x = 1;
test(&x);
```
```c
// in C3
fn void test(int* x) { ... }
test(&&1);
```
> 用 `&&` 创建的指针，其生命周期仅在当前函数内部有效！如果在一个函数里把 `&&` 创建的指针作为返回值 `return` 出去，在函数结束后它会变成野指针。
## 明确定义的求值顺序
C3 的表达式具有严格定义的求值顺序：
1. 二元表达式：从左到右求值。
2. 赋值表达式：从右到左求值（因此 `a = a++` 会保持 `a` 的值不变）。
3. 函数调用参数：严格按照参数列表从左到右的顺序求值。
> 在 C 语言中，很多求值顺序是"未定义行为"或"由编译器决定"的。比如在 C 里写 `foo(a(), b())`，你无法确定 `a()` 和 `b()` 谁先执行；写 `a = a++` 更是经典的 C 语言未定义行为。
## 复合字面量与自动类型推导
C3 支持 C 语言风格的结构体和数组复合字面量，只要上下文明确，C3 鼓励并推荐省略类型名称，由编译器自动推导：
```c
struct Foo { int a; double b; }

fn void test1(Foo x) { ... }
fn void test2(int[3] x) { ... }

// 传统的 C 风格写法（C3 也支持）：
test1((Foo){ 1, 2.0 });
test2((int[3]){ 1, 2, 3 });

// C3 推荐的极简推导写法：
test1({ 1, 2.0 });
test2({ 1, 2, 3 });
```
### 结合 `&&` 传递切片或数组指针
C3 的切片（`[]`）和 `&&` 结合后，传参变得非常优雅：
```c
fn void test_slice(int[] y) { ... }
fn void test_ptr(int[3]* z) { ... }

// 传递给切片：以下几种写法均可，最常用的是极简推导
test_slice({ 1, 2, 3 });

// 传递给数组指针：结合 && 获取临时数组的地址
test_ptr(&&(int[3]){ 1, 2, 3 });
```
## 编译期常量表达式
在 C3 中，所有常量表达式都保证在编译期间计算完毕。能够被 C3 认定为"编译期常量"的包括：
- 各种基本字面量（`null`、整数、浮点数、布尔值、字符串字面量）。
- 对常量进行算术运算的结果（如 `1 + 2`）。
- 以 `$` 开头的编译期变量（如 `$my_var`）。
- 无副作用、仅使用常量的宏输出。
不是编译期常量：
1. 非 null 的指针：即便它指向的是常量，指针本身在 C3 中也不被当作常量表达式。
2. 复合字面量：哪怕结构体里的值全都是常量（如 `{ 1, 2 }`），复合字面量整体在 C3 中依然不属于编译期常量表达式！
## 编译期嵌入二进制文件
`$embed(...)` 函数可以在编译期将外部文件的内容直接作为字节数组嵌入到程序中。  
在传统 C 语言中，如果你想把一张图片或文本文件打包进可执行文件里，通常需要借助 Makefile、`xxd` 工具或者转码成巨型 C 语言数组 `.h` 文件。
```c
// 1. 将整个图片嵌入为字节数组
char[*] my_image = $embed("my_image.png");

// 2. 限制读取长度：只嵌入前 4 个字节（例如读取文件头 Header）
char[4] my_header = $embed("foo.txt", 4);
```
### 优雅的文件缺失兜底处理
如果引用的文件不存在，默认会导致编译报错。但如果你希望在文件不存在时使用默认数据，可以结合 C3 的 Optional 类型（`?`）与空值合并运算符（`??`）：
```c
// 如果 my_image.png 存在就用它；如果不存在，自动降级使用 DEFAULT_IMAGE_DATA
char[] my_image = $embed("my_image.png") ?? DEFAULT_IMAGE_DATA;
```
## 总结
| 特性 | C 语言 | C3 语言 |
| --- | --- | --- |
| 右值/字面量取地址 | 不支持（需手动声明临时变量） | 支持，直接使用 `&&` 运算符（如 `&&1`） |
| 函数参数求值顺序 | 未定义/由编译器决定 | 严格从左到右求值 |
| 复合字面量类型 | 必须显式写出类型 `(Foo){...}` | 支持并推荐类型推导，直接写 `{...}` |
| 嵌入外部二进制文件 | 需依赖外部工具生成 `.h` 数组 | 内置 `$embed("file")` 编译期函数 |
| 文件嵌入失败处理 | 无 | 支持 Optional 语法与 `??` 提供默认后备数据 |
