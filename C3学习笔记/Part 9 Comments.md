C3 语言的注释机制非常有特色，它不只是"写给程序员看的文字"，还能直接参与编译器检查和文档生成。
## 四种注释类型概览
| 符号 | 类型 | 特点 / 核心卖点 |
| --- | --- | --- |
| `//` | 单行注释 | 传统写法，注释当前行。 |
| `/* ... */` | 多行注释 | 支持嵌套。 |
| `#!` | Shebang 注释 | 只在文件第一行第一列有效，用于 Unix/Linux 脚本直接运行。 |
| `<* ... *>` | 文档与契约注释 | 核心功能！编译器会自动解析里面的文档、错误类型和代码契约。 |
> 传统 C 语言中，如果你想把一大段代码临时注释掉，而这段代码内部刚好有 `/* ... */`，编译器就会提前闭合报错。C3 允许 `/* /* ... */ */` 嵌套，完美解决了这个问题。
## 契约注释 (`<* ... *>`)
在很多语言（如 Java、JS）中，文档注释（如 Javadoc、TSDoc）只是给 IDE 提供代码提示的文本。但在 C3 里，`<* ... *>` 还能直接给编译器下达断言和契约规则。
### 常用标签一览
- **`@param`**：说明函数输入参数。
- **`@return` / `@return?`**：说明返回值类型，或者可抛出的 Fault（错误类型）。
- **`@require`（前置条件）**：规定传入的参数必须满足的条件。如果不满足，编译器或运行时会直接报错（即契约编程 Design by Contract）。
- **`@ensure`（后置条件）**：规定函数执行完后，返回值或状态必须保证满足的条件。
- **`@deprecated`**：标记该函数已过时，别人调用时编译器会弹警告。
```c
module math_utils;

import std::io;

<*
 计算两个数相除。
 @param a : 被除数
 @param b : 除数
 @require b != 0 : "除数不能为零！"
 @return : 计算结果
*>
fn int divide(int a, int b)
{
    return a / b;
}

fn void test()
{
    // 如果这样调用，@require 契约检查会帮你在编译阶段或运行时捕获错误！
    int result = divide(10, 2);
}
```
### 错误继承
C3 使用 Fault 机制处理错误。如果你的函数要返回另一个函数可能抛出的错误，可以直接在注释里用 `@return? 目标函数!` 进行继承：
```c
<*
  @return? check_triangle!  <-- 自动继承 check_triangle 函数可能抛出的所有错误
*>
fn TriangleKind? get_triangle_kind(Triangle* triangle)
{
    check_triangle(triangle)!;
    // ...
}
```
