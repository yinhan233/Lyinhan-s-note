首先下载 LaTeX ISO 文件：

<https://ctan.mirror.twds.com.tw/tex-archive/systems/texlive/Images/texlive2026.iso>

## Windows 安装

可以双击打开 ISO 文件，里面有`install-tl-windows.bat`，双击后**傻瓜式安装**。

## Linux 安装

笔者为 CachyOS，具体步骤如下：

### 1. 挂载 ISO

```bash
sudo mkdir -p /mnt/tl
sudo mount -o loop /path/to/your/texlive2026.iso /mnt/tl
sudo /mnt/tl/install-tl --scheme scheme-full
```

会弹出安装界面。

### 2. 添加到 PATH

```bash
export PATH=/usr/local/texlive/2026/bin/x86_64-linux:$PATH
export MANPATH=/usr/local/texlive/2026/texmf-dist/doc/man:$MANPATH
export INFOPATH=/usr/local/texlive/2026/texmf-dist/doc/info:$INFOPATH
```

### 3. 配置系统字体

```bash
sudo cp /usr/local/texlive/2026/texmf-var/fonts/conf/texlive-fontconfig.conf /etc/fonts/conf.d/09-texlive.conf
sudo fc-cache -fsv
```

### 4. 卸载 ISO

```bash
sudo umount /mnt/tl
tex --version
```

### 5. 更新

```bash
sudo tlmgr update --self --all
```

**如果 sudo 没有继承 PATH**，可以：

```bash
sudo /usr/local/texlive/2026/bin/x86_64-linux/tlmgr update --self --all
```

或者创建 `/etc/sudoers.d/texlive`：

```text
Defaults secure_path="/usr/local/texlive/2026/bin/x86_64-linux:/usr/local/sbin:/usr/local/bin:/usr/bin"
```
