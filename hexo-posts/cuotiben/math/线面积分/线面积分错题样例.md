## 题目

计算

```text
∮_L (x dy - y dx)
```

其中 `L` 是单位圆 `x² + y² = 1`，取逆时针方向。

## 我的错误思路

看到曲线是圆，直接参数化后开始算，但没有先判断积分方向，也没有想到可以用格林公式。算到最后符号搞反了。

## 正确解法

令

```text
P = -y，Q = x
```

则

```text
∂Q/∂x - ∂P/∂y = 1 - (-1) = 2
```

由格林公式：

```text
∮_L P dx + Q dy = ∬_D 2 dS
```

单位圆面积是 `π`，所以

```text
原式 = 2 × π × 1² = 2π
```

## 参数化验证

令 `x = cosθ，y = sinθ，0 ≤ θ ≤ 2π`，则

```text
dx = -sinθ dθ
dy = cosθ dθ
x dy - y dx = cos²θ + sin²θ = 1
```

所以

```text
原式 = ∫₀^(2π) 1 dθ = 2π
```

两种方法结果一致。

## 易错点

1. 格林公式要求 `L` 是**正向闭曲线**，方向反了要加负号；
2. `P` 和 `Q` 的位置不要代反：`P` 对应 `dx`，`Q` 对应 `dy`；
3. 用参数化时，注意 `θ` 的积分范围和方向；
4. 最后检查一下曲线是否闭合，有没有奇点。

## 同类题

- 把 `L` 换成椭圆 `x²/a² + y²/b² = 1`，结果是多少？
- 如果 `L` 改成顺时针方向，结果怎么变？
- 如果曲线不闭合，需要怎样补线？
