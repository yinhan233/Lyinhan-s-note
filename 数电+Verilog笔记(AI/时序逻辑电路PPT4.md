# 🎛️ 第六章：同步时序电路的设计 (以"101"序列检测器为例)

> [!info] 💡 核心特点速览
> - **同步性**：所有触发器受**同一个统一的时钟脉冲 (CP)** 控制，状态更新同时发生。
> - **时序性**：当前的输出不仅取决于**当前的输入**，还取决于电路**当前的状态**（即之前的历史输入）。
> - **CS专业视角**：这就是我们在《编译原理》或《计算机组成》里常说的 **有限状态机 (FSM)**！PPT中的例子是一个经典的 **Mealy型状态机**（输出由当前状态和当前输入共同决定）。

---

## 🗺️ 全流程通关指南 (五步法)
根据老师的 PPT，设计一个同步时序电路（如"101"序列检测器）分为明确的五步：

### 第一步：逻辑分析与画状态图
- **明确目标**：检测输入序列 `X` 中的 `101`，出现时输出 `Z=1`，否则 `Z=0`。
- **注意重叠**：输入 `110011(101)1`，最后的 `1011` 中包含一个 `101`，且最后的 `1` 可以作为下一个序列的开头（这叫**可重叠检测**）。
- **画状态图/表**：
  - 定义初始态 $S_0$、收到"1"的态 $S_1$、收到"10"的态 $S_2$、收到"101"的态 $S_3$。
  - 根据输入转移状态，并记录输出（格式为：`输入/输出`，例如 `X/Z`）。

### 第二步：状态化简 (极其重要，必考)
> [!question] 为什么要化简？
> 减少状态数量 -> 减少所需触发器的个数 -> 降低硬件成本和电路复杂度！

- **等价状态的判断标准**：如果两个状态在**任何相同的输入**下，产生**相同的输出**，并且转换到的**次态是等价的**（次态相同、交错或循环），那么这两个现态等价，可以合并。
- **PPT推荐解法：隐含表法 (阶梯表格)**
  1. **画表格**：纵向缺头，横向少尾（两两组合不重复）。
  2. **顺次比较**：
     - **输出不同**：直接打 `×`（绝对不可能等价）。
     - **输出相同，次态也相同/交错**：打 `√`（直接等价）。
     - **输出相同，次态不同**：在格子里写上对应的次态（这叫**条件等价**，需要看次态是否等价）。
  3. **合并**：将等价的状态合并为一个（PPT例子中 $S_1$ 和 $S_3$ 等价，合并为 $S_1$）。

### 第三步：状态编码
将抽象的 $S_0, S_1, S_2$ 分配为二进制代码（因为硬件只认识 0 和 1）。
- 例如：$S_0 \rightarrow 01$, $S_1 \rightarrow 00$, $S_2 \rightarrow 11$。
- *注：编码方案不唯一（如顺序码、格雷码），不同的编码只会影响最终电路的复杂度，不影响逻辑功能。*

### 第四步：求解驱动方程与输出方程
这是将"状态表"转化为"逻辑电路"的关键。PPT 中介绍了两种方法，强烈建议掌握**第二种（基于 D 触发器）**，因为最简单。

> [!abstract] 两种求解方法总结 (对应 PPT 后半段)
> 1. **激励表法**：状态表 -> 结合触发器特性表 -> 画出每个触发器的激励函数的卡诺图 -> 得出方程。（**适合 JK 触发器**，较为繁琐）。
> 2. **推导法 (状态方程法)**：状态表 -> 画出次态 $Q_{n+1}$ 的卡诺图 -> 得到状态方程 -> 结合触发器特性方程反推。（**适合 D 触发器**，极其无脑）。

**🔥 重点：使用 D 触发器设计 (最简单)**
D 触发器的特性方程是 $Q_{n+1} = D$ (也就是你想让下一个状态是什么，输入 D 就是什么)。
根据 PPT 的卡诺图化简结果：
- $D_1 = X'Q_0'$
- $D_0 = X'$
- $Z = XQ_1$ (输出方程)

### 第五步：画出逻辑电路图
根据第四步算出来的方程，用与门、非门、或门和触发器连线即可（考试时照着方程连线，细心别连错即可）。

## 💻 Verilog HDL 实战 (让你秒懂)
作为计科专业的学生，写代码比画电路图直观得多。以上 PPT 的设计过程，用 Verilog 的 **三段式状态机** 实现如下：

```verilog
module sequence_detector_101 (
    input clk,
    input rst_n, // 低电平异步复位
    input x,     // 输入序列
    output z     // 检测到101时输出1
);

    // 1. 状态定义 (使用独热码或二进制码均可，这里按化简后的3个状态)
    localparam S0 = 2'b01; // 初始态/收到0
    localparam S1 = 2'b00; // 收到1/收到101 (S1和S3化简合并了)
    localparam S2 = 2'b11; // 收到10

    reg [1:0] current_state, next_state;

    // 第一段：同步时序逻辑，更新状态 (对应触发器的时钟上升沿)
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            current_state <= S0;
        else
            current_state <= next_state;
    end

    // 第二段：组合逻辑，判断下一个状态 (对应驱动方程)
    always @(*) begin
        case (current_state)
            S0: next_state = x ? S1 : S0; // 来1去S1，来0回S0
            S1: next_state = x ? S1 : S2; // 来1停留在S1(重新开始检测101)，来0去S2
            S2: next_state = x ? S1 : S0; // 来1说明101完成去S1(与S3合并)，来0去S0
            default: next_state = S0;
        endcase
    end

    // 第三段：组合逻辑，决定输出 (对应输出方程 Z = X & Q1)
    // 这是Mealy状态机，输出和当前状态以及当前输入x有关
    assign z = (current_state == S2) && (x == 1'b1); 

endmodule
```

## 📝 随堂小练 & 快速自测

为了确保你能在考试中快速拿分，请尝试回答以下问题：

**💡 习题 1：概念速答**
在进行状态化简时，如果状态 A 和状态 B 在输入 `X=0` 和 `X=1` 时的输出完全相同，且输入 `X=0` 时次态都是 C，输入 `X=1` 时，A 的次态是 B，B 的次态是 A。这两个状态能合并吗？
> [!success]- 点击查看答案
> **能合并。**
> 满足等价条件：1. 输出相同； 2. 次态相同（都是C）或交错（A到B，B到A）。所以 A 和 B 等价。

**💡 习题 2：D触发器 vs JK触发器**
为什么我们在做数字逻辑设计（包括写 Verilog 代码综合成电路时），绝大多数情况下倾向于使用 D 触发器而不是 JK 触发器？
> [!success]- 点击查看答案
> 因为 D 触发器的特性方程是 $Q^* = D$。不需要像 JK 触发器那样去查繁琐的"激励表"来分离 J 和 K 的方程。D 触发器的驱动方程直接等于次态方程，计算极简，极大降低了设计复杂度（见 PPT 第 38 页老师的吐槽："含 JK 触发器麻烦"）。

**💡 习题 3：读图分析 (经典考点)**
观察 PPT 第 35 页最终的电路图，输出 `Z` 接入了一个与门，其输入分别来自 `X` 和触发器 $Q_1$ 的输出。这说明该电路是 Moore 机还是 Mealy 机？
> [!success]- 点击查看答案
> **Mealy 机。**
> 判别标准：如果输出方程中包含了输入变量 $X$，就是 Mealy 机（如 $Z = XQ_1$）。如果输出仅仅是当前状态 $Q$ 的函数（如 $Z = Q_1 Q_0$），不含 $X$，则是 Moore 机。题目要求“出现 101 时输出”，由于只有 3 个状态，第 3 个周期的输入 $X$ 必须立刻参与输出判断，所以必然是 Mealy 型。
