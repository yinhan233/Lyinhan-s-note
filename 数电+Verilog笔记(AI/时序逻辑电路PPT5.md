# 📚 第六章：时序逻辑电路核心总结

## 💡 一、 什么是时序逻辑电路？（核心特点）

> [!info] 核心认知
> 组合逻辑电路（如加法器） = 无记忆的函数 `y = f(x)`
> 时序逻辑电路 = 带有状态变量（内存）的函数 `y = f(x, state)`，`next_state = g(x, state)`

**四大核心特点：**
1. **有记忆功能**：电路的输出不仅取决于**当前的输入**，还取决于**电路之前的状态**。
2. **包含存储原件**：必然包含触发器（Flip-Flop，通常是 D触发器或 JK触发器）用来保存当前状态。
3. **两套核心方程**：
   - **输出方程**：决定当前输出是什么（Mealy型与输入有关，Moore型与输入无关）。
   - **驱动/状态方程**：决定下一个时钟周期，电路会跳转到什么状态。
4. **时钟驱动**：状态的改变严格按照时钟信号（Clock）的节拍进行（同步时序电路）。

## ⚙️ 二、 传统硬核设计流程（考试大题必考）

对于手算题，一般遵循以下打怪升级流程：

1. **逻辑抽象 (最难一步)**：读懂题意，画出**状态转换图 (State Diagram)** 或列出 **状态转换表**。
2. **状态简化**：把功能完全相同的重复状态合并（等价状态合并）。
3. **状态编码**：给每个状态分配二进制代码（如 S0=00, S1=01...）。*⚠️强烈建议采用**格雷码 (Gray Code)**（如00->01->11->10），因为每次只变一位，能有效减少电路毛刺。*
4. **求出三大方程**：
   - 根据状态转换表，画出**卡诺图**。
   - 写出 **状态方程**（次态方程）。
   - 写出 **驱动方程**（你要给触发器的引脚喂什么信号）。
   - 写出 **输出方程**。
5. **画出逻辑电路图**（考试通常到这一步结束）。

## 🔄 三、 核心考点：电路的“自启动” (Self-Starting)

> [!warning] 什么是自启动？（CS视角：异常恢复机制）
> 假设你需要设计一个 5进制计数器，你需要用到 3 个触发器（最多能存 $2^3=8$ 个状态）。其中 3 个状态是**无效状态（多余状态）**。
> 如果通电一瞬间，或者受到干扰，电路刚好进入了这 3 个无效状态，**它还能不能自己跳回正常的 5 个工作状态中？**
> - 能跳回来 = **可自启动**
> - 陷入死循环 = **不可自启动**

**如何设计可自启动的电路？**
在画卡诺图化简时，多余状态通常被标记为 `X`（无关项）。
- 如果你把 `X` 当作 `1` 圈进去了，你必须把这些无效状态代入求出的状态方程中，计算它们的下一个状态（次态）。
- 如果次态回到了正常状态圈子里 -> **设计成功，可自启动**。
- 如果次态仍然是无效状态 -> **必须修改卡诺图**，强行把那个 `X` 当作 `0` 或者改成特定值，重新计算方程。

## 💻 四、 现代 EDA 玩法：Verilog 与有限状态机 (FSM)

作为CS学生，这部分是你的主场。基于硬件描述语言的设计，本质上就是写 `switch-case` 语句！

### 1. FSM 的三种 Verilog 写法
PPT中介绍了“101序列检测器”的三种写法。**建议无脑掌握“三段式”写法**，它是工业界标准，逻辑最清晰，最不容易出错。

> [!check] 黄金法则：三段式状态机
> - **第一段 (时序逻辑)**：只负责更新状态（`state <= next_state`）。
> - **第二段 (组合逻辑)**：根据当前状态和输入，计算下一个状态（`switch-case` 状态转移）。
> - **第三段 (组合/时序逻辑)**：计算输出（通常用 `assign` 或独立的 `always` 块）。

### 2. 例题：PPT中的 "101" 序列检测器 (三段式代码)

```verilog
module fsm_seq101 (
    input clk,    // 时钟
    input clr,    // 异步复位 (清零)
    input x,      // 串行输入数据
    output reg z  // 检测到101时输出1
);

    // 1. 定义状态 (采用格雷码)
    parameter S0 = 2'b00, S1 = 2'b01, S2 = 2'b11, S3 = 2'b10;
  
    reg [1:0] state, next_state;

    // --- 第一段：同步状态更新 (时序逻辑) ---
    always @(posedge clk or posedge clr) begin
        if (clr) 
            state <= S0;  // 异步复位回到初始状态
        else 
            state <= next_state;
    end

    // --- 第二段：次态计算 (组合逻辑) ---
    // 注意：现代Verilog推荐使用 always @(*) 替代 always @(state or x)
    always @(*) begin
        case (state)
            S0: if (x) next_state = S1; else next_state = S0;
            S1: if (x) next_state = S1; else next_state = S2; // 遇到0变"10"
            S2: if (x) next_state = S3; else next_state = S0; // 遇到1变"101"
            S3: if (x) next_state = S1; else next_state = S2;
            default: next_state = S0; // 必须有default，防止生成锁存器！
        endcase
    end

    // --- 第三段：输出逻辑 (组合逻辑) ---
    always @(*) begin
        if (state == S3) 
            z = 1'b1;
        else 
            z = 1'b0;
    end

endmodule
```

## 🎯 五、 实战演练与小习题（通关大Boss）

结合 PPT 第 26 页的主观题，我们来实操一下。这也是极高频的考试大题题型。

### 题目：设计一个 "10110" 序列检测器
**要求**：检测到 "10110" 时输出 1，否则输出 0。要求写出状态图并用 Verilog 实现。

### 🚀 Step 1: 逻辑分析与画状态图 (手算解法)
设初始状态为 `S0`。我们需要记住已经匹配了多少位。
- `S0`: 啥也没匹配上 (等待首个 '1')
- `S1`: 匹配了 "1"
- `S2`: 匹配了 "10"
- `S3`: 匹配了 "101"
- `S4`: 匹配了 "1011"
- `S5`: 匹配了 "10110" -> 此时输出 Z = 1

*(思考路径：如果在 S4("1011") 来了输入 '1' 会怎样？变成了 "10111"，完全破坏了序列，必须退回到 S1("1")。如果来了 '0'，则成功进入 S5 输出1。)*

### 🚀 Step 2: Verilog 完整实现 (满足第26页附加要求)

这道题不仅考状态机，还考了**使能开关(SW1)**、**数据输入(SW2)**，以及一个很经典的 CS 必备技能：**时钟分频**（每0.25秒检测一次，50MHz变4Hz）。

> [!example] 完整工程代码参考 (可以直接拿去应付实验课)

```verilog
module SeqDetector_10110 (
    input clk_50mhz,  // Y2: 50MHz 时钟
    input SW1,        // AB27: 总使能开关
    input SW2,        // AC27: 串行数据输入
    output reg LEDR0  // G25: 检测成功点亮
);

    // ==========================================
    // 1. 时钟分频器：将 50MHz 分频为 4Hz (0.25秒)
    // ==========================================
    reg [23:0] cnt; // 50,000,000 / 4 = 12,500,000，需要24位计数器
    reg clk_025s;

    always @(posedge clk_50mhz) begin
        if (cnt == 24'd12_499_999) begin
            cnt <= 0;
            clk_025s <= ~clk_025s; // 翻转时钟
        end else begin
            cnt <= cnt + 1;
        end
    end

    // ==========================================
    // 2. FSM 有限状态机核心 ("10110" 检测)
    // ==========================================
    // 状态编码 (6个状态)
    parameter S0=3'd0, S1=3'd1, S2=3'd2, S3=3'd3, S4=3'd4, S5=3'd5;
    reg [2:0] state, next_state;

    // 第一段：状态转移 (使用 0.25s 慢时钟)
    always @(posedge clk_025s) begin
        if (!SW1) 
            state <= S0;  // SW1 关闭时，系统复位
        else 
            state <= next_state;
    end

    // 第二段：次态逻辑
    always @(*) begin
        case(state)
            S0: next_state = SW2 ? S1 : S0; // 来1去S1，来0留S0
            S1: next_state = SW2 ? S1 : S2; // (1) 来0去S2(10)，来1留S1(1)
            S2: next_state = SW2 ? S3 : S0; // (10) 来1去S3(101)，来0毁了去S0
            S3: next_state = SW2 ? S4 : S2; // (101) 来1去S4(1011)，来0回S2(10)
            S4: next_state = SW2 ? S1 : S5; // (1011) 来0去S5(成功!)，来1回S1(1)
            S5: next_state = SW2 ? S1 : S0; // (10110) 重新开始检测
            default: next_state = S0;
        endcase
    end

    // 第三段：输出逻辑
    always @(*) begin
        // 只有当开关开启，且状态到达 S5 时才点亮 LED
        if (SW1 && (state == S5))
            LEDR0 = 1'b1;
        else
            LEDR0 = 1'b0;
    end

endmodule
```

## 📝 总结必背（期末考试避坑指南）

1. **组合逻辑无记忆，时序逻辑有记忆。** 时序逻辑必带时钟 (CLK)。
2. **考手算设计时**：严格按照 `画状态图 -> 状态表 -> 卡诺图化简 -> 写出三个方程（次态/驱动/输出）` 的套路来。
3. **考自启动时**：查卡诺图里的无关项 `X`！把 `X` 对应的次态算出来，如果没有跑到有效状态里，一定要修改设计。
4. **考 Verilog 时**：一律采用 **三段式状态机**。记得给 `case` 语句加上 `default`，这是为了防止综合出不要的锁存器（Latch），也是保证状态机**可自启动**的代码级实现方式！
