# 📚 数电核心笔记：第五章 触发器 (Flip-Flop)

> [!tip] 什么是触发器？(核心概念)
> 简单来说，触发器就是**能存 1 bit 数据的内存**。
> 组合逻辑电路（如加法器）没有记忆，输入一变输出立马变；而触发器**有记忆功能**，在没有外部触发时，能保持当前状态（0或1）不变。
> *   **现态 $Q^n$**：当前的输出状态。
> *   **次态 $Q^{n+1}$**：触发后，下一个时刻的输出状态。

---

## 一、 基本 RS 触发器 (Basic RS Latch)

这是最原始的触发器，属于**异步控制**（没有统一的时钟指挥，输入变了它就可能跟着变）。

### 1. 核心特点
*   **S (Set) 置位端**：负责把输出变成 1。
*   **R (Reset) 复位端**：负责把输出变成 0。
*   **保持**：S 和 R 都不起作用时，保持原来的状态。
> [!warning] 致命缺陷：约束条件
> S 和 R **绝对不能同时有效**！如果同时有效，输出状态将不可控（薛定谔的状态）。
> *PPT中提到了低电平有效和高电平有效两种，考试常考高电平有效，这里以此为例。*

### 2. 特性表与方程
| R (复位) | S (置位) | $Q^{n+1}$ (次态) | 功能说明 |
| :---: | :---: | :---: | :--- |
| 0 | 0 | $Q^n$ | **保持**（记住旧数据） |
| 0 | 1 | 1 | **置1** (Set) |
| 1 | 0 | 0 | **置0** (Reset) |
| 1 | 1 | 不定 | 🚫 **不允许 (约束)** |

*   **特性方程**：$Q^{n+1} = S + \overline{R}Q^n$
*   **约束条件**：$R \cdot S = 0$ 

### 3. Verilog HDL 实现
*(注：基本RS触发器在实际数字系统设计中很少直接写，因为没有时钟，容易产生毛刺，这里仅作行为级描述)*
```verilog
module basic_rs_latch (
    input S, R,
    output reg Q
);
    always @(*) begin
        if (R == 1'b1 && S == 1'b0)      Q = 1'b0;      // Reset
        else if (R == 1'b0 && S == 1'b1) Q = 1'b1;      // Set
        else if (R == 1'b1 && S == 1'b1) Q = 1'bx;      // 不定态 (x表示未知)
        // S=0, R=0 默认保持原状态，无需写代码
    end
endmodule
```

## 二、 时钟 RS 触发器 (Synchronous RS)

为了解决基本 RS 触发器“没人统一指挥”的问题，引入了**时钟信号 CP (Clock Pulse)**。

### 1. 核心特点
*   **有了总指挥 CP**：只有当 `CP = 1` 时，S 和 R 的信号才能生效。`CP = 0` 时，无论 S 和 R 怎么瞎搞，输出绝对**保持不变**。
*   **电平触发**：在 CP 处于高电平（1）的**整个期间**，只要 S/R 变化，输出就会跟着变。
> [!warning] 遗留问题
> 它依然没有解决 S 和 R 不能同时有效的**约束问题**（$R \cdot S = 0$ 依然存在）。

### 2. 特性方程
*   **特性方程**：$Q^{n+1} = S + \overline{R}Q^n$ (仅在 CP=1 时有效)

## 三、 D 触发器 (D Flip-Flop) —— 👑 计科人的神！

为了彻底干掉 RS 触发器烦人的“约束条件”，我们把 R 接口去掉了，直接让 $R = \overline{S}$，并把 S 改名为 **D (Data)**。
**这是现代计算机 CPU、寄存器、内存中最最最常用的组件！**

### 1. 时钟 D 触发器 (电平触发 Latch)
*   **特点**：当 `CP = 1` 时，输入 D 是什么，输出 $Q^{n+1}$ 就是什么。就像一个透明的窗户。
*   **特性方程**：$Q^{n+1} = D$ (非常简单粗暴)

### 2. 边沿触发 D 触发器 (Edge-Triggered FF) —— 重点中的重点
*   **特点**：为了抗干扰，它**只在时钟信号 CLK 的上升沿（或下降沿）那一瞬间**去读取 D 的值，并更新给 Q。其他时候哪怕 D 翻江倒海，Q 也稳如泰山。
*   **抗干扰能力极强**，是目前数字芯片设计（FPGA/ASIC）的基石。

### 3. Verilog HDL 实现 (计科必会)
这就是你以后写体系结构大作业、Verilog 课设天天要写的代码！

```verilog
// 带异步复位的边沿触发 D 触发器 (最经典写法)
module d_ff_edge (
    input clk,    // 时钟信号
    input rst_n,  // 异步复位信号 (低电平有效)
    input D,      // 数据输入
    output reg Q  // 数据输出
);

    // posedge clk: 上升沿触发
    // negedge rst_n: 下降沿触发 (复位)
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            Q <= 1'b0;  // 只要复位信号一拉低，立刻清零
        end else begin
            Q <= D;     // 时钟上升沿到来时，把 D 存入 Q
        end
    end

endmodule
```

## 四、 快速上手实战演练

为了对付考试，你需要掌握“看波形画输出”和“看逻辑写结果”的能力。

### 📝 例题 1：分析 D 触发器波形（对应 PPT P32/P35 思想）
**题目**：假设初态 $Q = 0$。给出一个上升沿触发的 D 触发器，已知 CLK 和 D 的波形，请描述 Q 的变化规律。
*   `CLK`: `0 -> 1` (此时 $D=1$) -> `保持1` (期间 $D$ 变成0) -> `1 -> 0` -> `0 -> 1` (此时 $D=0$)
**解析**：
> [!check] 解题秘诀：**只盯住 CLK 的“上升沿”（0变1的那一瞬间）**。
1. 第一个上升沿：看此时的 D 是多少？是 1。那么 Q 变成 1。
2. CLK 为 1 的保持期间：D 虽然变成了 0，但**边沿触发器不吃这一套**，Q 继续保持 1！
3. 第二个上升沿：看此时的 D 是多少？是 0。那么 Q 变成 0。
*结论：Q只在边沿瞬间捕获D，其余时间全部“保持”。*

### 📝 例题 2：逻辑推导方程
**题目**：如果在一个边沿 D 触发器外部，把它的输出 $\overline{Q}$ 直接连回它的输入 D（即 $D = \overline{Q}$），每次时钟上升沿到来时，Q 会怎样？
**解析**：
1. 代入 D 触发器特性方程：$Q^{n+1} = D$
2. 因为 $D = \overline{Q^n}$
3. 所以 $Q^{n+1} = \overline{Q^n}$
> [!tip] 结论与应用
> 每次时钟打过来，状态就翻转一次（0变1，1变0）。这就是**分频器**（频率减半）最基础的电路！

### 📝 例题 3：RS 触发器约束条件考察
**题目**：使用与非门构成的基本RS触发器（低电平有效，即 $S=0$置1，$R=0$清零），其约束条件是什么？
**答案**：$R + S = 1$ （或者写成不允许 $R=0$ 且 $S=0$）。因为如果两个低电平同时输入与非门，会强行让两个输出都变成1，破坏了触发器 $Q$ 和 $\overline{Q}$ 必须互反的物理定律。

| 触发器类型     | 核心输入信号   | 特性方程 / 行为                              | 致命痛点 / 解决的问题                     |
| :-------- | :------- | :------------------------------------- | :------------------------------- |
| **基本 RS** | S, R     | $Q^{n+1} = S + \overline{R}Q^n$        | 痛点：没时钟控制，且有约束 $RS=0$             |
| **时钟 RS** | CP, S, R | 仅CP=1时：$Q^{n+1} = S + \overline{R}Q^n$ | 解决：统一了时机。<br>痛点：约束依然存在。          |
| **电平 D**  | CP, D    | 仅CP=1时：$Q^{n+1} = D$                   | 解决：消灭了约束。<br>痛点：CP=1期间输入波动会引起干扰。 |
| **边沿 D**  | CLK, D   | 仅在CLK跳变沿：$Q^{n+1} = D$                 | 解决：抗干扰无敌，现代数字系统绝对主力！             |
