3. **`011`** (截断最高位)； **`0000000010`** (向左补零)
4. **B** (只要在 `always` 内部被赋值，左边变量必须是 `reg`)

6. **错** (必须逐个单元赋值，或者用系统任务批量读取)
7. **错** (`always`可综合，`initial`不可综合，仅用于仿真)
8. **C** (`always @(*)` 自动把所有输入加入敏感列表，防漏防Latch)
9. **错** (时序逻辑必须用**非阻塞赋值 `<=`**)
10. **C** (黄金法则第3条：锁存器建模尽量用非阻塞赋值 `<=`)
11. **`default`** (处理所有未列出的状态)
12. **B, D** (for循环在综合时会在物理空间上展开电路)
13. **错** (Function不能包含时间控制，不能调用Task，瞬间执行完毕)
14. **B** (A是结构化，C是行为化)

16. **`a`** (条件为0/假，选冒号后面的值)

19. **C** (综合工具会自动推断出最优的加法器电路)
20. **错** (竞争不一定会导致冒险，只有特定逻辑如A+A'才会导致毛刺)
21. **C** (时序同步设计是现代数字逻辑消除毛刺的根本大法)
22. **B** (用空间换时间，大幅降低延迟)

#### 最终挑战参考代码：

**练习1答案：**
```verilog
module mux2to1(
    input wire A, B, Sel,
    output wire Y
);
    assign Y = Sel ? B : A; 
endmodule
```

**练习2答案：**
**错误：** 描述具有记忆功能的时序逻辑（D触发器）时，错误使用了**阻塞赋值（`=`）**。
**修正：** 应该改为非阻塞赋值（`<=`）。
```verilog
// ... 
    if (!rst)
        Q <= 1'b0;
    else
        Q <= D; 
// ...
```

**练习3答案：**
```verilog
module priority_enc(
    input [3:0] I,
    output reg [1:0] Y
);
    always @(*) begin
        if (I[3])      Y = 2'b11;
        else if (I[2]) Y = 2'b10;
        else if (I[1]) Y = 2'b01;
        else if (I[0]) Y = 2'b00;
        else           Y = 2'b00; // 默认状态
    end
endmodule
```

**练习4答案：**
```verilog
function [2:0] count_ones;
    input [3:0] data_in;
    // 方法：纯组合逻辑，按位相加
    begin
        count_ones = data_in[0] + data_in[1] + data_in[2] + data_in[3];
    end
endfunction
```
*(注：也可以在function内声明integer用for循环累加，但按位相加在Verilog中更为精简)*

**练习5答案：**
```verilog
module voter3(
    input wire A, B, C,
    output reg Pass
);
    reg [1:0] sum; // 最大为3，需要2位宽

    always @(*) begin
        // 阻塞赋值计算票数和
        sum = A + B + C; 
      
        if (sum >= 2) 
            Pass = 1'b1;
        else 
            Pass = 1'b0;
    end
endmodule
```
