# 📖 第六章：时序逻辑电路 (Sequential Logic Circuits)

> [!info] 💡 核心认知（计科视角）
> 组合逻辑电路就像是没有记忆的纯函数：`y = f(x)`。
> **时序逻辑电路**就像是面向对象编程中的“实例对象”，它带有内部变量（状态）：`y = f(x, state)`，且状态会随时间更新：`next_state = g(x, state)`。

## 🎯 一、 时序电路的特点与分类

### 1. 结构与功能特点
*   **功能上：** 任意时刻的输出，不仅取决于**当前的输入**，还取决于电路**原来的状态**（即具有“记忆”功能）。
*   **结构上：** 包含 **组合逻辑电路** + **存储电路（触发器）**。输出通过反馈线连接回输入端。

### 2. 核心分类（必考概念）
按**时钟信号**分类：
*   **同步时序电路 (Synchronous)：** 所有触发器共享**同一个时钟 (CLK)**，状态在同一时刻统一变化。（我们主要学这个，也是现代 CPU 设计的主流）。
*   **异步时序电路 (Asynchronous)：** 没有统一时钟，状态变化有先有后，容易产生竞争冒险。

按**输出依赖关系**分类（经典考点）：

| 模型类型             | 输出方程 $Y$ 的依赖关系                            | 理解                           |
| ---------------- | ----------------------------------------- | ---------------------------- |
| **Mealy (米里) 型** | $Y = F(X, Q)$。不仅取决于当前状态 $Q$，还取决于当前输入 $X$。 | 输出不仅看现在的状态，还受外界输入立刻影响。       |
| **Moore (摩尔) 型** | $Y = F(Q)$。**仅仅**取决于电路的当前状态 $Q$。          | 状态决定一切，外界输入不能直接影响输出，只能先改变状态。 |

## 📦 二、 前置依赖：触发器黑盒模型
> [!warning] 考试不考内部结构！
> 把触发器当成一个**存储 1 bit 数据的变量**。我们只需要记住它们的**特性方程**（即下一个状态 $Q^{n+1}$ 或 $Q^*$ 是如何由当前状态 $Q$ 和输入决定的）。

| 触发器类型 | 特性方程 (次态方程) | 动作总结 (大白话) |
| :--- | :--- | :--- |
| **D 触发器** | $Q^* = D$ | 传声筒：输入什么，下一个状态就是什么。 |
| **JK 触发器** | $Q^* = J\overline{Q} + \overline{K}Q$ | 全能王：`J=1,K=0`置1；`J=0,K=1`置0；`J=0,K=0`保持；`J=1,K=1`翻转。 |
| **T 触发器** | $Q^* = T \oplus Q$ | 开关：`T=1` 状态翻转；`T=0` 状态保持不变。 |
| **RS 触发器** | $Q^* = S + R'\overline{Q}$ <br>*(约束: RS=0)* | S(Set)置1，R(Reset)置0。**绝对不能让 R和S 同时为1！** |

*(注：$Q^*$ 和 $Q^{n+1}$ 都表示下一个时钟周期的状态，即“次态”；$Q$ 表示当前状态“现态”)*

## 🛠️ 三、 时序逻辑电路的分析“三步曲”

面对一个复杂的同步时序电路图，分析它到底是个什么功能的计数器/序列发生器，只需刻板地执行以下三步算法（参照 PPT p.12）：

### 📝 Step 1: 抄写方程 (看图写式子)
1.  **驱动方程 (Drive Equations):** 找出每个触发器输入端的表达式（例如 $J_1 = ?, K_1 = ?$）。
2.  **输出方程 (Output Equation):** 找出整个电路最终输出端 $Y$ 的表达式。

### 🧮 Step 2: 代入求解状态方程
将算出的**驱动方程**，代入到对应触发器的**特性方程**（上面第二节的公式）中，得到整个电路的**状态方程** $Q^* = f(X, Q)$。

### 🔄 Step 3: 画状态转换表/图
枚举所有可能的状态，代入状态方程，算出下一个状态。画出圆圈和箭头组成的图（类似有限自动机 DFA）。
> [!check] 避坑指南 (PPT p.21 重点)
> 算出图后，一定要检查**有没有被遗漏的状态（无效状态）**！如果电路偶尔进入了无效状态，它能不能自动回到主循环里？（这叫电路的**自启动能力**）。

## 📚 四、 经典例题全解析

### 例题 1：模 7 加法计数器 (PPT p.13 - p.24)
**电路特点：** 3个下降沿 JK 触发器组成。没有外部数据输入，只有时钟 CLK。
**分析过程：**
1. **驱动方程** (看图得出)：
   * $J_1 = (Q_2Q_3)', K_1 = 1$
   * $J_2 = Q_1, K_2 = (Q_1'Q_3)'$
   * $J_3 = Q_1Q_2, K_3 = Q_2$
2. **状态方程** (代入 JK 触发器公式 $Q^* = JQ' + K'Q$)：
   * $Q_1^* = (Q_2Q_3)'Q_1'$
   * $Q_2^* = Q_1Q_2' + Q_1'Q_3'Q_2$
   * $Q_3^* = Q_1Q_2Q_3' + Q_2'Q_3$
3. **输出方程**：$Y = Q_2Q_3$ (进位脉冲)
4. **状态图结论**：经过枚举计算，状态在 `000 -> 001 -> 010 -> 011 -> 100 -> 101 -> 110 -> 000` 循环。这是一个**七进制（模7）加法计数器**。遇到状态 `111` 会自动跳回 `000`（具备自启动能力）。

### 例题 2：带控制端的可逆计数器 (PPT p.30 - p.31)
这是一个有输入变量 $A$ 的 D触发器电路。
* **状态图解析：**
  * 当 $A=0$ 时：状态 `00 -> 01 -> 10 -> 11 -> 00`，此时是**模4加法计数器**。
  * 当 $A=1$ 时：状态 `00 -> 11 -> 10 -> 01 -> 00`，此时是**模4减法计数器**。
* **结论：** 这是一个受输入 $A$ 控制的**模4方向可控计数器**。

## 💻 五、 程序员狂喜：Verilog HDL 实现

在硬件描述语言中，时序逻辑通常使用 `always @(posedge clk)` 或者 `always @(negedge clk)`，并且一定要使用**非阻塞赋值 `<=`** 来代表寄存器状态的更新。

### 1. 实现“模 7 加法计数器” (行为级描述，极简)
对应 PPT p.26 的逻辑：
```verilog
module ctr_mod_7(
    input clk, 
    output y, 
    output reg [2:0] q // 3位寄存器，代表状态 Q3 Q2 Q1
);

    // 时序逻辑：下降沿触发
    always @ (negedge clk) begin
        if (q == 3'd6) // 当计到 6 (110) 的时候，下一个状态归零
            q <= 3'b000;
        else 
            q <= q + 1; // 否则加 1
    end

    // 组合逻辑：输出进位脉冲
    assign y = (q == 3'd6) ? 1'b1 : 1'b0;

endmodule
```

### 2. 回答 PPT 第 31 页的疑问：模 4 可控计数器的 Verilog 程序
PPT p.31 留了一个悬念，让你写出例 6.2.3 的代码，这里直接给出标准答案：
```verilog
module mod4_up_down_counter(
    input clk,
    input A,       // A=0加法，A=1减法
    output reg [1:0] q // 模4只需要2个触发器
);

    always @(posedge clk) begin
        if (A == 1'b0) begin
            q <= q + 1; // 加法计数
        end else begin
            q <= q - 1; // 减法计数 (如果是00，减1会自动变成11)
        end
    end
endmodule
```
*计科视角理解：底层硬件虽然是一堆异或门和 D触发器，但用 Verilog 行为级写出来，就是一个简单的 `if-else`。*

## 📝 六、 小试牛刀 (快速自测)

1. **选择题：** 某此时序电路的输出不仅仅取决于当前状态，还直接受到了外部输入信号的控制，这属于哪种类型的时序电路？
   * 答：Mealy 型。
2. **填空题：** D触发器的特性方程是 _________；如果想用 JK 触发器实现类似 T 触发器（每次来时钟都翻转）的功能，应该让 J = _____, K = _____。
   * 答：$Q^* = D$；`1`，`1`。
3. **判断题：** 分析同步时序电路时，不仅要画出有效状态的转换，还要把无效状态代入方程看看它们的去向，以判断自启动能力。
   * 答：正确。
4. **代码题纠错：** 下面这段写时序逻辑的 Verilog 哪里有问题？
   ```verilog
   always @(posedge clk) begin
       q = q + 1; // 错误！
   end
   ```
   * 答：时序逻辑中更新寄存器状态必须使用**非阻塞赋值 `<=`**，应改为 `q <= q + 1;`。使用 `=`（阻塞赋值）会引发综合成组合逻辑的隐患。
