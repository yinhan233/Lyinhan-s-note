# 📚 第六章：时序逻辑电路 (Sequential Logic Circuits)

> [!info] 💡 **核心思想：什么是时序逻辑电路？**
> 与组合逻辑电路（现在的输出只和现在的输入有关，像纯函数）不同，**时序逻辑电路有“记忆”**。现在的输出不仅取决于当前的输入，还取决于电路**之前的状态**。
> **公式化理解**：`当前输出 = f(当前输入, 当前状态)` 且 `下一状态 = g(当前输入, 当前状态)`。

---

## 模块一：同步时序电路分析“三步走”

给你一个电路图，怎么看懂它在干嘛？只需要列出三个关键方程：

1. **驱动方程 (Drive Equation)**：看触发器的输入端接了什么信号。（比如 $D = \dots$ 或 $J= \dots, K = \dots$）
2. **状态方程 (State Equation)**：把驱动方程代入触发器的特性方程（考试最常用的 $D$ 触发器就是 $Q^* = D$）。这决定了电路的**“次态” ($Q^*$)**。
3. **输出方程 (Output Equation)**：看整个电路的最终输出 $Y$ 是怎么由当前状态 $Q$ 和输入决定的。

**👉 分析流程**：写出方程 $\rightarrow$ 算出状态转换表 $\rightarrow$ 画出状态转换图 $\rightarrow$ 总结电路功能（比如：哦！这是一个模4的加法计数器）。

## 模块二：两大常用核心器件 (重点掌握)

考试不考内部结构，你只需要把它们当成拥有特定 API 的 API 接口，记住它们的**控制引脚**和**功能表**即可。

### 1. 寄存器与移位寄存器 (Registers)
* **特点**：用来存放一组二进制代码。移位寄存器不仅能存，还能在时钟脉冲到来时，把数据向左或向右移动。
* **经典芯片**：**74LS194A** (带左右移、并行输入、保持、异步清零功能的四位移位寄存器)。

### 2. 计数器 (Counters) - 🌟 考试绝对重点
在数字系统里，计数器除了数数，还能用来分频、定时。
按照进制分，最常用的有两个“神级”芯片：
* **74161**：4位同步**二进制**计数器（模16，数到1111再回0000）
* **74160**：同步**十进制**计数器（模10，数到1001也就是9，再回0000）

> [!important] 📊 **74161 / 74160 的控制引脚优先级 (背诵)**
> 这两个芯片的引脚功能几乎一模一样，优先级从高到低如下：
> 1. **$R_D'$ (清零端)**：只要它为 0，不管别的，状态立刻归零（**异步清零**）。
> 2. **$LD'$ (置数端)**：如果清零无效且它为 0，时钟一来，直接把外部输入 $D_0 \sim D_3$ 的数据加载进来（**同步置数**）。
> 3. **$EP, ET$ (使能端)**：如果清零和置数都没工作，这俩必须都为 1 才能正常数数。有一个为 0 就保持原状态不动。

## 模块三：任意进制计数器的设计 (核心考点)

如何用现有的 $N$ 进制芯片（如模16的74161），拼凑出 $M$ 进制（如模6或模29）的计数器？

### 情况 A：当 N > M (大改小，比如用16进制改6进制)
原理：让计数器在数到某一个状态时，强行跳过后面的状态，回到起点。
有两种经典方法：

* **方法一：异步置零法 (利用 $R_D'$)**
  * **特点**：检测到目标状态（如6，即0110），立刻产生低电平去触发清零。
  * **缺点**：目标状态会短暂出现一下（闪亮），然后瞬间归零。
  * **设计口诀**：**“模 M 就拿 M 译码”**。想做模6，就拿 6 (0110) 的状态连接与非门，接到 $R_D'$ 上。

* **方法二：同步置数法 (利用 $LD'$)**
  * **特点**：检测到目标状态的前一个状态，当时钟到来时，强制加载 0000。
  * **优点**：没有过渡状态，工作更稳定。
  * **设计口诀**：**“模 M 就拿 M-1 译码”**。想做模6，就拿 5 (0101) 的状态连接与非门，接到 $LD'$ 上，置数端设为全0。

### 情况 B：当 N < M (小改大，比如用两块10进制拼成100进制)
* **并行进位法**：共用一个 Clock 时钟。低位片的进位输出 $C$ 接到高位片的使能端 ($EP, ET$) 上。低位数满了，高位才动一下。
* **串行进位法**：低位片的进位输出 $C$ 直接作为高位片的 Clock 时钟。

> [!tip] 组合玩法：
> 比如用两块 74160 (最大能到100) 做一个 **29进制**计数器：
> 先把两块级联成 100 进制，然后把整体看作一个大的 $N$，采用“整体置零”或“整体置数”法，检测状态 `0010 1001` (29) 或 `0010 1000` (28) 进行复位即可。

## 模块四：同步时序电路的设计 (状态机设计)

**经典例题：序列信号检测器（当输入出现 "101" 时，输出 1，否则输出 0）**

**设计流程 (适合计科人理解的 Automata 状态机视角)**：
1. **定义状态 (State)**：
   * $S_0$：初始状态（啥都没收到）
   * $S_1$：收到了一个 "1"
   * $S_2$：收到了 "10"
   * $S_3$：收到了 "101" (此时输出为1)
2. **画状态图 / 状态表**：根据新来的输入是 0 还是 1，决定跳转到哪个状态。
3. **状态化简**：如果有两个状态，面对相同的输入，会产生相同的输出并且跳到相同的新状态，这俩状态就是“等价”的，可以合并。（为了省代码和省硬件）。
4. **编码与实现**：给状态分配二进制编码（如00, 01, 10），写出 Verilog。

## 模块五：Verilog HDL 实现 (即贴即用)

计科专业狂喜部分！数电里的连线完全可以用代码写出来。

### 1. 简单的带异步复位的寄存器 (类似74HC175)
```verilog
module Register_4bit(
    input clk, rd,      // rd为复位信号
    input [3:0] d,
    output reg [3:0] q
);
    // 异步复位：敏感列表里不仅有clk，还有复位信号的下降沿
    always @(posedge clk or negedge rd) begin
        if (~rd) 
            q <= 4'b0000; // 只要复位有效，立刻清零
        else 
            q <= d;       // 否则时钟到来时更新数据
    end
endmodule
```

### 2. 移位寄存器 (带输入补充)
```verilog
module Shifter_4bit(
    input din, clk,
    output reg [3:0] qout,
    output dout
);
    always @(posedge clk) begin
        qout <= qout << 1;     // 整体左移一位
        qout[0] <= din;        // 最低位补上新输入的数据
    end
    assign dout = qout[3];     // 最高位作为串行输出
endmodule
```

### 3. 基于 EDA 直接写任意模数计数器 (模200计数器)
传统的画图接线太麻烦，用 Verilog 修改阈值只需改一行代码：
```verilog
module Count_200(
    input clk,
    output reg [7:0] count // 255最大，足够存200
);
    always @(posedge clk) begin
        if (count == 199) // 数到199归零 (0~199共200个数)
            count <= 0;
        else
            count <= count + 1;
    end
endmodule
```

### 4. 经典应用：时钟分频器 (50MHz 分频为 5MHz)
分频本质上就是计数。50M / 5M = 10，也就是说我们需要一个**模10计数器**。每数 5 个脉冲（半个周期），输出的电平翻转一次。
```verilog
module Clk_Divider(
    input clk50mhz,
    output reg clk5mhz
);
    reg [2:0] count; // 模5计数器只需要3位 (0~4)

    always @(posedge clk50mhz) begin
        if (count == 4) begin   // (N/2 - 1) = 10/2 - 1 = 4
            count <= 0;
            clk5mhz <= ~clk5mhz; // 计数满，时钟翻转
        end else begin
            count <= count + 1;
        end
    end
endmodule
```

## 模块六：自测小习题 📝

**Q1：异步清零和同步清零有什么本质区别？**
> **解答**：异步清零不看时钟脸色，清零信号一到瞬间归零（代码里体现为清零信号在 `always` 的敏感列表中）；同步清零必须等下一个时钟上升沿到来时才会起作用。

**Q2：现在手头只有一个模16计数器 74161，我要设计一个模 12 计数器。如果我使用“同步置数法”，我应该去检测数字几？**
> **解答**：数字 11（二进制为 `1011`）。因为是同步置数，会在检测到 11 后，等到下一个时钟沿才把 0000 载入，正好完成了 0 到 11 共 12 个状态的循环。如果用异步清零法，则需要检测数字 12 (`1100`)。

**Q3：用代码实现状态机时，状态图里的“状态化简”对于硬件实现有什么好处？**
> **解答**：减少状态数量。如果有5个状态，需要3个触发器（$2^2 < 5 \le 2^3$）；化简后如果只剩4个状态，只需要2个触发器。对于计科人来说，这就相当于优化了空间复杂度，降低了硬件成本。
