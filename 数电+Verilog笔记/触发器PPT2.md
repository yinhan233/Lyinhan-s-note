# ⚡ 数字逻辑笔记：常用触发器 (Flip-Flop)

> [!abstract] 计科视角的 TL;DR
> **触发器 (FF)** 就是用来存储 **1 bit** 数据的基本单元。相当于我们在代码里定义的一个 `bool` 变量，只不过它的值的改变受到**时钟信号 (CLK/CP)** 的严格控制。
> *考试重点：认清输入信号、记住状态方程、会画时钟边缘的波形图。*

## 一、 核心概念速查 (Cheat Sheet)

无论是哪种触发器，我们只关心三个基本概念：
1. **现态 ($Q^n$)**：当前触发器里存的值（0 或 1）。
2. **次态 ($Q^{n+1}$)**：下一个时钟节拍到来后，触发器里要变成的值。
3. **时钟 (CLK/CP)**：指挥官，告诉触发器“你现在可以更新状态了”。通常是**上升沿** ($\uparrow$) 或 **下降沿** ($\downarrow$) 触发。

---

## 二、 三大主力触发器精讲

### 1. D触发器 (Data / Delay) —— “无脑复读机”

> [!info] 特点介绍
> 最简单、最常用的触发器（CPU里的寄存器基本都是它拼出来的）。
> **特点：输入什么，输出就是什么。** 它不关心你以前存的是什么（与现态无关），只在时钟信号到来的那一瞬间，把输入端 $D$ 的值“复制粘贴”到输出端 $Q$。

*   **特性方程：** $$Q^{n+1} = D$$
  
**状态表：**
  
| D   | $Q^{n+1}$ | 说明 |
| --- | --------- | ---- |
| 0   | 0         | 置 0 |
| 1   | 1         | 置 1 |
#### 💻 Verilog HDL 实现 (边沿触发)
计科生秒懂：这就是一个简单的时序逻辑赋值。
```verilog
module d_ff (
    input clk,
    input rst_n, // 异步复位信号（习惯性加上，考试常考初态设为0）
    input d,
    output reg q
);
    // 仅在 clk 上升沿 或 rst_n 下降沿 时触发代码
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            q <= 1'b0;  // 复位清零
        else
            q <= d;     // Q 紧随 D 的变化
    end
endmodule
```

#### 📝 快速测验
**Q:** 如果在两次时钟上升沿之间，D 信号疯狂地在 0 和 1 之间跳变了几十次，Q 会怎么变？
**A:** Q **完全不变**。D 触发器（边沿触发）是个“瞎子”，它只在时钟上升沿那一瞬间睁眼看一眼 D 是多少，其他时间 D 怎么变它都不管。这叫**抗干扰能力强**。

---

### 2. JK触发器 —— “全能瑞士军刀”

> [!info] 特点介绍
> 功能最全的触发器。它有两个输入端 J 和 K。你可以把它理解为具有四种指令的微型状态机：**保持、清零、置位、翻转**。

*   **特性方程：** $$Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n$$ 
    *(如果J有效则强行置1，如果不受K清零影响则保持原状)*
    
**特性表：**

| J   | K   | $Q^{n+1}$        | 指令                             |
| --- | --- | ---------------- | ------------------------------ |
| 0   | 0   | $Q^n$            | **Keep (保持)**：什么都不做            |
| 0   | 1   | 0                | **Reset (清零)**：K(Kill)起作用，干掉数据 |
| 1   | 0   | 1                | **Set (置位)**：J(Jump)起作用，强制设为1  |
| 1   | 1   | $\overline{Q^n}$ | **Toggle (翻转)**：0变1，1变0        |


#### 💻 Verilog HDL 实现
用 `case` 语句实现非常直观：
```verilog
module jk_ff (
    input clk, rst_n,
    input j, k,
    output reg q
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) q <= 1'b0;
        else begin
            case ({j, k})
                2'b00: q <= q;       // 保持
                2'b01: q <= 1'b0;    // 置0
                2'b10: q <= 1'b1;    // 置1
                2'b11: q <= ~q;      // 翻转
            endcase
        end
    end
endmodule
```

#### 📝 快速测验
**Q:** 给定一个 JK 触发器，我想把它当做 D 触发器来用，应该怎么接线？  
**A:** 令 $J = D$, $K = \overline{D}$。这样当输入 1 时(J=1,K=0)置1，输入 0 时(J=0,K=1)置0，完美模拟 D 触发器。

---

### 3. T触发器 (Toggle) —— “状态切换开关”

> [!info] 特点介绍
> 专门用来做“翻转”的触发器。多用于**计数器**和**分频器**。只有一个输入端 T。
> **特点：T=0 睡觉（保持），T=1 翻身（翻转）。**

*   **特性方程：** $$Q^{n+1} = T \oplus Q^n$$ 
    *(计科翻译：次态是 T 和现态的异或)*
*   **衍生：T'触发器 (T-prime)**：相当于把 T 永远接在高电平（T=1），每次时钟来都会翻转。

#### 💻 Verilog HDL 实现
```verilog
module t_ff (
    input clk, rst_n,
    input t,
    output reg q
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) q <= 1'b0;
        else if (t) q <= ~q; // 仅当 t=1 时翻转状态
    end
endmodule
```

#### 📝 快速测验
**Q:** 假设输入时钟 CLK 的频率是 100MHz，如果使用一个 T'触发器（T始终=1），输出 Q 的波形频率是多少？
**A:** **50MHz**。因为 CLK 必须经历“两个”上升沿（或下降沿），Q 才能完成一次完整的 0->1->0 周期。这就是所谓的**二分频**。

## 三、 触发方式的演进与大坑 (考试必考画图)

> [!warning] 必考预警
> 考试画波形图，最重要的是先看**触发符号**。有小圆圈的是下降沿触发，没有的是上升沿触发。主从触发器最容易出错！

### 1. 电平触发 (Level Triggered) - 几乎淘汰
*   **特点：** 只要时钟 CLK=1 的期间，输入变了，输出就跟着变。
*   **致命缺点【空翻】**：在一个时钟周期内，如果输入信号抖动了多次，输出也会跟着乱跳多次。这在计算机时序控制里是灾难。

### 2. 边沿触发 (Edge Triggered) - 现代主流 (如你PPT第3/4/29页)
*   **特点：** 极其严格！只在 CLK 从 0变1（或1变0）的**那一瞬间**采样输入信号。
*   **优点：** 完美解决了“空翻”问题。波形图最好画，拿一把尺子对着边沿画一条虚线下来，只看这一瞬间的值即可。

### 3. 主从触发器 (Master-Slave) - 考试大坑 (PPT第18-28页)
由两个触发器拼接而成。分为“主”和“从”。（通常是下降沿 $\downarrow$ 看输出）。
*   **工作机制（两步走）：**
    1.  **CLK=1 期间：** 主触发器工作，接收输入信号；从触发器锁死。
    2.  **CLK下降沿 (1 $\rightarrow$ 0) 瞬间**： 主触发器锁死；从触发器读取主触发器的值，并输出到 $Q$。
*   **致命缺点【一次翻转现象】（重点）**：
    由于主从 JK 触发器内部有反馈线，在 CLK=1 的整个期间：
    *   如果现态 $Q=0$，主触发器**只能接收置 1 信号 (J=1)**，对 K 信号免疫。只要 CLK=1 期间 J 出现过一次高电平，主触发器就变成 1 且再也变不回去了，下降沿到来时 Q 必定变为 1。
    *   同理，如果现态 $Q=1$，主触发器**只能接收置 0 信号 (K=1)**，只要 K 出现过一次 1，下降沿到来时 Q 必定变为 0。

> [!tip] 💡 做题口诀：主从JK触发器波形图怎么画？
> 1. 先看初态。如果 $Q=0$，在整个 CLK=1 的高电平区间里，只盯着 $J$ 信号看。
> 2. 只要 $J$ 敢在这个区间里“凸”起变成 1（哪怕只有一瞬间），不管 $K$ 怎么变，等到**下降沿**到来时，$Q$ 直接画翻转成 1。
> 3. 反之亦然。这叫“记住曾经发生的改变”。

### 🎉 总结
作为计科人：
1. **D 触发器** = 赋值语句 `Q = D` (发生在上/下降沿)
2. **JK 触发器** = 万能状态机 (保持、清零、置位、翻转)
3. **T 触发器** = `Q = !Q` (当 T=1 时)
4. 画图题：尺子对准触发沿。碰到“主从JK触发器”，要往前检查整个高电平期间有没有“异常跳变”（一次翻转现象）。
