# 🧠 数电期末速成：触发器与寄存器 (Verilog视角)

> [!info] 💡 CS专业的底层逻辑理解
> 触发器（Flip-Flop）本质上就是我们在写代码时的**全局变量**。
> - **组合逻辑电路**：像纯函数，输入变了输出立刻变（没有记忆）。
> - **时序逻辑电路（触发器）**：带有 `static` 或全局属性的变量，只有在特定的**触发条件（如时钟滴答声）**下，才会根据当前的输入更新自己的值。

---

## 一、 触发器的核心分类 (The "Big Four")

我们先不管它怎么触发，先看它**“能干什么”**（逻辑功能）。考试中最常考的是这四种触发器的状态转移方程（即：下一个状态 $Q^{n+1}$ 和当前状态 $Q^n$ 及输入的关系）。

| 触发器 | 核心特点 | 状态转移方程 (特征方程) | CS大白话解释 |
| :--- | :--- | :--- | :--- |
| **D触发器** | **延迟/直通 (Delay)** | $Q^{n+1} = D$ | `Q = D;` (最常用，输入什么，时钟一敲输出就是什么) |
| **JK触发器** | **全能王** | $Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n$ | $J=1,K=0$置1；$J=0,K=1$置0；$1,1$状态翻转；$0,0$保持 |
| **RS触发器** | **置位/复位** | $Q^{n+1} = S + \overline{R}Q^n$ ($SR=0$) | S(Set)置1，R(Reset)置0。⚠️**不能同时为1** (Bug状态) |
| **T触发器** | **翻转 (Toggle)** | $Q^{n+1} = T \oplus Q^n$ | T为1就取反（翻转），T为0就保持。常用于计数器 |

## 二、 触发方式的进化史（为什么会有不同形状的时钟）

触发器的触发方式决定了它**什么时候去读取输入并更新状态**。PPT中重点讲述了JK触发器的进化，主要是为了修Bug。

### 1. 电平触发 (Level-triggered) - 也就是锁存器 (Latch)
- **特点**：只要时钟 $CP=1$（高电平期间），大门敞开，输入怎么变，输出就跟着怎么变。
- **致命Bug**：**空翻 (Race-around)**。时钟高电平期间，如果输入信号发生多次变化，输出也会跟着变多次，导致状态不可控。

### 2. 主从触发 (Master-Slave) - 主要是主从JK触发器
- **特点**：分两步走。$CP=1$ 时，主触发器接收信号，从触发器锁死；$CP$ 变 $0$ 时，主触发器锁死，从触发器把刚才接收的值推出去。
- **致命Bug**：**一次翻转现象**。在 $CP=1$ 期间，如果发生了干扰（比如本来该保持，结果J或者K闪了一下1），它的状态会被“弄脏”并记住，这辈子（这个周期内）再也改不回来了，直到下一个周期。

### 3. 边沿触发 (Edge-triggered) - 终极完美版 🌟
- **特点**：**瞬间抓拍**。只在时钟信号**上升沿（0变1）**或**下降沿（1变0）**那一瞬间读取输入。其余时间无论输入怎么蹦跶，输出绝对不理它。
- **结论**：完美解决了空翻和一次翻转问题，抗干扰能力极强，是我们现在数字芯片（包括CPU）最绝对的主流！

## 三、 必考考点：异步复位/置位 vs 同步复位

在实际的芯片中，除了正常工作的时钟，我们还需要“强制清零/强制置1”的按键（比如电脑的重启键）。PPT中强调了这两者的区别，这也是 Verilog 必考点！

> [!danger] 核心区别
> - **异步 (Asynchronous)**：特权阶级！不管时钟有没有来，只要复位信号一按，瞬间清零！
> - **同步 (Synchronous)**：普通员工。按了复位信号没用，必须等下一个**时钟有效边沿**到来时，才能执行清零动作。

### 💻 Verilog 实现对比 (极高频考点)

#### 1. 带有【异步复位】和【异步置位】的 D触发器 (上升沿触发)
*注：PPT中的 $\overline{R_D}$ 和 $\overline{S_D}$ 通常是低电平有效，这里以 PPT 第33页代码为例。*

```verilog
module dff_async (
    input clk, preset, reset, data, 
    output reg q // 注意：在always块里赋值的输出必须是reg类型
);
    // 触发列表：不仅有时钟沿，还有复位和置位的边缘！这就是“异步”的灵魂
    always @(posedge clk or negedge reset or posedge preset) begin
        if (~reset)          // 优先级最高：低电平异步复位
            q <= 1'b0;
        else if (preset)     // 优先级次之：高电平异步置位 (依据PPT)
            q <= 1'b1;
        else                 // 时钟沿到来：正常工作
            q <= data;
    end
endmodule
```

#### 2. 带有【同步复位】的 D触发器 (上升沿触发)
```verilog
module dff_sync (
    input clk, reset, data, 
    output reg q
);
    // 触发列表：【只有时钟边沿】！没有时钟，天王老子来了也改不了状态
    always @(posedge clk) begin
        if (reset) // 时钟来的时候，先看复位键按了没
            q <= 1'b0;
        else
            q <= data;
    end
endmodule
```

## 四、 常用集成芯片 (背诵/认脸题)

PPT提到了两款经典芯片及它们的 Verilog 建模，考试常考它们的作用：

> [!check] 1. 74LS373 (8位数据锁存器 Latch)
> - **特点**：**电平触发**。不是边沿！
> - **引脚**：`LE` (Latch Enable，相当于时钟，高电平敞开，低电平锁存)；`OE` (Output Enable，输出使能，低电平有效)。
> - **行为**：`LE=1` 时，Q跟着D变；`LE=0`时，Q锁死保持。`OE=1`时输出高阻态。
> - **代码特征**：没有 `posedge/negedge`，用的是组合逻辑触发 `always @(*)` 或 `always @(le, oe, d)`。

> [!check] 2. 74LS175 (4位 D触发器 Register)
> - **特点**：**边沿触发**（正脉冲/上升沿触发）。
> - **引脚**：带有低电平有效的**异步复位端** (`~RD`)。
> - **代码特征**：标准的触发器写法 `always @(posedge clk or negedge rd)`。

## 五、 快速上手实战（画波形图 & 习题技巧）

> [!tip] 考试画波形图的 3 步傻瓜法则：
> 1. **找眼睛**：先看触发器符号。有没有小圆圈？三角形代表边沿触发。没有圆圈是上升沿，有圆圈是下降沿。拿笔把所有有效时钟沿画一条**竖直虚线**。
> 2. **看特权**：有没有异步复位（$R_D$）/置位（$S_D$）？如果有，一旦它们有效，立刻强制画0或1，完全不用管理时钟！
> 3. **查状态**：只在第1步画的**竖直虚线那一个瞬间**，抬头看输入是什么。套用特征方程得出下一个状态画平线，直到遇到下一根虚线。

### 📝 随堂小测 (自测一下)

**问题 1：** 
如果一个触发器的Verilog代码是 `always @(posedge clk)`，请问它是电平触发还是边沿触发？是同步复位还是异步复位？
> **答案：** 边沿触发（上升沿）。所有的操作都包裹在这个always里，所以肯定是**同步复位**（因为敏感列表里没有复位信号）。

**问题 2：**
JK触发器当前状态 $Q=1$。在下一个时钟沿到来时，输入 $J=1, K=1$。请问下一个状态 $Q$ 是多少？
> **答案：** $Q=0$。JK触发器输入同为1时，执行**翻转(Toggle)**功能。当前是1，翻转后就是0。

**问题 3：**
PPT提到的“主从JK触发器的一次翻转现象”，为什么在后来的设计中被淘汰了？
> **答案：** 因为它的抗干扰能力差。在时钟高电平期间，虽然输出不突变，但主触发器极其敏感。输入只要稍微抖动出现过“翻转”信号，主触发器就会记下来并锁死，导致最终下降沿输出错误的状态。因此后来普遍改用“边沿触发器”。
