## 第一部分：找系统帮忙（DOS功能调用 `INT 21H`）

这部分就像是调用现成的API函数。你只需要记住一个核心公式：
**把功能号放进 `AH` 寄存器 ＋ 准备好需要的参数 ＋ 执行 `INT 21H`。**

PPT里只讲了4个最常用的功能，我们把它们分成“单字符”和“字符串”两类来记：

### 1. 单字符操作（一次一个字母）

*   **⌨️ 输入一个字符（1号功能）**
    *   **口诀**：`AH=1`，结果在 `AL`。
    *   **代码**：
        ```assembly
        mov ah, 1
        int 21h
        ; 执行完后，你敲击的字符的ASCII码就静静地躺在 AL 寄存器里了。
        ```
*   **🖥️ 输出一个字符（2号功能）**
    *   **口诀**：`AH=2`，东西放 `DL`。
    *   **代码**：
        ```assembly
        mov dl, 'A'  ; 把想显示的字符放入DL
        mov ah, 2
        int 21h
        ; 屏幕上就会打印出一个 'A'。注意：执行后 AL 的值会被改成 DL 的值。
        ```

### 2. 字符串操作（一次一串字母）

*   **🖥️ 输出一串字符（9号功能）**
    *   **口诀**：`AH=9`，地址给 `DX`，结尾必须是 `$`。
    *   **代码**：
        ```assembly
        ; 数据段里定义：msg db 'Hello!$'  <-- 注意结尾的$符号！
        mov dx, offset msg  ; 把字符串的首地址给DX
        mov ah, 9
        int 21h
        ```
*   **⌨️ 输入一串字符（10号，即 0AH 功能）** —— **重点易错区！**
    *   **口诀**：`AH=10`，地址给 `DX`。
    *   **注意**：你不能随便给个地址，必须提前定义一个**特殊结构**的缓冲区！
    *   **缓冲区结构（必须按这三步走）**：
        1.  第1个字节：**你允许**最多输入几个字符？（你自己设定的）
        2.  第2个字节：系统运行后**实际**输入了几个字符？（系统自动填的，不用你管，写 `?`）
        3.  第3个字节开始：真正存放你敲进去的字符的地方。
    *   **代码示例**：
        ```assembly
        ; 数据段定义：
        buffer db 10       ; 允许输入10个字符
               db ?        ; 实际输入个数(占位)
               db 11 dup(?) ; 存放字符的空间 (多留1个给回车符0DH)
      
        ; 代码段调用：
        mov dx, offset buffer
        mov ah, 10
        int 21h
        ```

## 第二部分：自己动手丰衣足食（直接写显存）

如果你觉得 `INT 21H` 输出的字都是黑底白字太单调，那就可以**直接修改显卡的内存（显存）**，实现五颜六色的效果！

### 1. 核心原理：屏幕就是一块内存
*   在彩色字符模式下，屏幕被分成了 **25行 × 80列**。
*   控制这块屏幕的内存地址是从 **`B8000H`** 开始的（一般把段寄存器 `ES` 设置为 `B800H`）。
*   **黄金规则：屏幕上的每一个字符，在内存里需要占用 2个字节！**
    *   **偶数地址（第1个字节）**：放字符的 ASCII 码（比如 'A'）。
    *   **奇数地址（第2个字节）**：放字符的 **颜色属性**。

### 2. 颜色属性怎么填？（一个字节，8个位）
PPT第13、14页给出了属性字节的构成：`7 6 5 4 3 2 1 0` 位。
*   **最高位（第7位）**：1代表闪烁，0代表正常。（全屏纯DOS下才可见闪烁）
*   **中间三位（6,5,4）**：**背景颜色**（RGB，比如 000是黑，111是白，001是蓝）。
*   **第3位**：1代表高亮（亮一点），0代表正常亮度。
*   **最低三位（2,1,0）**：**前景颜色**（即字体的颜色，RGB）。

> **举个栗子**：想要“蓝底黄字”（正常不闪烁）。
> 背景蓝(001)，高亮(1)，前景黄(红+绿=110)。
> 拼起来就是：`0 001 1 110` (二进制) = `1EH` (十六进制)。把 `1EH` 填到奇数地址，字就变成蓝底黄字了！

### 3. 万能位置计算公式（必考/必用）
你想把字显示在屏幕的第 `Row` 行，第 `Col` 列，地址偏移量该怎么算？
*   **公式：位置 = 行号 × 160 + 列号 × 2**
    *(注意：行号从0~24，列号从0~79。因为一行80个字，每个字占2字节，所以一行是160个字节)*
*   **举例**：在第 2 行，第 3 列显示字符。
    偏移量 = `2 * 160 + 3 * 2 = 320 + 6 = 326` (十进制) = **`0146H`** (十六进制)。

## 💡 总结成一句话的备忘录：
*   **键盘输一个**：`AH=1`, 返回在 `AL`。
*   **屏幕显一个**：`AH=2`, 字符放 `DL`。
*   **屏幕显一串**：`AH=9`, 地址放 `DX`, 结尾带 `$`。
*   **键盘输一串**：`AH=10`, 地址放 `DX`, 准备好“容量+实际+内容”的缓冲区。
*   **花式全屏显**：`ES` 指向 `B800H`，算好 `行*160+列*2`，连续写入 `[ASCII码, 颜色属性]`。
