# 8086 汇编语言（MASM 5.0）期末复习题 —— 解析

---

## 一、解析题（共 72 题）

### （一）基础知识（第 1 ~ 6 题）

**1.** 汇编语言的三种元素分别是什么？其中哪些能够被翻译为机器指令，哪些不能？

> **答**：  
> 三种元素：
> 1. **汇编指令**（助记符）—— **能**被翻译为机器指令。
> 2. **伪指令**（编译器执行）—— **不能**被翻译为机器指令，仅在汇编期间为汇编程序提供相关信息。
> 3. **其他符号**（+、- 等，由编译器识别）—— **不能**被翻译为机器指令。

---

**2.** 8086 CPU 有 \_\_\_\_ 根地址总线，最大寻址空间为 \_\_\_\_ B（即 \_\_\_\_ MB）。

> **答**：  
> 20 根地址总线，最大寻址空间为 2²⁰ B（即 **1 MB**）。

---

**3.** 8086 CPU 的数据总线宽度为 \_\_\_\_，控制总线的作用是 \_\_\_\_。

> **答**：  
> 数据总线宽度为 **16**（一次传送 2 字节）。  
> 控制总线的作用是：**CPU 通过控制总线对外部器件进行控制**（其根数决定了 CPU 提供了对外部器件的多少种控制）。

---

**4.** 执行指令 `ADD AX, BX` 后，可能受到影响的标志位有哪些？`MOV AX, BX` 指令是否会影响标志位？

> **答**：  
> `ADD` 影响的标志位：**CF**（进位）、**OF**（溢出）、**SF**（符号）、**ZF**（零）、**AF**（辅助进位）、**PF**（奇偶）。  
> `MOV` 指令**不影响**任何标志位。

---

**5.** 已知 `(DS)=2000H`，`(BX)=1000H`，则指令 `MOV AX, [BX]` 访问的物理地址是多少？

> **答**：  
> 物理地址 = 段地址 × 16 + 偏移地址 = 2000H × 10H + 1000H = 20000H + 1000H = **21000H**。

---

**6.** 8086 CPU 采用 \_\_\_\_ 存储模式（大端/小端）。若在 `2000:0000` 处存放字数据 `5678H`，则 `2000:0000` 单元存放 \_\_\_\_H，`2000:0001` 单元存放 \_\_\_\_H。

> **答**：  
> 采用 **小端（Little-Endian）** 存储模式。  
> `2000:0000` 存放 **78H**（低字节），`2000:0001` 存放 **56H**（高字节）。

---

### （二）寄存器与标志位（第 7 ~ 16 题）

**7.** 8086 CPU 共有多少个 16 位寄存器？按功能可分为哪几类？

> **答**：  
> 共 **14 个** 16 位寄存器，分为 4 类：
> 1. **通用寄存器**（数据寄存器）：AX、BX、CX、DX
> 2. **变址与指针寄存器**：SI、DI、SP、BP
> 3. **指令指针寄存器**：IP
> 4. **段寄存器**：CS、DS、SS、ES
> （另有标志寄存器 FLAGS / PSW）

---

**8.** 下列寄存器中，哪些可以拆分为两个 8 位寄存器使用？  
A. AX &emsp; B. SI &emsp; C. CX &emsp; D. DI

> **答**：  
> **A 和 C**。AX → AH/AL，CX → CH/CL。  
> SI 和 DI 不能拆分为 8 位寄存器。

---

**9.** 写出下列寄存器的默认用途：  
（1）AX &emsp;（2）BX &emsp;（3）CX &emsp;（4）DX &emsp;（5）SP &emsp;（6）BP &emsp;（7）SI &emsp;（8）DI

> **答**：  
> （1）**AX**：累加器，算术运算、I/O 操作的默认寄存器。  
> （2）**BX**：基址寄存器，常用于存放内存基地址，可用于 `[...]` 寻址（默认段 DS）。  
> （3）**CX**：计数寄存器，`LOOP` 指令、字符串操作的默认计数器。  
> （4）**DX**：数据寄存器，配合 AX 进行 32 位乘除运算，或存放 I/O 端口地址。  
> （5）**SP**：堆栈指针寄存器，始终指向栈顶，配合 SS 管理堆栈。  
> （6）**BP**：基址指针寄存器，放入 `[...]` 时默认配合 SS 段访问堆栈数据。  
> （7）**SI**：源变址寄存器，常用于字符串操作和变址寻址（默认段 DS）。  
> （8）**DI**：目的变址寄存器，常用于字符串操作和变址寻址（默认段 DS）。

---

**10.** 执行以下指令后，`AX` 和 `DX` 的值分别是多少？
```asm
MOV AX, 0FFFH
ADD AX, 1
```

> **答**：  
> `0FFFH + 1 = 1000H`，`AX = 1000H`。  
> `DX` 的值**不变**（ADD 只影响目的操作数 AX）。  
> 注意：无符号加法的进位进入 CF=1，但 AX 本身只保存低 16 位结果 1000H。

---

**11.** 已知 `(AL)=86H`，`(BL)=7FH`。执行 `ADD AL, BL` 后：
（1）`AL` 的值是多少？  
（2）`CF` 的值是多少？为什么？  
（3）`SF` 的值是多少？为什么？  
（4）`OF` 的值是多少？为什么？

> **答**：  
> 86H + 7FH = 105H（8 位运算，进位丢弃至 CF，AL 只保留低 8 位）。
>
> （1）**`AL = 05H`**（取低 8 位 05H）。  
> （2）**`CF = 1`**。按无符号数：134 + 127 = 261 > 255，产生进位。  
> （3）**`SF = 0`**。结果 05H 的最高位为 0。  
> （4）**`OF = 0`**。按有符号数：86H = -122，7FH = +127。(-122) + (+127) = +5，结果在 -128 ~ +127 范围内，无溢出。  
> 用公式判断：OF = 1 仅当两个操作数符号相同且结果符号不同。86H（负，MSB=1）与 7FH（正，MSB=0）符号不同 → OF = 0。

---

**12.** 已知 `(AX)=3000H`，`(BX)=5000H`。执行 `SUB AX, BX` 后：
（1）`AX` 的值是多少？  
（2）`CF` 的值是多少？  
（3）`ZF` 的值是多少？

> **答**：  
> 3000H - 5000H = -2000H → 补码表示 = **E000H**。
>
> （1）**`AX = E000H`**。  
> （2）**`CF = 1`**。无符号数 3000H < 5000H，发生借位。  
> （3）**`ZF = 0`**。结果 E000H ≠ 0。

---

**13.** 执行以下指令后，`AX` 和 `BX` 的值分别是多少？`CF` 的值是多少？
```asm
MOV AX, 5678H
MOV BX, 1234H
ADD AX, 0DEF0H
ADC BX, 9ABCH
```

> **答**：  
> `AX = 5678H + DEF0H = 13568H`，低 16 位 = **3568H**，`CF = 1`（有进位）。  
> `BX = 1234H + 9ABCH + CF(1) = 1234H + 9ABCH + 1 = ACF1H`。  
>
> 最终：**`AX = 3568H`**，**`BX = ACF1H`**，**`CF = 0`**（1234H + 9ABCH + 1 = ACF1H，无进位）。

---

**14.** 执行以下指令后，`AX` 和 `DX` 的值分别是多少？`CF` 的值是多少？
```asm
MOV AX, 2000H
MOV BX, 3000H
SUB AX, BX
SBB DX, 0
```

> **答**：  
> `AX = 2000H - 3000H = F000H`（借位后），`CF = 1`。  
> `DX = DX - 0 - CF(1) = DX - 1`（DX 初值未知，假设为 n，则 DX = n - 1；若 DX 初值为 0，则 DX = FFFFH）。  
>
> 若假设 `DX` 初值为 0：**`AX = F000H`**，**`DX = FFFFH`**，**`CF = 1`**。

---

**15.** 8086 的标志寄存器 FLAGS 中，`ZF`、`SF`、`CF`、`OF`、`PF` 分别表示什么含义？其中针对有符号数运算的标志位是哪个，针对无符号数运算的标志位是哪个？

> **答**：  
> | 标志位 | 名称 | 含义 |
> |:---:|:---|:---|
> | ZF | 零标志 | 结果为 0 时 ZF=1 |
> | SF | 符号标志 | 结果为负（最高位为 1）时 SF=1 |
> | CF | 进位/借位标志 | 无符号数运算发生进位/借位时 CF=1 |
> | OF | 溢出标志 | 有符号数运算发生溢出时 OF=1 |
> | PF | 奇偶标志 | 结果低 8 位中 1 的个数为偶数时 PF=1 |
>
> **CF** 针对**无符号数**运算；**OF** 针对**有符号数**运算。两者相互独立。

---

**16.** 执行以下指令后，分别写出 `ZF` 和 `SF` 的值：
```asm
MOV AL, 0
ADD AL, 0FFH
```

> **答**：  
> `0 + 0FFH = 0FFH`。  
> **`ZF = 0`**（结果 0FFH ≠ 0）。  
> **`SF = 1`**（结果 0FFH 最高位为 1，作为有符号数时为负数 -1）。

### （三）内存寻址（第 17 ~ 26 题）

**17.** 8086 中，能够放入 `[...]` 中用于内存寻址的寄存器有哪几个？分别写出它们默认对应的段寄存器。

> **答**：  
> 只有 4 个：
> | 寄存器 | 类别 | 默认段寄存器 |
> |:---:|:---|:---:|
> | **BX** | 基址寄存器 | **DS** |
> | **BP** | 基址寄存器 | **SS** |
> | **SI** | 变址寄存器 | **DS** |
> | **DI** | 变址寄存器 | **DS** |

---

**18.** 下列寻址方式中，哪些是合法的？哪些是非法的？说明理由。
（1）`MOV AX, [AX]`  
（2）`MOV AX, [BX]`  
（3）`MOV AX, [BP]`  
（4）`MOV AX, [SI+DI]`  
（5）`MOV AX, [BX+SI]`  
（6）`MOV AX, [BX+BP]`

> **答**：  
> （1）**非法** — AX 不是可寻址寄存器（只有 BX、BP、SI、DI 可放入 `[...]`）。  
> （2）**合法** — BX 是基址寄存器，默认段 DS。  
> （3）**合法** — BP 是基址寄存器，默认段 SS。  
> （4）**非法** — 不能同时使用两个变址寄存器（SI + DI）。  
> （5）**合法** — 基址（BX）+ 变址（SI）合法。  
> （6）**非法** — 不能同时使用两个基址寄存器（BX + BP）。

**19.** 已知 `(DS)=2000H`，`(BX)=100H`，`(SI)=50H`。分别计算以下指令访问的物理地址：
（1）`MOV AL, [BX]`  
（2）`MOV AL, [BX+SI]`  
（3）`MOV AL, [BX+200H]`  
（4）`MOV AL, [BX+SI+50H]`

> **答**：  
> 物理地址 = DS × 16 + EA（偏移地址）。
>
> （1）EA = 100H → **20100H**  
> （2）EA = 100H + 50H = 150H → **20150H**  
> （3）EA = 100H + 200H = 300H → **20300H**  
> （4）EA = 100H + 50H + 50H = 1A0H → **201A0H**

---

**20.** 8086 有哪 5 种核心内存寻址方式？请写出每种寻址方式的汇编形式和偏移地址（EA）计算公式。

> **答**：
> | 寻址方式 | 汇编形式 | EA 计算公式 | 默认段 |
> |:---|:---|:---|:---:|
> | 直接寻址 | `[idata]` | idata | DS |
> | 寄存器间接寻址 | `[BX]` / `[SI]` / `[DI]` / `[BP]` | 寄存器值 | DS（BP 为 SS） |
> | 寄存器相对寻址 | `[BX+idata]` | (BX) + idata | DS |
> | 基址变址寻址 | `[BX+SI]` / `[BX+DI]` | (BX) + (SI)/(DI) | DS |
> | 相对基址变址寻址 | `[BX+SI+idata]` | (BX) + (SI) + idata | DS |

**21.** 已知 `(DS)=1000H`，`(SS)=2000H`，`(BX)=100H`，`(BP)=100H`。分别写出以下指令访问的物理地址及段寄存器来源：
（1）`MOV AL, [BX]`  
（2）`MOV AL, [BP]`

> **答**：  
> （1）段地址来自 **DS** = 1000H。物理地址 = 1000H × 16 + 100H = **10100H**。  
> （2）段地址来自 **SS** = 2000H。物理地址 = 2000H × 16 + 100H = **20100H**。

**22.** 在 MASM 5.0 中，直接写 `MOV AL, [0]` 会被汇编器错误解析为什么？应如何修正？

> **答**：  
> 会被错误解析为 `MOV AL, 0`（将立即数 0 赋给 AL）。  
> 修正方法：显式添加段前缀，如 **`MOV AL, DS:[0]`**。

**23.** 指出下列指令中的错误并说明原因：
```asm
MOV [1000H], [2000H]      ; (1)
MOV DS, 1000H              ; (2)
MOV ES, DS                 ; (3)
MOV AL, 1234H              ; (4)
```

> **答**：  
> （1）**错误**：两个操作数都是内存操作数，8086 不允许直接内存到内存传送。需通过寄存器中转。  
> （2）**错误**：8086 不支持直接向段寄存器赋值立即数。需先赋给通用寄存器：`MOV AX, 1000H` → `MOV DS, AX`。  
> （3）**错误**：两个段寄存器之间不能直接传送。需通过通用寄存器中转：`MOV AX, DS` → `MOV ES, AX`。  
> （4）**错误**：操作数尺寸不匹配。AL 是 8 位，1234H 是 16 位。应改为 `MOV AX, 1234H`。

**24.** 已知数据段中有以下定义：
```asm
DATA SEGMENT
    ORG 100H
    VAR1 DB 10H, 20H, 30H
    VAR2 DW 4050H, 6070H
DATA ENDS
```

写出变量 `VAR1` 和 `VAR2` 的偏移地址，并画出内存中从 `VAR1` 开始各字节的存储内容。

> `VAR1` 偏移地址 = **0100H**（ORG 100H 指定了起始偏移）。

> 0105H: 70H   ← VAR2 低字节（6070H）
> 0106H: 60H   ← VAR2 高字节（6070H）
> ```

**25.** 执行以下指令后，`(AX)=`？`(BX)=`？`(CX)=`？
```asm
DATA SEGMENT
    ORG 200H
    ARR DB 10H, 20H, 30H, 40H
DATA ENDS
    LEA BX, ARR
    MOV AL, [BX]
    MOV AH, 0
    MOV CX, 3
L:  ADD AL, [BX+1]
    INC BX
    LOOP L
```

> **答**：  
> 初始：`BX = 200H`，`AL = [200H] = 10H`，`AH = 0`，`AX = 0010H`，`CX = 3`。
>
> 第 1 轮（CX=3）：`AL = 10H + [201H] = 10H + 20H = 30H`，`BX = 201H`。  
> 第 2 轮（CX=2）：`AL = 30H + [202H] = 30H + 30H = 60H`，`BX = 202H`。  
> 第 3 轮（CX=1）：`AL = 60H + [203H] = 60H + 40H = A0H`，`BX = 203H`。
>
> 结果：**`AX = 00A0H`**，**`BX = 0203H`**，**`CX = 0`**。

### （四）堆栈操作（第 27 ~ 32 题）

**27.** 8086 的栈操作以 \_\_\_\_（字节/字）为基本单位。栈的生成方向是向 \_\_\_\_（高地址/低地址）的。

> **答**：  
> 以 **字（Word，2 字节）** 为基本单位。栈向 **低地址** 方向生长。

---

**28.** 写出 PUSH 和 POP 指令的完整执行步骤。

> **答**：  
> **PUSH 入栈**：  
> 1. SP = SP - 2（栈向低地址生长）。  
> 2. 将 16 位数据写入 `SS:SP` 指向的字单元。
>
> **POP 出栈**：  
> 1. 读取 `SS:SP` 指向的 16 位数据到目标寄存器。  
> 2. SP = SP + 2（栈向高地址退回）。

---

**29.** 已知 `(SS)=2000H`，`(SP)=0010H`。画出执行以下指令过程中 `SP` 和栈顶内容的变化（每一步）：
```asm
MOV AX, 1234H
PUSH AX
MOV BX, 5678H
PUSH BX
POP CX
POP DX
```

> **答**：  
> | 步骤 | SP | 栈顶 `SS:SP` 处内容 | 说明 |
> |:---|:---|:---|:---|
> | 初始 | 0010H | — | 空栈 |
> | `PUSH AX` | 000EH | 1234H | SP 先减 2，再将 1234H 写入 `2000:000E` |
> | `PUSH BX` | 000CH | 5678H | SP 再减 2，将 5678H 写入 `2000:000C` |
> | `POP CX` | 000EH | 1234H | 先读 `2000:000C` 的 5678H → CX，SP 加 2 |
> | `POP DX` | 0010H | — | 先读 `2000:000E` 的 1234H → DX，SP 加 2 恢复 |
>
> 最终：**`CX = 5678H`**，**`DX = 1234H`**，**`SP = 0010H`**（恢复初始值）。

**30.** 下列指令序列执行后，`(AX)=`？`(SP)=`？
```asm
MOV AX, 1000H
MOV SS, AX
MOV SP, 10H
MOV AX, 1234H
PUSH AX
MOV BX, 5678H
PUSH BX
POP AX
POP BX
```

> **答**：  
> `PUSH AX` → `[1000:000E] = 1234H`，`SP = 000EH`。  
> `PUSH BX` → `[1000:000C] = 5678H`，`SP = 000CH`。  
> `POP AX` → `AX = [1000:000C] = 5678H`，`SP = 000EH`。  
> `POP BX` → `BX = [1000:000E] = 1234H`，`SP = 0010H`。
>
> 结果：**`AX = 5678H`**，**`SP = 0010H`**。

**31.** 8086 硬件是否提供栈超界保护？程序员必须如何避免栈溢出问题？

> **答**：  
> 8086 硬件**不提供栈超界保护机制**。程序员必须：  
> 1. 手动规划并分配足够的栈空间（使用 `DW n DUP(0)` 预留）。  
> 2. 确保 PUSH 和 POP 严格配对。  
> 3. 避免无限制递归调用。

---

**32.** 在子程序调用中，为什么需要在子程序开头 `PUSH` 用到的寄存器，结尾按相反顺序 `POP`？如果不这样做可能导致什么问题？

> **答**：  
> **原因**：子程序可能修改了主程序正在使用的寄存器，导致主程序在返回后数据错乱（**寄存器冲突**）。  
> **相反顺序**：栈是 LIFO（后进先出），入栈顺序为 A→B→C，出栈必须 C→B→A 才能还原。  
> **不保护的后果**：例如主程序用 `CX` 计数循环，子程序内部也使用 `CX` 且未保存，返回后主程序 `CX` 值可能被破坏，导致循环错误或死循环。

### （五）程序结构与伪指令（第 33 ~ 38 题）

**33.** 写出下列伪指令的作用：
（1）`SEGMENT` / `ENDS`  
（2）`END`  
（3）`ASSUME`  
（4）`DB` / `DW` / `DD`

> **答**：  
> （1）**`SEGMENT`**：标记一个段的开始。**`ENDS`**：标记对应段的结束。  
> （2）**`END`**：标记整个汇编程序的结束边界，编译器据此停止编译。`END start` 同时指明程序入口地址。  
> （3）**`ASSUME`**：告诉编译器将某个段寄存器与程序中定义的段建立关联（如 `ASSUME CS:CODE, DS:DATA`）。它是一种"编译器层面的假设"，CPU 不会自动加载段地址。  
> （4）**`DB`**：定义字节（1 字节），**`DW`**：定义字（2 字节），**`DD`**：定义双字（4 字节）。

**34.** 阅读下列程序，指出其中的错误（语法错误和逻辑错误）：
```asm

    DB 12H, 34H, 56H
    MOV AX, 0
    MOV CX, 3
    MOV BX, 0

    LOOP S
```

**64.** 从 `int n` 指令发出到 CPU 开始执行中断处理程序，CPU 自动完成了哪些步骤？（按顺序写出）

> **答**：  
> 1. 获取中断类型码 `n`。  
> 2. 标志寄存器（FLAGS）入栈保存。  
> 3. 清除 TF 和 IF 标志位（`TF = 0`，`IF = 0`）。  
> 4. 当前 `CS` 入栈，当前 `IP` 入栈。  
> 5. 从中断向量表中 `n×4` 处读取新的 `IP`，`n×4+2` 处读取新的 `CS`。  
> 6. `CS:IP` 指向中断处理程序入口，开始执行。

**65.** 中断处理程序必须以什么指令返回？它和普通的 `RET` 有什么区别？为什么不能用 `RET` 代替？

> **答**：  
> 必须以 **`IRET`** 指令返回。  
> 区别：  
> - `RET`（段内返回）只执行 `POP IP`。  
> - `RETF`（段间返回）执行 `POP IP` → `POP CS`。  
> - **`IRET`** 执行 `POP IP` → `POP CS` → **`POP FLAGS`**（恢复标志寄存器）。  
> 不能替代的原因：中断发生时 CPU 不仅压入了 CS 和 IP，还压入了 FLAGS（标志寄存器）。只有 `IRET` 能正确弹出 FLAGS，否则标志寄存器被破坏。

> | `POP CX` → CX=1 | — | 0010H |
> | `PUSH DX(4)` | 000EH: 0004H | 000EH |
>

```asm
CODE ENDS
```

### 第 24 题
**题**：编程实现冒泡排序：将数据段中 `N` 个无符号字节数据按升序排列。

**解**：
```asm
ASSUME CS:CODE, DS:DATA

DATA SEGMENT
    ARR DB 56, 23, 89, 12, 45, 78, 34, 91
    N DW 8
DATA ENDS

CODE SEGMENT
START:
    MOV AX, DATA
    MOV DS, AX

    MOV CX, N
    DEC CX          ; 外层循环 N-1 次
OUTER:
    PUSH CX
    LEA BX, ARR
INNER:
    MOV AL, [BX]
    CMP AL, [BX+1]
    JBE NO_SWAP     ; 无符号 ≤ 则不交换
    XCHG AL, [BX+1]
    MOV [BX], AL
NO_SWAP:
    INC BX
    LOOP INNER
    POP CX
    LOOP OUTER

    MOV AX, 4C00H
    INT 21H
CODE ENDS
END START
```

**题**：编写一个完整的 8086 汇编程序（使用标准多段结构），实现：将数据段中的两个字变量 `DIVIDEND_L`（低字）和 `DIVIDEND_H`（高字）构成的 32 位被除数除以 16 位除数 `DIVISOR`，商存入 `QUOTIENT`，余数存入 `REMAINDER`。

```asm
STACK ENDS
```

### 第 27 题
**题**：编写一个自定义的除法溢出中断处理程序（0 号中断），当发生除法溢出时，在屏幕中间显示红色字符串 `"DIVIDE ERROR!"`，然后安全返回 DOS。要求：在主程序中安装该中断处理程序，并测试触发除法溢出。

**解**：
```asm
ASSUME CS:CODE, DS:DATA, SS:STACK

DATA SEGMENT
    MSG DB 'DIVIDE ERROR!', '$'
DATA ENDS

STACK SEGMENT
    DW 64 DUP(0)
STACK ENDS

CODE SEGMENT
START:
    ; 初始化数据段
    MOV AX, DATA
    MOV DS, AX
    MOV AX, STACK
    MOV SS, AX
    MOV SP, 80H

    ; 安装 0 号中断处理程序
    MOV AX, CS
    MOV DS, AX
    MOV SI, OFFSET DIV0     ; 源：中断处理程序（在代码段中）
    MOV AX, 0
    MOV ES, AX
    MOV DI, 200H            ; 目的：0000:0200（安全空闲区）
    CLD
    MOV CX, OFFSET DIV0_END - OFFSET DIV0
    REP MOVSB

    ; 设置中断向量表：0 号中断 → 0000:0200
    MOV AX, 0
    MOV ES, AX
    MOV WORD PTR ES:[0*4], 200H     ; IP
    MOV WORD PTR ES:[0*4+2], 0      ; CS

    ; 恢复 DS
    MOV AX, DATA
    MOV DS, AX

    ; 测试触发除法溢出
    MOV AX, 1000
    MOV BL, 0
    DIV BL          ; 触发 0 号中断

    MOV AX, 4C00H
    INT 21H

; ===== 自定义 0 号中断处理程序 =====
DIV0:
    JMP SHORT DIV0_START
    ERRMSG DB 'DIVIDE ERROR!', '$'
DIV0_START:
    PUSH AX
    PUSH BX
    PUSH CX
    PUSH DX
    PUSH DS
    PUSH ES
    PUSH SI
    PUSH DI
    PUSH BP

    MOV AX, DATA
    MOV DS, AX
    MOV DX, OFFSET MSG
    MOV AH, 9
    INT 21H

    POP BP
    POP DI
    POP SI
    POP ES
    POP DS
    POP DX
    POP CX
    POP BX
    POP AX
    IRET            ; 中断返回（恢复 IP、CS、FLAGS）
DIV0_END:
    NOP

CODE ENDS
END START
```

### 第 28 题
**题**：编程实现：将从键盘输入的一串字符（以回车结束）存入缓冲区，然后将其中所有数字字符（'0'~'9'）提取出来，存入另一个缓冲区，并在末尾加上 `'$'` 后用 `INT 21H` 的 9 号功能显示。

**解**：
```asm
ASSUME CS:CODE, DS:DATA

DATA SEGMENT
    BUF DB 80               ; 输入缓冲区大小
    LEN DB ?                ; 实际输入长度
    STR DB 80 DUP('$')      ; 输入内容
    DIGITBUF DB 80 DUP(0)   ; 数字提取缓冲区
    PROMPT DB 'Please input a string: $'
    OUTPUT DB 0DH, 0AH, 'Digits found: $'
DATA ENDS

CODE SEGMENT
START:
    MOV AX, DATA
    MOV DS, AX

    ; 显示提示
    MOV DX, OFFSET PROMPT
    MOV AH, 9
    INT 21H

    ; 输入字符串
    MOV DX, OFFSET BUF
    MOV AH, 0AH
    INT 21H

    ; 提取数字字符
    LEA SI, STR
    LEA DI, DIGITBUF
    MOV CL, LEN
    MOV CH, 0
    JCXZ SHOW
L:  MOV AL, [SI]
    CMP AL, '0'
    JB SKIP
    CMP AL, '9'
    JA SKIP
    MOV [DI], AL
    INC DI
SKIP:
    INC SI
    LOOP L
    MOV BYTE PTR [DI], '$'

SHOW:
    ; 显示提取结果提示
    MOV DX, OFFSET OUTPUT
    MOV AH, 9
    INT 21H
    ; 显示提取出的数字
    MOV DX, OFFSET DIGITBUF
    MOV AH, 9
    INT 21H

    MOV AX, 4C00H
    INT 21H
CODE ENDS
END START
```
