### 一、 解析题（概念、计算与执行过程追踪）

**1. 【编译过程】**
在Linux平台下，使用GCC将C语言源程序（如`hello.c`）处理成可执行文件的过程分为四个步骤。请问这四个步骤分别是什么？生成汇编代码的是哪一步？
**【答案与解析】**
*   **答案**：预处理（Pre-processing）、编译（Compilation）、汇编（Assembly）、链接（Linking）。生成汇编代码的是**编译（Compilation）**阶段（使用`gcc -S`命令）。
*   **解析**：PPT第6页明确指出，预处理生成`.i`文件，编译生成`.s`汇编文件，汇编生成`.o`目标文件，链接生成可执行文件。

**2. 【架构与寻址】**
8086 CPU有多少根地址总线？它的物理内存寻址能力最大是多少？
**【答案与解析】**
*   **答案**：8086 CPU有20根地址总线。最大寻址能力为1MB（即$2^{20}$字节）。
*   **解析**：PPT第50页。8086内部寄存器是16位的（只能寻址64KB），为了寻址1MB空间，采用了20位地址总线，通过段基址和偏移地址组合来实现。

**3. 【物理地址计算】**
已知段寄存器 `DS = 2896H`，有效地址（偏移地址） `EA = 1655H`。请计算要访问的数据的物理地址。
**【答案与解析】**
*   **答案**：物理地址 = 29FB5H。
*   **解析**：PPT第55页。物理地址 = 段基址 × 16（即左移一位加0） + 偏移地址。计算过程：`28960H + 1655H = 29FB5H`。

**4. 【物理地址的逆向思考】**
某内存单元的物理地址为 `12340H`，如果已知段地址（段基址）为 `1230H`，此时的偏移地址是多少？如果偏移地址为 `0040H`，段地址又是多少？
**【答案与解析】**
*   **答案**：若段地址为`1230H`，偏移地址为`0040H`；若偏移地址为`0040H`，段地址为`1230H`。
*   **解析**：PPT第53页指出，同一个物理地址可以由不同的“段地址:偏移地址”组成。物理地址 = 段基址×10H + 偏移地址。`12300H + 0040H = 12340H`。

**5. 【小端模式（Little Endian）】**
如果在0地址处开始存放一个字型数据（Word，16位）为 `1234H`。请问在内存中，`0000H` 单元和 `0001H` 单元分别存放的数据是多少？
**【答案与解析】**
*   **答案**：`0000H`单元存放 `34H`，`0001H`单元存放 `12H`。
*   **解析**：PPT第83页讲述了“小端方式”：字的低位字节存放在低地址单元中，高位字节存放在高地址单元中。`1234H`的低位字节是`34H`，高位字节是`12H`。

**6. 【指令改错】**
请指出以下指令中的错误，并说明原因：
(1) `MOV DS, 1000H`
(2) `ADD DS, AX`
**【答案与解析】**
*   **答案与解析**：
    (1) **错误**。不能将立即数直接传送给段寄存器。必须借助通用寄存器中转，如：`MOV AX, 1000H` 然后 `MOV DS, AX`。（PPT第85页明确指出这是错的）。
    (2) **错误**。算术运算指令（如ADD, SUB）不能直接对段寄存器（如DS）进行操作。（PPT第91页指出，段寄存器不能参与ADD/SUB等操作）。

**7. 【启动状态】**
8086 PC机开机或复位后，CPU执行的第一条指令位于什么物理地址？此时的CS和IP分别是多少？
**【答案与解析】**
*   **答案**：物理地址为 `FFFF0H`。此时 `CS = FFFFH`，`IP = 0000H`。
*   **解析**：PPT第60页。开机时，CS被强制初始化为FFFFH，IP为0000H。物理地址计算：FFFF0H + 0000H = FFFF0H。这也是BIOS启动代码的入口。

**8. 【数据段寻址】**
如果需要累加数据段 `123B0H ~ 123BAH` 中的前3个“字型（Word）”数据，请问这三个字型数据所在的内存偏移地址分别是多少？（假设段基址为 `123B0H`）
**【答案与解析】**
*   **答案**：偏移地址分别为 `0`、`2`、`4`。
*   **解析**：PPT第92页。一个字型数据占两个字节（两个内存单元）。因此第一个字在偏移0和1，第二个字在偏移2和3，第三个字在偏移4和5。所以起始偏移地址分别是0、2、4。

**9. 【栈的指针与方向】**
8086 CPU中，哪个寄存器组合用于指向栈顶？栈的生长方向是向高地址生长还是向低地址生长？
**【答案与解析】**
*   **答案**：`SS:SP` 指向栈顶。栈是**向低地址**生长的。
*   **解析**：PPT第95页。栈是一种后进先出（LIFO）的存储区，入栈（PUSH）时，SP=SP-2，即指针从高地址向低地址移动。

**10. 【PUSH指令执行过程】**
请详细描述执行指令 `PUSH AX` 时，CPU内部发生的两步主要操作。
**【答案与解析】**
*   **答案**：
    (1) `SP = SP - 2`；
    (2) 将 `AX` 中的内容送入 `SS:SP` 指向的内存单元处。
*   **解析**：PPT第99页。由于8086的入栈操作以“字”为单位，且栈向低地址生长，所以先减2腾出空间，再将16位数据写入。

**11. 【栈的状态分析】**
初始状态下，设栈空时，栈段寄存器 `SS = 1000H`，如果栈空间分配的最高地址为 `1000FH`，那么栈空时 `SP` 的初始值应该设置为多少？
**【答案与解析】**
*   **答案**：`SP = 0010H`。
*   **解析**：PPT第100页。栈空时，SP指向栈空间最高地址的**下一个单元**。最高地址是1000F，下一个单元就是1000FH + 1 = 10010H。此时相对于段基址1000H的偏移量即为0010H。

**12. 【程序执行过程追踪 1】**
假定内存中相应单元的内容如下，写出下面指令执行后寄存器AX、BX、CX的值。（参考PPT第89页）
执行前内存状态：`10000H`处存放23，`10001H`处存放11，`10002H`处存放22，`10003H`处存放11。
```assembly
mov ax, 1000H
mov ds, ax
mov ax, 11316  ; 注：11316是十进制，转换为十六进制是 2C34H
mov [0], ax
mov bx, [0]
sub bx, [2]
mov [2], bx
```
**【答案与解析】**
*   **最终结果**：`AX = 2C34H`, `BX = 1B12H`。
*   **解析**（同PPT第90页）：
    *   `mov ax, 1000H; mov ds, ax`：设置数据段基址为1000H。
    *   `mov ax, 11316`：十进制11316 = `2C34H`，此时 `ax = 2C34H`。
    *   `mov [0], ax`：将 `2C34H` 存入 `1000:0` 处。因为是小端模式，`10000H`存放`34H`，`10001H`存放`2CH`。
    *   `mov bx, [0]`：将 `1000:0` 处的字读入bx，此时 `bx = 2C34H`。
    *   `sub bx, [2]`：将 `1000:2` 处的字（即`1122H`）从bx中减去。`2C34H - 1122H = 1B12H`。此时 `bx = 1B12H`。
    *   `mov [2], bx`：将结果写入 `1000:2` 处。

**13. 【保护模式：分段机制】**
在保护模式下，逻辑地址转换为物理地址的过程中，GDTR寄存器存放的是什么？段选择子（Segment Selector）包含哪三部分内容？
**【答案与解析】**
*   **答案**：`GDTR`寄存器存放的是全局描述符表（GDT）在物理内存中的基地址和表长度（界限）。段选择子包含13位的索引号（Index）、1位的表指示符（TI，0代表GDT，1代表LDT）和2位的请求特权级（RPL）。
*   **解析**：PPT第66-67页。段选择子通过GDTR找到GDT，加上索引找到段描述符，从而获取段基址。

**14. 【保护模式：段描述符】**
保护模式的段描述符（Descriptor）中，G标志位（粒度位）的作用是什么？如果G=1，段限长的单位是什么？
**【答案与解析】**
*   **答案**：G标志位用于确定段限长（Limit）的单位。如果 `G = 1`，段长度的单位为4KB；如果 `G = 0`，单位为1字节。
*   **解析**：PPT第70页。当G=1时，20位的段限长最大可以表示 $2^{20} \times 4KB = 4GB$ 的空间。

**15. 【保护模式：分页机制】**
在32位x86保护模式下，如果开启了分页机制，标准的页大小是多少？CR3寄存器的作用是什么？
**【答案与解析】**
*   **答案**：标准页大小为 **4KB**。`CR3`寄存器（又称页目录基址寄存器 PDBR）存放的是**页目录表（Page Directory）的物理基地址**。
*   **解析**：PPT第71-73页。线性地址转换物理地址时，先从CR3获取页目录基址，然后利用线性地址的前10位作为索引查找页目录项。

**16. 【三级地址概念辨析】**
在x86架构中，存在逻辑地址、线性地址和物理地址。请简述这三者的关系和转换流程。
**【答案与解析】**
*   **答案**：
    逻辑地址（形式为 段寄存器:偏移量）经过 **分段机制（Segment Mechanism）** 转换后得到 线性地址。
    线性地址如果开启了 **分页机制（Paging Mechanism）**，则经过页表转换得到 物理地址（如果不开启分页，线性地址直接就是物理地址）。
    物理地址是最终发送到物理内存芯片地址总线上的真实地址。
*   **解析**：PPT第75-78页详细总结了这三种地址的转换流程图。

**17. 【栈顶超界危险】**
为什么说“栈顶超界”是危险的？8086 CPU在硬件层面是否保证了对栈的操作不会超界？
**【答案与解析】**
*   **答案**：栈顶超界是危险的，因为当栈满时继续PUSH（上溢），或者栈空时继续POP（下溢），会覆盖栈空间以外的其他内存数据，这可能导致其他程序的数据或代码被破坏。8086 CPU **不保证** 对栈的操作不会超界。
*   **解析**：PPT第102-103页。8086CPU只根据SS:SP的值进行PUSH和POP，程序员必须自己操心栈顶超界的问题。

**18. 【指令执行结果分析 2】**
假设 `AX = 001AH`, `BX = 0026H`。执行以下指令后，指出各寄存器的值：（参考PPT第47页）
`add al, bl` -> `AX` 的值变为多少？
`add ah, bl` -> `AX` 的值变为多少？
`add bh, al` -> `BX` 的值变为多少？
**【答案与解析】**
*   **答案**：
    `add al, bl`：`1AH + 26H = 40H`，`AX = 0040H`。
    `add ah, bl`：`00H + 26H = 26H`，`AX = 2640H`。
    `add bh, al`：`00H + 40H = 40H`，`BX = 4026H`。
*   **解析**：这是对8位寄存器独立操作的考察。AL和BL的加法不会影响AH，即便产生进位也是存入标志寄存器（CF）而不是直接进位到AH。

**19. 【存储单位换算】**
1MB、1GB分别等于多少字节（Byte）？（用2的幂次方表示）
**【答案与解析】**
*   **答案**：$1MB = 2^{20} Bytes$，$1GB = 2^{30} Bytes$。
*   **解析**：PPT第48页。$1KB = 1024B = 2^{10}B$，依此类推。

**20. 【CS和IP的修改】**
能否使用 `MOV CS, AX` 或 `MOV IP, BX` 这样的指令来修改CS和IP的值？如果不可以，应该用什么指令？
**【答案与解析】**
*   **答案**：**不可以**。8086没有提供对CS和IP直接使用MOV指令进行修改的功能。必须使用转移指令（如 `JMP`、`CALL`、`RET`等）来同时或单独修改CS和IP。
*   **解析**：PPT第61页明确强调了修改CS和IP的值应该使用 `JMP` 指令。例如 `jmp 段地址:偏移地址` 修改CS和IP；`jmp 寄存器` 仅修改IP。

**21. 【程序填空：使用MOV指令访问内存】**
我们需要将 `10000H` 处的数据读入到 `al` 寄存器中，请补全下面的汇编代码。
```assembly
mov bx, ________  ; (1)
mov ds, ________  ; (2)

```
**【答案与解析】**

    (1) `1000H`

*   **解析**：PPT第86页。首先将段地址1000H放入通用寄存器BX，然后转入段寄存器DS。此时DS:0就指向物理地址10000H。通过 `mov al, [0]` 完成读取。

**22. 【程序改写：利用栈交换数据】**
假设 `AX = 002AH`，`BX = 002BH`。要求在不使用其他通用寄存器（如CX, DX等）作为中间变量的情况下，仅仅利用栈来交换AX和BX中的数据。请写出完成此功能的汇编指令片段。
**【答案与解析】**
*   **答案**：
    ```assembly
    push ax
    push bx
    pop ax
    pop bx
    ```
*   **解析**：PPT第107页习题原题。栈是“后进先出”结构。先压入AX，再压入BX。弹栈时，先弹出栈顶元素（原BX的数据）放入AX，再弹出次栈顶元素（原AX的数据）放入BX，从而实现交换。出栈顺序与入栈顺序**相反**。

**23. 【编程题：初始化栈空间】**
请编写一段汇编指令，将 `10000H ~ 1000FH` 这段16字节的内存空间当作栈来使用，并且初始化为空栈状态。
**【答案与解析】**
*   **答案**：
    ```assembly
    mov ax, 1000H
    mov ss, ax
    mov sp, 0010H
    ```
*   **解析**：PPT第106页/108页。设置栈段基址：将1000H给SS。栈顶指针初始化：由于分配的栈空间最高地址是1000FH，栈空时SP指向最高地址的下一个单元，即偏移量0010H。

**24. 【程序阅读与堆栈分析】**
阅读如下代码，回答问题：
```assembly
mov ax, 1000H
mov ss, ax
mov sp, 0010H
mov ax, 001AH
mov bx, 001BH
push ax
push bx
sub ax, ax
sub bx, bx
pop bx
pop ax
```
问题：
(1) `sub ax, ax` 的作用是什么？
(2) 程序执行完毕后，`AX` 和 `BX` 的值分别是多少？
**【答案与解析】**
*   **答案**：
    (1) 将AX清零（等同于 mov ax, 0）。
    (2) `AX = 001AH`，`BX = 001BH`。
*   **解析**：PPT第106页。程序先将001AH压栈，再将001BH压栈。随后清空寄存器。接着先 `pop bx`，将后压入的001BH弹出给BX；再 `pop ax`，将先压入的001AH弹出给AX。此过程演示了入栈和出栈操作，结果不仅恢复了数据，而且没有改变AX和BX原来的对应值（注意这里入栈顺序和出栈顺序是对称的）。

**25. 【综合编程：累加字型数据】**
现有两个字型数据，分别存放在数据段偏移地址为 `0` 和 `2` 的内存单元中。请编写汇编代码片段，计算这两个数据的和，并将结果保存在偏移地址为 `4` 的内存单元中。（假设段地址已正确设置在 DS 中）。
**【答案与解析】**
*   **答案**：
    ```assembly
    mov ax, [0]     ; 取第一个字到AX
    add ax, [2]     ; 将第二个字加到AX中
    mov [4], ax     ; 将结果AX存入偏移地址为4的单元
    ```
*   **解析**：综合考察了内存读写 `MOV` 指令与加法 `ADD` 指令的搭配。注意16位字型数据每次占用2个字节，因此地址分别是 `[0]`, `[2]`, `[4]`，刚好对应连续的三个字型存储空间。这与PPT第92页“累加数据段中的前3个字型数据”的思想一脉相承。

**27. 【程序追踪：栈的指针变化】**
假设初始 `SS=1000H`, `SP=000EH`。执行以下两条指令后，SP的值变为多少？
```assembly
push ax
push bx
```
**【答案与解析】**
*   **答案**：`SP = 000AH`。
*   **解析**：PPT第99页。执行一次 `push` 操作，SP减2。初始 `000EH`，执行 `push ax` 后变为 `000CH`，执行 `push bx` 后再减2，变为 `000AH`。

**28. 【代码结构分析】**
PPT给出了一个典型的8086汇编程序结构（例1.1，Hello world示例），在伪指令 `ASSUME CS:CODES, DS:DATAS` 中，它的作用是什么？
**【答案与解析】**
*   **答案**：它的作用是告诉编译器（汇编器），将 `CODES` 段与 `CS` 寄存器关联起来，将 `DATAS` 段与 `DS` 寄存器关联起来。
