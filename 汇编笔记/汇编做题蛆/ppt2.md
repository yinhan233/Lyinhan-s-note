# 8086汇编语言测试卷（基于PPT 1-56页）

## 一、 解析与分析题（共17题）

**1. 【概念解析】在汇编语言源程序中，有两类指令：汇编指令和伪指令。请简述它们的主要区别，并列举PPT中提到的至少三个伪指令。**
*   **答案与解析：**
    *   **区别：** 汇编指令有对应的机器码，最终由CPU执行；伪指令没有对应的机器码，它们是用来指示编译器如何工作的指令，由编译器在编译时处理，CPU并不执行。
    *   **例子：** `segment`、`ends`、`end`、`assume`。

**2. 【程序结构】`ends` 和 `end` 这两个伪指令长得很像，它们的作用分别是什么？能不能混用？**
*   **答案与解析：** 不能混用。
    *   `ends` 是和 `segment` 成对使用的，用来标记**一个段**的结束（End Segment）。
    *   `end` 是一个汇编程序的**结束标记**，通知编译器整个源代码文件结束。此外，`end` 后面还可以接标号（如 `end start`），用来指明程序的入口地址。

**3. 【程序返回】在DOS系统中，一个单任务程序运行结束后，需要将CPU的控制权交还给什么程序？在代码的末尾需要添加哪两条指令来实现这一过程？**
*   **答案与解析：** 需要交还给DOS的命令解释器（通常是 `command.com`，即系统的shell）。
    *   需要的指令是：
        `mov ax, 4c00h`
        `int 21h`

**4. 【内存加载原理】（分析题）假设Debug将一个程序加载入内存后，查看到 `DS = 129E`。请问：**
**(1) 该程序的PSP（程序段前缀）的段地址和偏移地址是多少？物理地址是多少？**
**(2) 该程序真正代码所在的段地址是多少？（假设代码段紧接着PSP存放）**
*   **答案与解析：**
    *   (1) 程序加载后，DS中存放着程序所在内存区的段地址，但这个内存区的前256个字节（100H）存放的是PSP。所以PSP的段地址是 `129E`，偏移地址是 `0`。物理地址为 `129E * 10H + 0 = 129E0H`。
    *   (2) 因为PSP占256个字节（即 `100H` = `10H * 16`），所以代码的实际物理地址是 `129E0H + 100H = 12AE0H`。转换成段地址就是 `129E + 10H = 12AE`。因此代码的段地址 CS = `12AE`。

**5. 【Debug调试】在使用Debug单步调试包含 `int 21h` 的程序时，当执行到 `int 21h` 指令时，应该使用 `T` 命令还是 `P` 命令？为什么？**
*   **答案与解析：** 应该使用 `P` 命令。如果使用 `T`（Trace）命令，会单步进入DOS操作系统的中断处理子程序内部，导致无法正常退出或迷失在系统代码中；使用 `P`（Proceed）命令可以直接执行完该中断调用，显示 "Program terminated normally"，然后返回Debug。

**6. 【循环指令】执行 `loop s` 指令时，CPU在内部会进行哪两步具体的操作？**
*   **答案与解析：**
    *   第一步：将 `cx` 寄存器中的值减1，即 `(cx) = (cx) - 1`。
    *   第二步：判断 `cx` 中的值。如果不为零，则转移到标号 `s` 处继续执行；如果为零，则向下执行 `loop` 后面的下一条指令。

**7. 【代码分析】阅读下列汇编代码，指出程序执行完毕后，`ax` 寄存器中的值是多少？（写出计算过程）**
```assembly
mov ax, 2
mov cx, 3
s: add ax, ax
loop s
```
*   **答案与解析：** `ax` 的最终值为 `16` (或 10H)。
    *   初始：`ax = 2`, `cx = 3`
    *   第1次循环：`add ax, ax` -> `ax = 4`。`loop` 使 `cx=2`，继续。
    *   第2次循环：`add ax, ax` -> `ax = 8`。`loop` 使 `cx=1`，继续。
    *   第3次循环：`add ax, ax` -> `ax = 16`。`loop` 使 `cx=0`，循环结束。
    *   本质是计算 $2 \times 2^3 = 16$。

**8. 【编译器差异】在Debug中直接汇编输入 `mov ax, [0]` 和在源程序（被MASM编译）中写入 `mov ax, [0]`，它们的结果一样吗？如果不一致，MASM会把它当成什么指令？在MASM中正确的写法是什么？**
*   **答案与解析：** 不一样。
    *   在Debug中，`mov ax, [0]` 表示将 `DS:0` 内存单元的数据送入 `ax`。
    *   在MASM编译器中，它会将 `mov ax, [0]` 当作普通的立即数传送指令，即等同于 `mov ax, 0`。
    *   在MASM中如果想要表示内存单元，必须加上段前缀，即显式地写为 `mov ax, ds:[0]`，或者将偏移地址放入 `bx` 中再访问：`mov bx, 0` -> `mov ax, [bx]`。

**9. 【数据溢出处理】（填空题）如果我们要计算内存单元中一系列8位字节数据的和，结果存放在16位寄存器 `dx` 中。为了防止类型不匹配（8位加16位），我们需要用一个16位寄存器（如 `ax`）作为中转。请补全以下核心逻辑：**
```assembly
mov al, ds:[bx]   ; 取出一个8位数据
mov ah, ___       ; 【空1】处理数据长度问题
add dx, ___       ; 【空2】累加
```
*   **答案与解析：**
    *   【空1】`0` （将 `ah` 置零，使得 `ax` 寄存器整体的值就等于被取出的那个字节的值，相当于把8位无符号数扩展成16位无符号数）。
    *   【空2】`ax` （将扩展后的16位数据累加到 `dx` 中）。

**10. 【段前缀】PPT中提到了段前缀的概念，请列举出至少4个可以作为段前缀的寄存器名称。**
*   **答案与解析：** `ds:` (数据段)、`cs:` (代码段)、`ss:` (栈段)、`es:` (附加段)。

**11. 【安全空间】在8086模式下（如DOS中），随意向一段内存空间写入内容是很危险的。在一般的PC机中，哪一段内存空间是DOS和其他合法程序通常不会使用的“相对安全的空间”？容量是多少字节？**
*   **答案与解析：** 安全空间是 `0:200h ~ 0:2FFh`。容量是 `256` 个字节（100H）。

**12. 【多段程序入门】为什么要将数据、栈和代码放入不同的段中？只放在一个代码段有什么不好？**
*   **答案与解析：** （PPT第49页）如果将数据、栈和代码都放在一个段里面，会使得程序显得混乱；更重要的是，8086模式下有段大小的限制，处理的数据很多时，如果总空间超过64KB，就不能放在一个段中了。

**13. 【程序入口】（填空与分析）看下面的代码框架，如果去掉了 `end start` 中的 `start`（仅保留 `end`），程序还能通过编译吗？加载到内存后，CPU会发生什么错误？**
```assembly
assume cs:code
code segment
    dw 0123h, 0456h  ; 数据区
start: 
    mov bx, 0        ; 代码区
    mov cx, 2
code ends
end start
```
*   **答案与解析：** 能通过编译。但是，如果不加 `start` 指定程序的入口地址，程序被加载到内存后，CS:IP 默认会指向代码段的最开头。而代码段的开头是用 `dw` 定义的**数据**（`0123h`等），CPU会错误地把这些数据当做机器指令去解码和执行，导致不可预知的崩溃或死机。

**14. 【栈段设置】要使得一段内存被CPU当作栈来使用，必须通过指令显式地设置哪两个寄存器？**
*   **答案与解析：** 必须设置 `SS`（栈段寄存器，Stack Segment）和 `SP`（栈指针寄存器，Stack Pointer）。

**15. 【综合运行追踪】给出以下程序，假设 `data` 段被加载到的段地址为 `1000H`。请问循环结束后，内存单元 `1000:0000` 到 `1000:0003` 中的数据分别变成了什么？**
```assembly
assume cs:code, ds:data
data segment
    db 1, 2, 3, 4
data ends

code segment
start:
    mov ax, data
    mov ds, ax
    mov bx, 0
    mov cx, 4
s:  inc byte ptr [bx]   ; inc指令：加1
    inc bx
    loop s
  
    mov ax, 4c00h
    int 21h
code ends
end start
```
*   **答案与解析：** 数据变成了 `2, 3, 4, 5`。
    解析：这是一个遍历字节数组并将其加1的循环。`db 1, 2, 3, 4` 定义了4个字节。`inc byte ptr [bx]` 表示将 `ds:[bx]` 指向的一个字节加1。循环4次，分别把这4个字节的值都加了1。

**16. 【堆栈与多段操作】（填空题）如果定义了一个栈段，大小为16个字节，请填空完成栈的初始化：**
```assembly
stack segment
    dw 0,0,0,0,0,0,0,0  ; 定义16个字节空间
stack ends
code segment
start:
    mov ax, stack
    mov ss, ax
    mov sp, _____     ; 【填空】
...
```
*   **答案与解析：** `16` 或 `10H`。
    解析：栈是从高地址向低地址生长的。申请了16个字节的栈段，栈空时，栈顶指针 `SP` 应该指向栈底的下一个内存单元的位置，即 16。

**17. 【ASCII显示】（扩展分析）PPT末尾的综合练习中提到，要在屏幕上显示一个数字字符（比如显示数字'2'），不能直接 `mov dl, 2` 然后调用中断，而需要加上一个数值。这个数值是多少？为什么？**
*   **答案与解析：** 需要加上 `48`（或 `30H`）。
    解析：因为计算机屏幕显示的是ASCII码字符。数字 `0` 的ASCII码是48（`30H`），数字 `1` 是49，以此类推。要打印数字的字符，必须将其真实数值加上48转换为对应的ASCII码，再送入 `dl` 寄存器并通过 `int 21h` (AH=02h) 输出。

## 二、 编程与综合题（共8题）

**18. 【基础编程 - Loop与[bx]】请编写完整的汇编程序：计算连续计算自然数 1+2+3+...+10 的和，并将结果保存在 `ax` 寄存器中。（不考虑在屏幕显示）**
*   **答案与解析：**
```assembly
assume cs:code
code segment
start:
    mov ax, 0       ; ax用来存放累加和，初始为0
    mov bx, 1       ; bx作为被加数，初始为1
    mov cx, 10      ; 循环次数10次
s:  add ax, bx      ; 累加
    inc bx          ; bx变成下一个自然数
    loop s          ; cx减1，不为0则继续跳到s
  
    mov ax, 4c00h   ; 退出程序
    int 21h
code ends
end start
```
*解析：利用 `cx` 控制次数，`bx` 作为递增的自然数，`ax` 用于保存结果。*

**19. 【安全空间清零】请编写完整的汇编程序：使用 `loop` 指令，将 DOS 安全空间 `0:200H ~ 0:2FFH`（共256个字节）全部清零。**
*   **答案与解析：**
```assembly
assume cs:code
code segment
start:
    mov ax, 0
    mov ds, ax      ; ds = 0
    mov bx, 200h    ; bx = 0200h, 起始偏移地址
  
    mov cx, 256     ; 循环256次 (0:200 ~ 0:2FF 共256个字节)
  
s:  mov byte ptr ds:[bx], 0  ; 将内存单元置0 (使用byte ptr明确是字节操作)
    inc bx          ; 偏移地址自增1
    loop s
  
    mov ax, 4c00h
    int 21h
code ends
end start
```
*解析：重点在于设置正确的段地址（0）和偏移地址基址（200h），以及正确的循环次数（256次），注意对内存进行字节级操作。*

**20. 【段前缀使用 - 数据拷贝】（综合应用）请编写程序：将内存 `ffff:0 ~ ffff:b` 段中的数据（共12个字节）拷贝到目标单元 `0020:0 ~ 0020:b` 中。**
*(提示：使用两个段寄存器 `ds` 和 `es` 分别指向源段和目标段，以提高效率，这是PPT中第40页推荐的做法)*
*   **答案与解析：**
```assembly
assume cs:code
code segment
start:
    mov ax, 0ffffh
    mov ds, ax      ; ds 指向源数据段 ffffH
    mov ax, 0020h
    mov es, ax      ; es 指向目标数据段 0020H
  
    mov bx, 0       ; 偏移地址从0开始
    mov cx, 12      ; 拷贝12个字节，循环12次
  
s:  mov dl, ds:[bx] ; 从 ffff:bx 取出一个字节
    mov es:[bx], dl ; 放入 0020:bx 中
    inc bx          ; bx加1，指向下一个字节
    loop s
  
    mov ax, 4c00h
    int 21h
code ends
end start
```
*解析：内存到内存不能直接通过一条 `mov` 指令完成，必须经过寄存器（如 `dl`）中转。利用 `es` 段超越前缀可以免去在循环内部频繁切换 `ds` 值的麻烦。*

**21. 【逆序存放数据】（基于栈特性）在代码段中定义了8个字型数据（16位）。请编写程序，利用栈的“先进后出”特性，将这8个字型数据逆序重新存放到它们原来的内存位置中。**
```assembly
assume cs:code
code segment
    dw 0123h, 0456h, 0789h, 0abch, 0defh, 0fedh, 0cbah, 0987h
    dw 0,0,0,0,0,0,0,0 ; 提供16字节的栈空间
start:
    ; 请补全代码
```
*   **答案与解析：**
```assembly
assume cs:code
code segment
    ; 8个字数据占16字节，偏移地址 0~15
    dw 0123h, 0456h, 0789h, 0abch, 0defh, 0fedh, 0cbah, 0987h
    ; 定义栈空间，占16字节，偏移地址 16~31
    dw 0,0,0,0,0,0,0,0 

start:
    mov ax, cs
    mov ss, ax
    mov sp, 32      ; 栈顶指向分配的栈空间的最高地址+1，即32

    mov ax, cs
    mov ds, ax      ; ds也指向代码段，为了读取数据
    mov bx, 0
    mov cx, 8       ; 共有8个字，循环8次入栈

s1: push ds:[bx]    ; 按顺序入栈
    add bx, 2       ; 字数据占2字节，所以bx加2
    loop s1

    mov bx, 0       ; 重置bx
    mov cx, 8       ; 循环8次出栈
  
s2: pop ds:[bx]     ; 出栈放回原处，由于栈先进后出，先出来的是最后一个数
    add bx, 2
    loop s2

    mov ax, 4c00h
    int 21h
code ends
end start
```
*解析：考察对代码段内数据地址的计算，以及 `push` 和 `pop` 操作。因为 `CS` 中包含了数据和栈，所以 `SS` 和 `DS` 都要指向 `CS`。*

**23. 【综合算法：找最大值并输出】（进阶挑战，源自PPT第55页实验）在 `data` 段中定义了一组无序的数字（0-9之间），请编写完整的程序，找出其中的最大数，将其转换为对应的字符，并使用中断输出到屏幕上。**
```assembly
datas segment
    db 2, 5, 4, 7, 0, 8, 1, 3, 9, 6
datas ends
```
*   **答案与解析：**
```assembly
assume cs:code, ds:datas
datas segment
    db 2, 5, 4, 7, 0, 8, 1, 3, 9, 6
datas ends

code segment
start: 
    mov ax, datas
    mov ds, ax
    mov bx, 0
    mov cx, 10      ; 数组长度为10
  
    mov al, 0       ; 用al存放当前找到的最大数，初始设为0

L1: cmp al, ds:[bx] ; 将当前最大数与内存中的数比较
    jnb next        ; 如果al不小于(大于等于)内存中的数，跳过更新跳转到next
    mov al, ds:[bx] ; 否则（al较小），更新最大数到al
next: 
    inc bx
    loop L1         ; 循环10次
  
    ; 此时最大值存放在 al 中
    add al, 48      ; 或者 add al, 30h。将数字(如9)转化为ASCII码字符('9')
    mov dl, al      ; int 21h的02h号功能要求要输出的字符放在dl中
    mov ah, 02h
    int 21h         ; 调用DOS中断打印字符
  
    mov ax, 4c00h
    int 21h
code ends
end start
```
*解析：综合考察了段初始化、循环遍历、`cmp`与条件转移指令（虽然PPT中只是一闪而过但流程图明确要求判断）、ASCII码转换，以及DOS的屏幕输出中断（`ah=02h`）。*

**24. 【指令长度与地址偏移计算】阅读下面的代码：**
```assembly
assume cs:abc
abc segment
    mov ax, 2     ; 机器码：B8 02 00 (占3字节)
    add ax, ax    ; 机器码：03 C0    (占2字节)
    add ax, ax    ; 机器码：03 C0    (占2字节)
    mov ax, 4c00h ; 机器码：B8 00 4C (占3字节)
    int 21h       ; 机器码：CD 21    (占2字节)
abc ends
end
```
**请问该程序被编译后，代码段的总长度（cx中存放的程序长度）是多少个字节？`int 21h` 这条指令的首地址偏移量（IP值）是多少？**
*   **答案与解析：**
    *   **总长度：** 3 + 2 + 2 + 3 + 2 = **12** 个字节。当Debug加载程序时，`cx` 的值就是 `000C` (十进制12)。
    *   **`int 21h` 偏移量：** 前面的指令共占用了 3 + 2 + 2 + 3 = 10 个字节（偏移量 0 到 9）。因此 `int 21h` 的首地址偏移量（IP）为 **000A**（即十进制的10）。

**25. 【易错辨析】某同学在编写程序时，打算将偏移地址 `0` 处的**字节**数据送入 `ax` 寄存器中，他写了如下代码：`mov ax, ds:[0]`。请指出他的错误，并给出两种修改方案（要么改目标，要么改数据）。**
*   **答案与解析：**
    *   **错误分析：** 类型不匹配。`ax` 是一个 16 位（字型）寄存器，而意图获取的是一个字节（8位）数据。`mov ax, ds:[0]` 实际上会一次性读取 `ds:0` 和 `ds:1` 两个字节的数据拼成一个字放入 `ax` 中，这违背了程序员“只取一个字节”的初衷。
    *   **修改方案一（修改目标寄存器）：** 将目标改为8位寄存器 `al` 或 `ah`。例如：`mov al, ds:[0]`。
    *   **修改方案二（修改操作数指示）：** 明确指定源操作数为字节属性，并赋给低位，高位清零（如果目的是放进ax）：
        ```assembly
        mov al, ds:[0]
        mov ah, 0
        ```
    *(注：汇编语言中类型匹配是非常严格的，这也是PPT中特别强调“处理数据长度问题”的原因)*
