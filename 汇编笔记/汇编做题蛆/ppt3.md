**1. 【执行过程分析】**
已知 `AL` 寄存器中的值为 `'a'` (ASCII码为 61H，即 01100001B)。
执行指令 `and al, 11011111B` 后，`AL` 中的值变为多少？对应的字符是什么？
**答案与解析：**
*   **答案**：`AL` = 41H (01000001B)，对应字符为 `'A'`。
*   **解析**：PPT第9页指出，小写字母ASCII码的第5位（从0开始算）为1，大写字母为0。`and` 指令按位与，`11011111B` 的第5位是0，其他位是1。这会将 `al` 的第5位强制置0，其他位不变，从而实现小写转大写。

**2. 【寻址方式推导】**
已知 `(DS)=2000H`, `(BX)=1000H`。执行指令 `mov ax, [bx+200]` 时，CPU访问的物理内存地址是多少？
**答案与解析：**
*   **答案**：21200H (或直接写公式 2000H * 10H + 1000H + 00C8H，但注意200是十进制，转换为十六进制是C8H)。
*   **解析**：PPT第11页说明 `[bx+idata]` 的数学描述为 `(EA) = (bx) + idata`，物理地址 = `(ds)*16 + (bx) + idata`。物理地址 = 20000H + 1000H + C8H(十进制200) = 210C8H。*(注：若题目中的200指200H，则为21200H，通常汇编默认不带H为十进制)*。

**3. 【指令等价替换】**

**4. 【寄存器使用限制】**

*   **解析**：PPT第48页明确强调，只有这4个寄存器能用于中括号寻址，并且指出了 `bp` 默认与 `ss` 配合。

**5. 【指令纠错】**

`mov [bx], 1`
**答案与解析：**
*   **答案**：有错误。由于1是一个常数，CPU无法判断是要传送一个字节（byte）还是一个字（word）到内存中。

**25. 【短转移原理计算】**
已知当前指令 `jmp short s` 的第一字节机器码所在物理地址对应的IP为 `0003H`。`jmp short` 指令长2字节。标号 `s` 处的指令IP为 `0009H`。
问：该转移指令机器码的第二个字节（即位移量）应该是多少？
**答案与解析：**
*   **答案**：位移量 = `04H`。
*   **解析**：参考PPT第71页公式。执行 `jmp short s` 时，`(IP) = (IP) + 位移`。注意，这里的 `(IP)` 是**指令读取完后**的IP值，即下一条指令的地址。`jmp short` 长2字节，读取完后 `IP = 0003H + 2 = 0005H`。
目标 `IP = 0009H`。
位移量 = 目标IP - 当前IP = `0009H - 0005H = 04H`。

请简述 `jmp short ptr 标号` 和 `jmp near ptr 标号` 的异同点。（参考PPT第75, 82页）
**答案与解析：**
*   **相同点**：都是段内转移（只修改 IP，不修改 CS）；机器码中包含的都是转移的**位移量**，而不是目标的绝对地址；位移量都是由编译器在编译时计算出来的。
*   **不同点**：`jmp short`（短转移）提供的是 8 位位移量，修改范围是 -128 到 127。`jmp near ptr`（近转移）提供的是 16 位位移量，修改范围是 -32768 到 32767。
