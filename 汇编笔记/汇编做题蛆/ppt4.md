# 汇编语言测试题（基于第10章与第11章）

## 第一部分：解析题（共22题）
**考察代码追踪、寄存器变化、指令原理与程序填空**

**1. `ret` 与 `retf` 指令的本质是什么？请写出它们执行时等价的寄存器操作。**
> **【答案与解析】**
> *   `ret` 指令实现**近转移**。它用栈中的数据修改IP。
>     等价操作：`(IP) = ((ss)*16 + (sp))`，`(sp) = (sp) + 2`。等同于 `pop IP`。
> *   `retf` 指令实现**远转移**。它用栈中的数据修改CS和IP。
>     等价操作：先出栈IP：`(IP) = ((ss)*16 + (sp))`，`(sp) = (sp) + 2`；后出栈CS：`(CS) = ((ss)*16 + (sp))`，`(sp) = (sp) + 2`。等同于 `pop IP`，然后 `pop CS`。*(参考PPT P3)*

**2. 分析以下代码段，程序执行完 `retf` 后，CS:IP 会指向哪里？**
```assembly
mov ax, code
mov ss, ax
mov sp, 16
mov ax, 0
push cs
push ax
mov bx, 0
retf
```
> **【答案与解析】**
> 会指向当前代码段（`code`段）的第一条指令，即 `CS:0000`。
> **解析：** `push cs` 将代码段地址压栈，`push ax` 将0压栈。此时栈顶是 0000H，栈顶之下是 CS 的值。`retf` 执行时，首先弹出栈顶的值给 IP，所以 `IP = 0`；然后弹出下一个值给 CS，所以 CS 保持为代码段的段地址不变。因此程序跳转到当前代码段的首地址开始执行。*(参考PPT P4)*

**3. `call 标号`（如 `call s`）指令属于段内转移还是段间转移？它的转移原理是什么？**
> **【答案与解析】**
> 属于**段内转移**（依据位移进行转移）。
> **解析：** CPU执行时，先将当前的 IP 压栈：`(sp) = (sp) - 2`，`((ss)*16+(sp)) = (IP)`；然后将 IP 修改为标号处的地址与 `call` 指令后的首地址之间的**16位位移**。相当于执行了 `push IP` 和 `jmp near ptr 标号`。注意它不能实现短转移。*(参考PPT P7)*

**4. 假设内存中代码如下，执行到 `1000:3` 时，执行 `call s`，执行后 SP 会发生什么变化？压入栈中的 IP 值是多少？**
```assembly
1000:0   b8 00 00   mov ax, 0
1000:3   e8 01 00   call s
1000:6   40         inc ax
1000:7   58       s:pop ax
```
> **【答案与解析】**
> *   SP 变化：`(sp) = (sp) - 2`。
> *   压入栈中的 IP 值是：**0006H**。
> **解析：** `call s` 压入的是 `call` 指令的**下一条指令**的偏移地址。下一条指令是 `inc ax`，它的地址是 `1000:6`，因此压入栈中的 IP 是 0006H。执行 `pop ax` 后，AX 的值将变成 0006H。*(参考PPT P8)*

**5. 给出以下指令执行后的结果：**
```assembly
mov sp, 10h
mov ax, 0123h
mov ds:[0], ax
call word ptr ds:[0]
```
> **【答案与解析】**
> 执行后：`(IP) = 0123H`，`(sp) = 0EH`。
> **解析：** `call word ptr` 是段内间接转移。它等价于 `push IP` 加上 `jmp word ptr ds:[0]`。`sp` 原来是 10H，压栈一个字后变成 10H-2 = 0EH。IP 被修改为 `ds:[0]` 中的字数据，即 0123H。*(参考PPT P10)*

**6. 执行以下代码后，DX 和 AX 的值分别是多少？**
```assembly
mov ax, 100
mov bx, 10000
mul bx
```
> **【答案与解析】**
> `(AX) = 4240H`，`(DX) = 000FH`。
> **解析：** 这是16位乘法。100 * 10000 = 1000000（十进制）。转化为十六进制是 `0F4240H`。16位乘法的结果保存在 `DX:AX` 中，高16位在 DX，低16位在 AX。因此 DX=000F，AX=4240。*(参考PPT P22)*

**7. 在使用 `xchg` 指令时，以下哪条指令是合法的？**
A. `xchg ax, 10h`
B. `xchg ds, ax`
C. `xchg byte ptr [si], [di]`
D. `xchg ax, bx`
> **【答案与解析】**
> **合法的是 D。**
> **解析：** `xchg` 指令的规则是：1. 任何一个操作数不能是立即数（排除A）；2. 任何一个操作数不能是段寄存器（排除B）；3. 不能同时都是内存操作数（排除C）；4. 两个操作数长度必须相等。D项是两个寄存器交换，完全合法。*(参考PPT P23)*

**8. 子程序设计中，当存在多个子程序互相调用时，由于寄存器数量有限，极易产生“寄存器冲突”。PPT中推荐的标准解决方案是什么？**
> **【答案与解析】**
> 解决方案是：**用堆栈来保护现场和恢复现场**。
> 在子程序的开始，将子程序中会用到的寄存器内容都 `push` 压入栈中保存；在子程序返回（`ret/retf`）之前，按照**相反的顺序**将寄存器的内容 `pop` 弹出恢复。*(参考PPT P31-32)*

**9. （填空题）如果结果为0，则 ZF = ______；如果结果不为0，则 ZF = ______。**
> **【答案与解析】**
> ZF = **1**；ZF = **0**。
> **解析：** ZF（Zero Flag）是零标志位。记住“结果为零，零标志才为真(1)”。*(参考PPT P41)*

**10. 以下指令执行后，PF（奇偶标志位）的值是多少？**
```assembly
mov al, 1
add al, 10
```
> **【答案与解析】**
> PF = **0**。
> **解析：** PF 记录的是结果的**低8位**中，二进制位 `1` 的个数。1 + 10 = 11（十进制），转为二进制是 `0000 1011B`。其中有 3 个 `1`。个数为奇数，所以 PF=0（偶数时PF为1）。*(参考PPT P42)*

**11. CF（进位标志位）和 OF（溢出标志位）有什么区别？**
> **【答案与解析】**
> *   **CF** 是对**无符号数**运算有意义的标志位。它记录了最高有效位向更高位的进位值或借位值。
> *   **OF** 是对**有符号数**运算有意义的标志位。它记录了运算结果是否超出了机器所能表示的有符号数范围（发生溢出）。*(参考PPT P46)*

**12. 计算 `0F0H + 88H`，执行 `mov al, 0F0H` 和 `add al, 88H` 后，CF 和 OF 的值分别是多少？**
> **【答案与解析】**
> CF = **1**，OF = **1**。
> **解析：** 
> F0H = `1111 0000B`，88H = `1000 1000B`。
> 相加结果：`1 0111 1000B`，即 78H，最高位产生了进位 `1`，所以 CF = 1。
> 从有符号数看：F0H是负数（-16），88H是负数（-120），两个负数相加得到了一个正数（78H符号位为0），发生了溢出，所以 OF = 1。*(参考PPT P46)*

**13. `adc` 指令的功能是什么？试写出 `adc ax, bx` 表达的数学公式。**
> **【答案与解析】**
> `adc` 是带进位的加法指令。
> 数学公式：`(ax) = (ax) + (bx) + CF`。它通常用于与 `add` 配合进行大数（如32位或更大）的加法运算。*(参考PPT P47)*

**14. 在进行128位数据相加的循环程序中（PPT P52 实验题），为什么不能用 `inc si` 和 `inc di` 来移动指针，而必须用 `add si, 2`？**
> **【答案与解析】**
> 因为 `inc` 指令**不影响 CF（进位标志位）**。如果不影响CF，倒不是主要问题；更大的问题是，如果用 `add si, 1`，它**会修改CF位**，从而破坏前面 `adc` 指令产生的、留给下一步运算用的真实进位值！
> *(注：PPT原文解释是“inc和loop指令不影响CF位”，所以此处必须保证在adc之间不要有改变CF的指令。`add si, 2` 虽然会影响CF，但在PPT的示例中使用 `add si,2` 实际上是错误的如果放在 `adc` 之前！仔细看PPT P52的思考题，正确答案是应该将改变指针的指令提取出去，或者利用 `pushf` 和 `popf` 保护CF，或者直接展开循环。PPT中提到的替代指令是 `add si, 2`，但通常 `add` 会改变CF。如果非要用，应放在不影响进位的逻辑中，或者像PPT后续用 `pushf`。)* **严格按PPT P52解答：** 实际上 `inc` **不影响** CF，这是它的特性。但如果是要加2，写成 `add si, 2` **会影响** CF。如果循环体内有 `adc`，使用 `add si, 2` 会覆盖上一步加法产生的 CF 值，导致高位加法计算错误。因此如果在循环体中用 `add si,2`，必须配合 `pushf` 和 `popf` 保护标志寄存器（或者使用不影响CF的指令）。*(参考PPT P52)*

**15. `sbb` 是什么指令？它的计算公式是什么？**
> **【答案与解析】**
> `sbb` 是带借位的减法指令。
> 计算公式（以 `sbb ax, bx` 为例）：`(ax) = (ax) - (bx) - CF`。*(参考PPT P53)*

**16. `cmp` 指令的本质是什么？它会保存运算结果吗？**
> **【答案与解析】**
> `cmp` 是比较指令，它的功能相当于**减法指令**，只是它**不保存结果**，只对标志寄存器（ZF, PF, SF, CF, OF）进行设置。*(参考PPT P55)*

**17. 在无符号数比较中，执行 `cmp ax, bx` 后，如果 `(ax) < (bx)`，相关的标志位会是什么状态？**
> **【答案与解析】**
> 会产生借位，所以 **CF = 1**。*(参考PPT P56)*

**18. 有符号数比较：`cmp ah, bh`，如果 SF=1 且 OF=1，说明真正的逻辑大小关系是 `(ah)` 大于还是小于 `(bh)`？**
> **【答案与解析】**
> `(ah) > (bh)`。
> **解析：** SF=1 表示实际减法结果的符号位为负。OF=1 表示发生了溢出。因为溢出导致了实际结果的符号位变反，所以“逻辑上真正的结果”必然为正。结果为正说明 `ah - bh > 0`，即 `ah > bh`。*(参考PPT P59)*

**19. 根据无符号数的条件转移指令，写出以下指令的含义：**
*   `je`：__________
*   `jb`：__________
*   `ja`：__________
> **【答案与解析】**
> *   `je`：等于则转移 (Equal)，检测 ZF=1。
> *   `jb`：低于则转移 (Below)，检测 CF=1。
> *   `ja`：高于则转移 (Above)，检测 CF=0 且 ZF=0。*(参考PPT P61)*

**20. `DF` 标志位的作用是什么？`cld` 和 `std` 指令分别如何设置 `DF`，且对串操作有什么影响？**
> **【答案与解析】**
> `DF` (Direction Flag) 是方向标志位，用于在串处理指令中，控制每次操作后 `si`, `di` 的增减。
> *   `cld` 指令：将 DF 设置为 **0**。每次操作后 `si`, `di` **递增**（正向传送）。
> *   `std` 指令：将 DF 设置为 **1**。每次操作后 `si`, `di` **递减**（逆向传送）。*(参考PPT P68, P71)*

**21. 简述 `movsb` 指令执行的完整内部操作（包含寻址方式和寄存器的变化）。**
> **【答案与解析】**
> `movsb` 是以**字节**为单位传送的串传送指令。
> 内部操作：
> 1. 将 `ds:si` 指向的内存单元中的一个字节送入 `es:di` 指向的内存单元中：`((es)*16 + (di)) = ((ds)*16 + (si))`。
> 2. 根据 DF 位的值决定增减：
>    如果 DF=0，则 `si = si + 1`，`di = di + 1`；
>    如果 DF=1，则 `si = si - 1`，`di = di - 1`。*(参考PPT P69)*

**22. `rep` 指令通常和串传送指令配合使用，它的作用原理是什么？**
> **【答案与解析】**
> `rep` 的作用是根据 **cx** 寄存器的值，重复执行其后面的串传送指令（如 `movsb` 或 `movsw`）。每执行一次，`cx = cx - 1`，直到 `cx = 0` 时停止重复。这等价于一个隐式的 `loop` 循环。*(参考PPT P70)*

**23. 补全程序代码：计算 data 段中第一组数据（假设为 8 个字型数据）的 3 次方，结果保存在后面的 dword 单元中。（注意子程序的参数传递）**
```assembly
assume cs:code
data segment
    dw 1, 2, 3, 4, 5, 6, 7, 8
    dd 0, 0, 0, 0, 0, 0, 0, 0
data ends

code segment
start: mov ax, data
       mov ds, ax
       mov si, 0
       mov di, 16
       mov cx, 8
    s: mov bx, [si]
       _________________  ; 调用计算3次方的子程序
       mov [di], ax
       mov [di+2], dx
       add si, 2
       add di, 4
       loop s
     
       mov ax, 4c00h
       int 21h

cube:  _________________  ; 计算bx的三次方，低16位在ax，高16位在dx
       mul bx
       mul bx
       _________________  ; 子程序返回
code ends
end start
```
> **【答案与解析】**
> 填空 1: `call cube` (调用子程序)
> 填空 2: `mov ax, bx` (将底数给AX，准备乘法)
> 填空 3: `ret` (返回主程序)
> **解析：** 主程序通过 `bx` 传递参数给子程序。子程序 `cube` 需要计算 $bx^3$。第一次执行 `mov ax, bx` 然后 `mul bx` 得到 $bx^2$；再执行一次 `mul bx` 得到 $bx^3$，结果自动保存在 `dx:ax` 中。最后用 `ret` 返回。主程序中 `[di]` 存低位 AX，`[di+2]` 存高位 DX。*(参考PPT P26)*

**24. 编程题：编写一个子程序，功能是将一个全为字母的以0结尾的字符串转化为大写。字符串首地址由 `ds:si` 传入。要求在子程序中解决可能出现的寄存器冲突问题。**
> **【答案与解析】**
> ```assembly
> capital: 
>     push cx        ; 保护使用到的寄存器
>     push si
>   
> change: 
>     mov cl, [si]
>     mov ch, 0
>     jcxz ok        ; 如果 (cx)=0，说明遇到字符串结尾，结束循环
>     and byte ptr [si], 11011111b  ; 转化为大写 (将第5位清零)
>     inc si
>     jmp short change
>   
> ok: 
>     pop si         ; 恢复寄存器，注意先压后出的顺序 (LIFO)
>     pop cx
>     ret
> ```
> **解析：** 本题考察点有三个：一是利用 `jcxz` 检测0结束符；二是利用位运算 `and` 转化大写；三是最重要的，利用 `push` 和 `pop` 将 `cx` 和 `si` 保存起来，避免破坏调用者（主程序）原有的寄存器状态。*(参考PPT P29-P32)*

**25. 编程填空：计算 `1EF0001000H + 2010001EF0H`，结果放在 `ax`（高16位），`bx`（次高16位），`cx`（低16位）中。**
```assembly
mov ax, 001EH
mov bx, 0F000H
mov cx, 1000H

_________________ cx, 1EF0H  ; 低16位运算
_________________ bx, 1000H  ; 次高16位运算
_________________ ax, 0020H  ; 高16位运算
```
> **【答案与解析】**
> 填空 1: `add`
> 填空 2: `adc`
> 填空 3: `adc`
> **解析：** 大数加法分步进行。最低位的16位直接相加，使用 `add`，它会产生进位记录在 CF 中。后续的较高位必须使用 `adc`（带进位加法），把前一步的 CF 值加进来。*(参考PPT P51)*

**26. 编程填空：统计 data 段中数值**等于 8**的字节的个数，用 ax 保存结果。**
```assembly
data segment
    db 8, 11, 8, 1, 8, 5, 63, 38
data ends

; 代码段部分：
       mov bx, 0
       mov ax, 0
       mov cx, 8
    s: cmp byte ptr [bx], 8
       _________________ next   ; 如果不相等，则跳过计数
       inc ax                   ; 相等则计数
 next: inc bx
       loop s
```
> **【答案与解析】**
> 填空: `jne` (或 `jnz`)
> **解析：** 要求统计“等于8”的个数。当 `cmp` 比较不等于8时，应该跳过累加指令 `inc ax`。所以这里用“不等于则转移”指令 `jne`。*(参考PPT P64)*

**27. 修改上一题的逻辑：统计 data 段中数值**大于 8**的字节的个数（假设无符号数），用 ax 保存结果。请写出对应的条件跳转指令。**
```assembly
    s: cmp byte ptr [bx], 8
       _________________ next   ; 指令填空
       inc ax
 next: inc bx
       loop s
```
> **【答案与解析】**
> 填空: `jna` (或 `jbe`)
> **解析：** 要统计“大于8”的个数。那么如果“不大于8（即小于等于8）”时，就应该跳过 `inc ax`。无符号数“不大于（不高于）”的跳转指令是 `jna` (Jump if Not Above)。*(参考PPT P65)*

**28. 补全程序：使用串传送指令，将 data 段中的第一个字符串（16个字节）复制到它后面的空间中。**
```assembly
data segment
    db 'Welcome to masm!'
    db 16 dup (0)
data ends
code segment
start: mov ax, data
       mov ds, ax
       mov es, ax      ; ds和es都指向data段
       mov si, 0       ; 源地址起始
       mov di, 16      ; 目的地址起始
       mov cx, 16      ; 传送长度16次
       _________________   ; 传送方向为正向
       _________________   ; 执行重复的字节传送指令
     
       mov ax, 4c00h
       int 21h
code ends
```
> **【答案与解析】**
> 填空 1: `cld`
> 填空 2: `rep movsb`
> **解析：** 复制数据到后面的空间，不存在重叠覆盖问题，使用正向传送即可。`cld` 清除 DF 标志位使得 `si/di` 递增。`rep movsb` 根据 `cx` 的值循环传送16个字节。*(参考PPT P72)*

**29. 如果需要将一个内存空间的数据“逆向传送”（从高地址向低地址传送），需要在执行 `rep movsb` 之前执行哪条指令来设置方向标志？请写出初始化 SI 和 DI 的大致思路。**
> **【答案与解析】**
> 需要执行 **`std`** 指令，将 DF 设置为 1。
> **思路：** 源变址寄存器 SI 应初始化为源数据块的**最后一个单元**的偏移地址；目的变址寄存器 DI 应初始化为目的数据块的**最后一个单元**的偏移地址。这样在执行 `movsb` 时，SI 和 DI 才会正确地递减，实现从后往前的逆向复制。*(参考PPT P73)*

**30. 标志寄存器也有入栈出栈操作。请写出将标志寄存器压入栈中，以及从栈中弹出的指令。**
> **【答案与解析】**
> *   压入栈：**`pushf`** (push flags)
> *   弹出栈：**`popf`** (pop flags)
> **解析：** 这两条指令常用于在执行会大面积破坏标志位的代码（如循环加法中的某些非核心运算）前后，保护和恢复程序的标志状态(PSW/Flag)。*(参考PPT P74)*
