# 一、 解析题（概念理解、数据变化、程序填空与纠错）

**1. 【填空题】** 根据8086CPU的机制，中断源分为软件中断和硬件中断，其中软件中断又称为内中断。请列举PPT中提到的三种引起内中断的情况：________、________、________。
*   **答案：** 由中断指令`int n`引起；由CPU的某些错误引起（如除法错、溢出）；为调试程序DEBUG设置的中断（单步、断点）。
*   **解析：** 见PPT第1页。内中断是不受中断允许标志位IF控制的。

**2. 【分析题】** 8086提供了256个中断类型，请问中断向量表存放在内存的哪个物理地址范围？每个表项占用几个字节？其中高地址和低地址分别存放什么寄存器的内容？
*   **答案：** 存放在内存 `0000:0000` 到 `0000:03FF` 的区域（共1024字节）。每个表项占用4个字节。低两个字节存放偏移地址（IP），高两个字节存放段地址（CS）。
*   **解析：** 见PPT第2页。CPU根据8位中断类型码（0~255）查找向量表。寻找公式为：IP的物理地址 = 中断类型码 * 4；CS的物理地址 = 中断类型码 * 4 + 2。

**3. 【计算题】** 假设我们需要编写并安装一个自定义的 `INT 7CH` 中断，请问该中断处理程序的入口地址（IP和CS）应该分别保存在中断向量表的哪个具体的物理地址单元中？
*   **答案：** IP的内容保存在 `0000:01F0H`，CS的内容保存在 `0000:01F2H`。
*   **解析：** 7CH 转换为十进制是 124。公式：IP地址 = 7CH * 4 = 1F0H；CS地址 = 7CH * 4 + 2 = 1F2H。由于向量表在0段，所以物理地址即为上述值。

**4. 【简答题】** 请按顺序默写出CPU响应内中断时，执行的6个完整的“中断过程”步骤。
*   **答案：**
    (1) 取得中断类型码；
    (2) 标志寄存器（pushf）的值入栈；
    (3) 设置标志寄存器的第8位TF和第9位IF的值为0（TF=0, IF=0）；
    (4) CS的内容入栈；
    (5) IP的内容入栈；
    (6) 从内存地址为中断类型码*4和中断类型码*4+2的两个字单元中读取中断程序的入口地址设置IP和CS。
*   **解析：** 见PPT第3页。这是中断处理的核心机制，必须牢记，特别是先压标志寄存器，再清零TF和IF，最后压CS和IP。

**5. 【分析题】** 在编写中断处理程序时，最后一条指令通常是 `iret`。请用汇编指令描述 `iret` 指令在CPU内部具体执行了哪三步操作？
*   **答案：**
    `pop IP`
    `pop CS`
    `popf`
*   **解析：** 见PPT第4页。`iret` 必须与中断响应时的压栈顺序（pushf -> push CS -> push IP）严格反向对应，以恢复中断前的执行现场。

**6. 【改错题】** 某同学在复习指令时，写下了如下代码尝试修改段寄存器：
```assembly
mov ds, 1000H
mov cs, ax
```
请问这两条指令是否正确？如果不正确，请说明原因。
*   **答案：** 均不正确。
*   **解析：** 见PPT第32页。8086汇编中，不能直接将立即数传送给段寄存器（如DS），必须通过通用寄存器中转（如 `mov ax, 1000H; mov ds, ax`）。同时，`MOV` 指令绝对不能用于修改 `CS` 和 `IP` 的值，修改CS:IP必须使用转移指令（如 `jmp`, `call`, `ret`, `int` 等）。

**7. 【判断分析题】** 发生单步中断的条件是标志寄存器中的TF位为1。在执行完中断过程后，CPU会自动将TF置为0。这种设计的目的是什么？如果不断将TF设为1会发生什么？
*   **答案：** 目的：防止在执行单步“中断处理程序”自身时，内部的指令再次引发单步中断，从而导致死循环。
*   **解析：** 见PPT第15-16页。Debug程序的 `T` 命令就是利用了此机制。如果进入中断处理程序后TF仍然为1，那么执行中断处理程序的第一条指令就会再次触发单步中断，永远无法真正处理原先的中断。

**8. 【分析题】** CPU在执行完指令后一般会立即响应中断，但PPT中提到了3种“不能响应中断的特殊情况”，请列举出来，并说明第一种情况的原因。
*   **答案：**
    情况1：执行完 `mov ss, XX` 的指令后。
    情况2：执行到 `STI` 指令时。
    情况3：执行到 `IRET` 指令时。
    原因：修改SS时往往紧接着需要修改SP（如 `mov sp, 0`）来重新定位栈顶。SS:SP联合指向栈顶，对它们的设置必须连续完成。如果在修改完SS后立即响应中断，中断过程会将寄存器压栈，此时SP尚未设置正确，会导致原有数据被错误覆盖或系统崩溃。
*   **解析：** 见PPT第17-18页。这是极易考查的系统保护机制。

**9. 【程序填空题】** 下面是将自己编写的 `do0`（0号中断处理程序）安装到内存 `0000:0200` 处的代码。请填空完整：

**10. 【计算题】** 在B8000H显存中显示字符，若要求在屏幕正中央（第12行，第36列，行号列号均从0开始编号）显示一个字符，请计算它在当前显存段（`es=B800H`）中的偏移地址是多少？

**11. 【分析题】** B8000H显存中，每个字符占用2个字节，这两个字节分别存放什么？偶地址和奇地址各存什么？
*   **答案：** 占用2个字节分别存放ASCII码和属性。偶地址存放ASCII码，奇地址存放属性（颜色）。

**12. 【逻辑查错题】** 某同学编写0号中断处理程序时，为了显示"overflow!"，他将字符串放在了 `data segment` 中（如下代码）。请问这样写存在什么隐患？正确的做法是什么？

**16. 【代码阅读与分析题】** 
请分析以下定制INT 7CH中断的局部代码，并回答问题：
```assembly
mov ax, 0
mov es, ax
mov word ptr es:[7ch*4], 200h
mov word ptr es:[7ch*4+2], 0
...
Sqr:  mul ax
      iret
Sqrend: nop
```
问题：这个INT 7CH中断处理程序实现了什么功能？返回值保存在哪里？
*   **答案：** 功能是求一个word型数据（16位）的平方。参数由 `AX` 提供。由于使用了 `mul ax`（16位乘法），结果的低16位保存在 `AX` 中，高16位保存在 `DX` 中。
*   **解析：** 见PPT第20-21页。考察对 `mul` 指令的隐式寄存器使用的理解，16位乘16位，结果是32位，默认存在 DX:AX 中。

**17. 【综合编程题】编写 0号中断（除法溢出）安装及处理程序**
要求：
(1) 编写安装程序，将自定义的 `do0` 拷贝到 `0000:0200H`。
(2) 设置中断向量表。
(3) 当发生除法溢出时，屏幕中间（第12行）显示绿色的字符串 "overflow!"（绿色属性值为 `02H`）。
(4) 显示完毕后利用 `mov ax, 4c00h; int 21h` 返回DOS。
*(提示：记得使用正确的字符串数据存放方式)*

*   **参考答案与解析（由于长度限制，提供核心代码框架）：**
```assembly
assume cs:code
code segment
start:
    ; 1. 安装中断程序到 0:200
    mov ax, cs
    mov ds, ax
    mov si, offset do0
    mov ax, 0
    mov es, ax
    mov di, 200h
    mov cx, offset do0end - offset do0
    cld
    rep movsb

    ; 2. 设置中断向量表 (类型0)
    mov ax, 0
    mov es, ax
    mov word ptr es:[0*4], 200h
    mov word ptr es:[0*4+2], 0

    ; 返回DOS
    mov ax, 4c00h
    int 21h

    ; 3. 中断处理程序具体实现
do0:
    jmp short do0start
    db "overflow!"  ; 数据内嵌

do0start:
    mov ax, cs
    mov ds, ax
    mov si, 202h    ; 字符串在此代码段(0:200开始)中的相对位置：jmp占2字节，所以从202h开始

    mov ax, 0b800h
    mov es, ax
    mov di, 12*160+36*2 ; 屏幕中间位置

    mov cx, 9       ; 字符串长度
s:  mov al, [si]    ; 取字符
    mov es:[di], al
    mov byte ptr es:[di+1], 02h ; 设置颜色为绿色 (此行代码结合了显示原理，PPT中未写死颜色，但考察了显存结构)
    inc si
    add di, 2
    loop s

    mov ax, 4c00h   ; 发生溢出后强制返回DOS
    int 21h
do0end: nop

code ends
end start
```
*   **解析：** 见PPT 7-14页综合。此题是全篇PPT的核心大题，涵盖了代码复制、向量表重写、`jmp`跨越数据、直接写显存等诸多8086核心技能。

**18. 【综合编程题】编写并测试笑脸中断 INT 60H**
按照PPT实验练习的要求，设计一个中断子程序INT 60H，当调用它时，能在屏幕上当前光标位置输出一个回车换行，并利用DOS 2号功能输出一个笑脸（ASCII码为 `01H`，或者直接按PPT要求循环输出特定字符）。
要求写出中断处理程序 `smigin` 的实现主体（包括开/关中断的保护）。
*   **参考答案与解析：**
```assembly
smigin:
    sti             ; 开中断 (PPT演示逻辑)
    mov cx, 10      ; 循环10次
leng: 
    mov dl, 01h     ; 笑脸符号 ASCII
    mov ah, 2       ; 调用 DOS INT 21H 2号功能打印字符
```

**19. 【代码补全题】字符串交互程序设计**
结合PPT中INT 21H调用的复习内容。要求写一段代码：提示用户输入一个字符，如果用户输入的是小写字母 'c'，则调用刚才我们写好的 `INT 7CH`（假设已安装好，虽然7CH原题是求平方，这里假设它是个通用调用），否则直接退出。
*   **参考答案与解析：**
```assembly
; 假设数据段中已有 mess3 db 0ah, 0dh, 'Continue or Quit(c/q)?$'
; 打印提示信息
    mov dx, offset mess3
    mov ah, 9
    int 21h
  
; 接收键盘输入
    mov ah, 1
    int 21h         ; 用户输入的字符此时保存在 AL 中
  
; 判断是否为 'c'
    cmp al, 'c'
    je conti        ; 如果相等(ZF=1)，跳到conti执行
    jmp quit        ; 否则退出

conti:
    int 7ch         ; 调用 7CH 中断

quit:
    mov ax, 4c00h
    int 21h
```
*   **解析：** 见PPT第26-27页。考察了DOS调用的 9号功能（打印字符串）、1号功能（接收单字符）、以及 `cmp` 和 条件转移指令 `je` 的配合使用。

**20. 【查错与填空题】关于 rep movsb 的细节**
在使用 `rep movsb` 搬运中断程序时，下列寄存器的初始化必不可少，请指明它们的功能：
```assembly
mov cx, [长度] ; CX的作用是：___________
cld            ; cld的作用是：___________，如果漏掉可能导致：___________
```
*   **答案：**
    CX的作用是：设置循环/传输的次数（字节数）。
    cld的作用是：将标志寄存器中的方向标志位DF清零，使得每次传输后SI和DI自动递增（正向传输）。
    漏掉导致的后果：如果此时DF恰好为1，SI和DI会每次递减，导致拷贝方向向低地址蔓延，不仅无法正确拷贝代码，还可能破坏系统底层的其他中断向量。
*   **解析：** 见PPT第10页和第35页串处理指令复习。强调了串操作指令环境设置的重要性。

**21. 【解析题】** 内存单元物理地址的计算公式是 `段地址 × 16 + 偏移地址`。PPT中提到8086的数据总线是16位，而地址总线是20位。请问：在段地址固定不变的情况下，CPU可以通过改变偏移地址最多寻址多少KB的物理内存空间？
*   **答案：** 64KB。
*   **解析：** 见PPT第31页。偏移地址是16位的，`2^16 = 65536` 字节 = 64KB。这也是为什么一个段最大只能是64KB的原因。
