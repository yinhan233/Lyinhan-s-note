# 第10章 软件项目管理 — 重点笔记

## 一、项目管理概述

- 按**预定进度、费用**完成软件开发和维护
- **项目五阶段**：启动 → 计划 → 实施 → 控制 → 收尾

## 二、SPMP 文档

- **软件项目管理计划书**
- 内容：实施计划、资源需求、成本估计
- **里程碑**：项目关键节点

## 三、五大管理内容

> **风险管理、配置管理、成本管理、质量管理、进度管理**

---

## 四、风险管理

### 4.1 风险类型

| 类型 | 说明 |
|------|------|
| **项目风险** | 进度、资源、预算等 |
| **技术风险** | 技术难度、可行性 |
| **商业风险** | 市场、竞争、盈利 |

### 4.2 风险管理步骤

1. **风险识别**：列出潜在风险
2. **风险分析**：评估概率、严重程度、优先级
3. **风险应对**：**回避** / **降低** / **接受**

## 五、软件配置管理（SCM）⭐

- **软件配置** = 各种文档和程序的总称
- **SCI（软件配置项）** = 程序 + 文档 + 数据
- **基线** = 里程碑；复审后 SCI 交付成为基线
- **原则**：基线前**自由**修改，基线后**严格管理**（变更控制）
- **工具**：VSS / CVS / **Git** / GitHub / Gitee / GitLab

## 六、成本估算方法 ⭐

### 6.1 代码行（LOC / KLOC）

- 简单但有**局限**：
  - 只是开发的一部分
  - 语言差异大
  - 不够准确

### 6.2 功能点（FP）⭐

- 基于**信息域值**：

| 类型 | 缩写 |
|------|------|
| 外部输入 | Inp |
| 外部输出 | Out |
| 外部查询 | Inq |
| 内部逻辑文件 | Maf |
| 外部接口文件 | Inf |

- **FP = UFP × TCF**
- **TCF = 0.65 + 0.01 × DI**（14 种技术因素，每项 0~5 分，DI 范围 0~70）

### 6.3 问题分解估算

1. 分解功能
2. 估算每个功能 LOC / FP
3. **期望值 EV = (S_opt + 4S_m + S_pess) / 6**
4. 合并

### 6.4 过程分解估算

- 分解**过程活动** → 估算每个活动工作量

### 6.5 COCOMO 模型（构造性成本模型）⭐

- **三个级别**：基本 / 中级 / 高级
- **三种模式**：

| 模式 | 特点 |
|------|------|
| **组织型** | 小型、简单、经验丰富团队 |
| **半独立型** | 中等规模、中等复杂 |
| **嵌入型** | 大型、复杂、强约束 |

- **基本公式**：
  - **E = a × (KLOC)^b**（工作量，人月）
  - **T = c × (E)^d**（开发时间，月）
- **15 个 EAF 工作量调节因子**（中级 COCOMO 使用）

## 七、质量管理

### 7.1 质量度量

| 指标 | 含义 |
|------|------|
| **正确性** | 每 KLOC 缺陷数 |
| **可维护性** | MTTC（平均修改时间） |
| **完整性** | 抵御攻击的能力 |
| **可用性** | 用户易用程度 |
| **可靠性** | 无失效运行概率 |

### 7.2 缺陷排除效率

- **DRE = E / (E + D)**
- E = 交付前发现的缺陷数，D = 交付后发现的缺陷数

### 7.3 软件可靠性

- **R(t) = e^(-λt)**
- **MTTF = 1/λ**（平均无故障时间）
- **R_sys = R_s × R_H × R_op**（系统可靠性 = 软件 × 硬件 × 人员操作）

### 7.4 质量标准

- **ISO 9000 标准**
- **CMM / CMMI 五级**：

| 级别 | 名称 |
|------|------|
| 1 | **初始级** |
| 2 | **可重复级** |
| 3 | **定义级** |
| 4 | **管理级** |
| 5 | **优化级** |

## 八、进度管理

| 工具 | 特点 |
|------|------|
| **甘特图（Gantt）** | 直观显示任务时间段，不能反映依赖关系 |
| **PERT 图** | 显示任务依赖，可求**关键路径**（最长路径） |
| **工程网络图** | 结合 PERT，节点+弧表示活动和事件 |
