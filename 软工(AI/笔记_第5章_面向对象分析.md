# 第5章 面向对象分析 — 重点笔记

## 一、面向对象基础

| 缩写 | 全称 | 含义 |
|------|------|------|
| **OOA** | Object-Oriented Analysis | 面向对象分析 |
| **OOD** | Object-Oriented Design | 面向对象设计 |
| **OOI** | Object-Oriented Implementation | 面向对象实现 |
| **OOT** | Object-Oriented Testing | 面向对象测试 |

## 二、UML（统一建模语言）

- 由 **OMG** 发布的**可视化建模语言**

### 模型元素

- **结构元素**：类、对象、用例、结点、构件、包、接口
- **关系元素**：关联、泛化、依赖、聚集

## 三、UML视图

| 视图 | 关注点 |
|------|--------|
| **用例视图** | 系统外部行为（用户角度） |
| **逻辑视图** | 系统内部结构（类和对象） |
| **交互视图** | 对象间交互 |
| **构件视图** | 软件组件组织 |
| **部署视图** | 硬件拓扑和软件部署 |

- **结构图（静态）**：类图、对象图、构件图、部署图
- **行为图（动态）**：用例图、活动图、顺序图、通信图、状态图

## 四、OOA过程

```
需求阶段                          分析阶段
├─ 功能建模 → 用例图 + 活动图     ├─ 领域业务建模 → 类图
                                  └─ 系统行为建模 → 顺序图 / 通信图
```

## 五、用例图

### 四要素

1. **参与者（Actor）**：与系统交互的外部实体
2. **用例（Use Case）**：系统提供的一个功能单元
3. **关系**：关联、包含、扩展、泛化
4. **主题（Subject）**：系统边界

### 关系类型

| 关系 | 符号 | 含义 |
|------|------|------|
| **关联** | 实线 | 参与者与用例的交互 |
| **包含（include）** | 虚线箭头 + `<<include>>` | 基用例**必定**包含子用例 |
| **扩展（extend）** | 虚线箭头 + `<<extend>>` | 在特定条件下**可选**扩展 |
| **泛化** | 带空心三角的实线 | 继承关系 |

## 六、用例描述

- **用例名称**、**范围**、**级别**
- **主要参与者**
- **涉众及关注点**
- **前置条件**、**成功保证（后置条件）**
- **主成功场景**（主事件流）
- **扩展**（NEA三段法）：
  - **N**ormal（正常变体）
  - **E**xception（异常）
  - **A**lternative（替代）

## 七、活动图

### 基本元素

- **初始节点**（实心圆）/ **终点节点**（牛眼）
- **活动节点**（圆角矩形）
- **转移**（箭头）
- **分支与监护条件**（菱形 + [条件]）
- **分叉（fork）与汇合（join）**（粗线段）：表示并发

### 泳道图

- 将活动按**责任主体**分区，明确谁执行什么

## 八、分析类 — 三种构造型

| 构造型 | 符号 | 含义 |
|--------|------|------|
| **实体类（Entity）** | 底部带横线的圆 | 长效持久信息（如数据库表） |
| **边界类（Boundary）** | 左侧带竖线的圆 | 系统与参与者的交互界面 |
| **控制类（Control）** | 顶部带箭头的圆 | 协调、排序、控制逻辑 |

## 九、CRC技术（类-职责-协作者）

- **C**lass — 标识候选类
- **R**esponsibility — 指明每个类的职责
- **C**ollaborator — 确定协作关系
- 常用**角色扮演技术**进行验证

## 十、顺序图（时序图）

### 基本元素

- **对象** / **参与者**：顶部矩形
- **生命线**：对象下方的垂直虚线
- **激活条**：生命线上的矩形，表示对象正在执行
- **消息**：对象间的水平箭头，描述信息传递**顺序**

## 十一、通信图（协作图）

- 与顺序图**语义等价**
- **强调对象的组织结构**（而非时间顺序）
- **消息编号**：表示调用顺序
- 支持**迭代标记**（`*`）和**监护条件**（`[条件]`）

## 十二、状态图

### 基本元素

- **状态**：圆角矩形
- **转移**：状态间的箭头
- **事件**：触发转移的条件
- **初始状态**（实心圆）/ **终止状态**（牛眼）
