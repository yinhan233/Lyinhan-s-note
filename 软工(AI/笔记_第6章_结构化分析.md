# 第6章 结构化分析 — 重点笔记

## 一、结构化分析（SA）概述

- **起源**：20世纪70年代，**E.Yourdon** 等倡导
- **核心思想**：面向**数据流**的需求分析方法
- **基本策略**：**自顶向下、逐层分解**

## 二、三种模型

| 模型 | 工具 | 描述域 |
|------|------|--------|
| **数据流模型** | 数据流图（DFD） | 功能域 |
| **实体关系模型** | E-R图 | 信息域 |
| **状态转换模型** | 状态转换图（STD） | 行为域 |

## 三、数据流图（DFD）

### 四种基本符号

| 符号 | 含义 | 图形 |
|------|------|------|
| **数据源点/终点** | 外部实体（数据的来源或去向） | 矩形 |
| **加工/处理** | 数据变换 | 圆角矩形/圆 |
| **数据存储** | 数据的静态存储 | 开口矩形（双横线） |
| **数据流** | 数据的流动方向 | 带箭头的线 |

### 分层构建

```
顶层图（Context Diagram）
  └─ 0层图
       └─ 1层图
            └─ ... 底层图（不可再分解的加工）
```

### 构建步骤

1. 确定系统**输入输出**，构建**顶层DFD**
2. 细化顶层为**0层DFD**
3. **逐层细化**直至底层（每个加工不可再分解）

### 注意事项

- **命名规范**：加工 = **动词 + 名词**，数据流 = **名词**
- 画的是**数据流**，不是控制流
- 每个加工**至少一个输入和一个输出**
- **按层编号**：如 1、1.1、1.2、1.1.1 ...
- **保持父子图平衡**：父图中加工的输入输出 = 子图的外部输入输出

## 四、数据字典（DD）

### 四类条目

| 条目类型 | 说明 |
|----------|------|
| **数据流条目** | 描述DFD中数据流的组成 |
| **数据存储条目** | 描述DFD中数据存储的组成 |
| **数据项条目** | 描述数据的最小组成单位 |
| **加工条目** | 描述加工的逻辑（判定表/判定树/结构化语言） |

### 定义符号

| 符号 | 含义 | 示例 |
|------|------|------|
| **=** | 被定义为 | 学生 = 学号 + 姓名 + 年龄 |
| **+** | 与（连接） | |
| **[ \| ]** | 或（选择） | 性别 = [男 \| 女] |
| **{ }** | 重复 | {课程} |
| **( )** | 可选 | (备注) |
| **..** | 连接符（范围） | 1..9 |

## 五、实体关系模型（E-R图）

### 三个基本要素

| 要素 | 图形 | 说明 |
|------|------|------|
| **实体** | 矩形 | 现实世界中可区分的对象 |
| **属性** | 椭圆 | 实体的特征 |
| **关联（联系）** | 菱形 | 实体间的关系 |

### 基数（Cardinality）

| 类型 | 含义 |
|------|------|
| **1:1** | 一对一 |
| **1:n** | 一对多 |
| **m:n** | 多对多 |

## 六、状态转换图（STD）

### 基本元素

| 元素 | 图形 | 说明 |
|------|------|------|
| **状态** | 圆角矩形 | 系统在某时刻的状况 |
| **变迁（转移）** | 箭头 | 状态之间的切换 |
| **事件** | 箭头上的标记 | 触发变迁的条件 |

### 事件表达式

```
事件说明 [守卫条件] / 动作表达式
```

- **事件说明**：触发转移的事件
- **守卫条件**：转移发生的前提条件
- **动作表达式**：转移时执行的操作
