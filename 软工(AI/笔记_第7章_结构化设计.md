# 第7章 结构化设计 — 重点笔记

## 一、软件结构图（SC图）

### 1.1 主要元素

- **模块**、**控制关系**（调用）、**信息传递**（数据/控制）、**选择调用**、**循环调用**

### 1.2 形态特征

| 特征 | 含义 |
|------|------|
| **深度** | 层次数目 |
| **宽度** | 同一层最大模块数 |
| **扇出** | 一个模块直接调用的下级模块数 |
| **扇入** | 一个模块被多少上级模块调用 |

## 二、软件结构优化准则

- 深度宽度**适当**
- 扇出扇入**适当**：**扇入大** = 共享多（好），**扇出大** = 过分复杂（不好）
- 模块**独立性**强
- 模块**大小适当**
- **作用域在控制域内**
- 接口**简单清晰**

## 三、数据流类型

| 类型 | 特点 |
|------|------|
| **变换流** | 输入 → 变换中心 → 输出 |
| **事务流** | 事务中心选择活动通路 |
| **混合流** | 两种兼有 |

## 四、面向数据流设计方法（SD方法）

**四步**：
1. 复查精化 DFD
2. 分析数据流类型（变换流/事务流）
3. 自顶向下模块分解
4. 优化

### 4.1 变换设计步骤

1. 确定**变换中心**和输入输出边界
2. 设计**顶层和第一层**
3. 设计中下层
4. 优化

### 4.2 事务设计步骤

1. 确定**事务中心**和加工路径
2. 设计**接收分支**和**发送分支**（调度模块）
3. 中下层设计

## 八、判定表 ⭐

- **结构**：条件定义 + 条件组合 + 动作定义 + 条件组合下的动作
- **步骤**：
  1. 提取条件
  2. 标出取值
  3. 计算组合数（2^n）
  4. 提取动作
  5. 制作判定表
  6. 完善合并（去除不可能组合）
