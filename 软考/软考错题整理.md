## 1. DMA 传输方式

**题目：** DMA是一种高速的数据传输模式，下列描述中，错误的是（ ）。

> A. DMA传输方式可以产生中断  
> B. DMA传输过程主要由硬件来实现  
> C. DMA传输过程包含3个阶段：申请阶段、响应阶段和数据传输阶段  
> D. DMA操作可以通过软件来启动，也可以通过内部部件的请求来启动

**正确答案：C**

**解析：** 一个完整的 DMA 传输过程包含 **4 个步骤**：DMA 请求、DMA 响应、DMA 传输、**DMA 结束**（总线控制权交还 CPU）。选项 C 遗漏了"结束阶段"。

**知识点：**

- **DMA（Direct Memory Access，直接存储器访问）**：允许不同速度的硬件装置直接通信，无需 CPU 大量介入。
- DMA 控制器直接掌管总线，传输前后涉及**总线控制权转移**：CPU → DMA 控制器（传输前），DMA 控制器 → CPU（传输后）。
- DMA 传输动作本身由 DMA 控制器执行和完成，CPU 只负责初始化该动作。
- 广泛应用于高效能嵌入式系统算法和网络。

## 2. Jackson 设计方法

**题目：** Jackson设计方法是一种面向（ ）的软件设计方法。

> A. 对象　　B. 数据流　　C. 数据结构　　D. 控制结构

**正确答案：C**

**解析：** Jackson **设计**方法是面向**数据结构**的软件设计方法；而 Jackson **分析**方法是面向**数据流**的分析方法，注意区分。

**知识点：**

- 常见面向数据结构的开发方法还包括 Warnier 方法。
- 结构化分析与设计方法是面向数据流的。
- 面向对象方法是面向对象（如 UML）。

## 3. 任务上下文切换

**题目：** 下列关于任务上下文切换的描述中，不正确的是（ ）。

> A. 任务上下文是任务控制块(TCB)的组成部分  
> B. 上下文切换由一个特殊的任务完成  
> C. 上下文切换时间是影响RTOS性能的重要指标  
> D. 上下文切换由RTOS内部完成

**正确答案：B**

**解析：** 上下文切换**并不是由一个特殊任务完成**的，而是在 RTOS 内核内部完成的机制。

**知识点：**

- **上下文切换**：处理器控制权从当前运行任务转移到另一个就绪任务时所执行的操作。
- 任务的上下文（寄存器、状态信息等）记录在 **TCB（任务控制块）** 中，是 TCB 的组成部分。
- 切换过程：保存当前任务状态 → 选择新任务 → 恢复新任务状态。
- 保护和恢复上下文的操作依赖于具体处理器。
- 上下文切换时间直接影响 RTOS 的**实时性能**。

## 4. 数字签名

**题目：** 下面不属于数字签名作用的是（ ）。

> A. 接收者可验证消息来源的真实性  
> B. 发送者无法否认发送过该消息  
> C. 接收者无法伪造或篡改消息  
> D. 可验证接受者合法性

**正确答案：D**

**解析：** 数字签名验证的是**发送者**身份和消息完整性，不能验证**接收者**合法性。

**知识点：**

数字签名三大功能：

| 功能 | 说明 |
|------|------|
| **报文鉴别** | 接收者能验证消息确实来自声称的发送者，其他人无法伪造签名 |
| **报文完整性** | 接收者确认数据未经篡改 |
| **不可否认性** | 发送者事后无法抵赖 |

- 实现过程：生成消息摘要 → 使用**发送方私钥**加密摘要 → 接收方用**发送方公钥**验证。

## 5. 防火墙功能

**题目：** 以下关于防火墙功能特性的叙述中，不正确的是（ ）。

> A. 提供漏洞扫描功能  
> B. 隐藏内部IP以及网络结构细节  
> C. 控制进出网络的数据包和数据流向  
> D. 提供流量信息的日志和审计

**正确答案：A**

**解析：** 防火墙**不具备漏洞扫描功能**，漏洞扫描是漏洞扫描器（如漏洞扫描工具/IDS）的功能。

**知识点：**

防火墙核心功能：
- **包过滤**：监测流经数据包并决定放行或阻止。
- **网关能力**：隐藏内部网络结构和 IP，外部用户只能看到防火墙。
- **日志与审计**：对流经的流量进行详细记录和审计。
- 防火墙≠漏洞扫描器，漏洞扫描属于入侵检测系统（IDS）或专用扫描工具的范畴。

## 6. 嵌入式 DSP 处理器

**题目：** 【考生回忆版】以下针对嵌入式DSP处理器的描述，正确的是（ ）。

> A. 直接在片内固化嵌入操作系统的代码模块  
> B. 使用VHDL语言进行内部程序设计  
> C. 单片机是嵌入式DSP处理器  
> D. 一般采用哈佛结构

**正确答案：D**

**解析：** 嵌入式 DSP 处理器普遍采用**哈佛结构**（程序存储器和数据存储器分开），以支持高效的信号处理。

**知识点：**

- **DSP（Digital Signal Processor）**：专门用于信号处理的处理器，系统结构和指令算法特殊设计。
- 主要特点：
  - 采用**哈佛结构**或改进的哈佛结构。
  - 支持**流水线操作**（如 TMS320C6000 高达 8 级流水线）。
  - 集成硬件加速模块（如 MAC 乘法累加器）。
  - 处理速度比通用 CPU 快 10～50 倍。
- 应用领域：数字滤波、FFT、频谱分析等。
- VHDL 是硬件描述语言，用于 FPGA/ASIC 设计，非 DSP 内部程序设计。
- 单片机 ≠ DSP，二者是不同类型的嵌入式处理器。

## 7. 容错技术

**题目：** 关于容错技术，下面叙述中不正确的是（ ）。

> A. 通常硬件实现容错常用的有恢复块技术和N版本技术  
> B. 从余度设计角度出发，系统通常采用相似余度或非相似余度实现系统容错  
> C. 从结构角度出发，容错结构有单通道加备份结构、多通道结构  
> D. 系统容错技术，主要研究系统对故障的检测、定位、重构和恢复

**正确答案：A**

**解析：** **恢复块技术**和**N 版本技术**是**软件**实现容错的常用技术，而非硬件实现容错。

**知识点：**

容错技术框架：

| 维度 | 分类 |
|------|------|
| **实现方式** | 硬件容错（冗余硬件）、软件容错（恢复块、N 版本）、信息容错（纠错码）、时间容错 |
| **余度设计** | 相似余度（同构）、非相似余度（异构） |
| **结构角度** | 单通道+备份、多通道结构（如 TMR 三模冗余） |
| **核心任务** | 故障检测 → 故障定位 → 系统重构 → 系统恢复 |

- **恢复块技术**：主块执行失败时，依次尝试备用块。
- **N 版本技术**：N 个独立开发团队按同一规格分别实现，运行时通过表决机制输出。

## 8. 嵌入式软件测试

**题目：** 关于嵌入式软件测试，下列叙述中错误的是（ ）。

> A. 软件的测试级别一般分为静态测试和动态测试  
> B. 通过测试发现软件错误，为软件产品的质量评价提供依据

**知识点：**

| 分类维度 | 具体内容 |

| **测试目的** | 发现软件错误，为软件质量评价提供依据 |
| **测试依据** | 合同、技术协议、研制任务书、需求规格说明、设计文档等 |

## 11. 拒绝服务攻击

**题目：** 如果使用大量的连接请求攻击计算机，使得所有可用的系统资源都被消耗殆尽，最终计算机无法再处理合法用户的请求，这种手段属于（ ）攻击。

> A. 拒绝服务　　B. 口令入侵　　C. 网络监听　　D. IP欺骗

**正确答案：A**

**解析：** 这是典型的 **DoS（拒绝服务）** 攻击特征——通过大量请求耗尽系统资源。

**知识点：**

| 攻击类型 | 特征 |
|----------|------|

| **口令入侵** | 通过猜测、暴力破解、字典攻击获取口令 |
| **网络监听（Sniffing）** | 被动截获网络通信数据包 |

## 12. 寄存器

**题目：** 寄存器可以用来暂时存储数据，下面描述不正确的是（ ）。

> A. 寄存器由触发器组成  
> B. 移位寄存器可以用来实现左移或者右移功能  
> C. N位寄存器一般由N个触发器组成  
> D. 寄存器是一种组合逻辑器件

**正确答案：D**

**解析：** 寄存器是**时序逻辑电路**（依赖时钟信号），不是组合逻辑电路。

**知识点：**

| 概念 | 说明 |
|------|------|
| **组合逻辑电路** | 输出仅取决于当前输入（如译码器、编码器、多路选择器），无记忆功能 |
| **时序逻辑电路** | 输出取决于当前输入和历史状态（如寄存器、计数器、状态机），有记忆功能 |
| **寄存器组成** | 由触发器构成，N 位寄存器包含 N 个触发器 |
| **移位寄存器** | 在时钟控制下可实现数据左移或右移，常用于串并转换 |

## 13. 指令流水线

**题目：** 将一条指令的执行过程分解为取指、分析和执行三步，按照流水方式执行，若取指时间 t取指＝4Δt、分析时间 t分析＝2Δt、执行时间 t执行＝3Δt，则执行完100条指令，需要的时间为（ ）∆t。

> A. 200　　B. 300　　C. 400　　D. 405

**正确答案：D**

**解析：**

流水线执行时间公式：(t₁ + t₂ + ... + tₖ) + (n - 1) × Δt_max

- 各段执行时间：4Δt、2Δt、3Δt
- 最慢段 Δt_max = 4Δt
- 总时间 = (4 + 2 + 3)Δt + (100 - 1) × 4Δt = 9Δt + 99 × 4Δt = 9Δt + 396Δt = **405Δt**

**知识点：**

- **流水线周期**：取各段执行时间中的最大值。
- **流水线建立时间**：第一条指令完成全部流水段所需时间（各段时间之和）。
- **流水线稳定后**：每个周期完成一条指令。
- 实际流水线还需考虑流水线寄存器的延迟和可能的停顿（气泡）。

## 14. 死锁与资源分配

**题目：** 某系统中仅有5个并发进程竞争某类资源，且都需要该类资源3个，那么该类资源至少有（ ）个，才能保证系统不会发生死锁。

> A. 9　　B. 10　　C. 11　　D. 15

**正确答案：C**

**解析：**

预防死锁的最小资源数公式：≥ m × (k - 1) + 1

- m = 进程数 = 5，k = 每个进程所需资源数 = 3
- 最小资源数 = 5 × (3 - 1) + 1 = 5 × 2 + 1 = **11**

最坏情况：每个进程都持有 2 个资源（共 10 个），还差 1 个。只要再有 1 个资源（总共 11 个），就能保证至少一个进程获得全部 3 个资源并完成，之后释放所有资源供其他进程使用。

**知识点：**

- **死锁必要条件**（Coffman 条件）：互斥、持有并等待、不可剥夺、循环等待。
- **银行家算法**：通过模拟资源分配来判断系统是否处于安全状态。
- 通用公式：m 个进程各需 k 个同类资源，避免死锁至少需要 `m × (k - 1) + 1` 个资源。

## 15. 存储器芯片计算

**题目：** 某计算机主存容量为64KB，其中ROM区为4KB，其余为RAM区，按字节编址。现要用2K×8位的ROM芯片和4K×4位的RAM芯片来设计该存储器，则需要上述规格的ROM芯片数和RAM芯片数分别是（ ）。

> A. 1、15　　B. 2、15　　C. 2、30　　D. 1、30

**正确答案：C**

**解析：**

- **ROM 区**：4KB，芯片规格 2K×8 位 ≈ 2KB/片 → 4KB ÷ 2KB = **2 片**
- **RAM 区**：64KB - 4KB = 60KB，芯片规格 4K×4 位 = 2KB/片 → 60KB ÷ 2KB = **30 片**

**知识点：**

存储器芯片容量计算：

| 芯片规格 | 容量计算 |
|----------|----------|
| 2K × 8 位 | 2K = 2 × 1024 = 2048 地址，每个地址 8 位 = 1 字节，容量 = **2KB** |
| 4K × 4 位 | 4K = 4096 地址，每个地址 4 位 = 半字节，容量 = 4 × 1024 × 4 / 8 = **2KB** |

> 注意：**字节**（Byte） = 8 位（bit），芯片容量 = 地址数 × 数据位宽 / 8。

## 16. C 程序未赋初值变量

**题目：** 若C程序的表达式中引用了未赋初值的变量，则（ ）。

> A. 编译时一定会报告错误信息，该程序不能运行  
> B. 可以通过编译并运行，但运行时一定会报告异常  
> C. 可以通过编译，但链接时一定会报告错误信息而不能运行  
> D. 可以通过编译并运行，但运行结果不一定是期望的结果

**正确答案：D**

**解析：** C 语言编译器**不强制检查变量是否赋初值**，赋初值是良好编程习惯。未赋初值的变量值为**随机数**（不确定值），程序可编译运行但结果不可预期。

**知识点：**

- 局部变量存储在栈上，未初始化时其值为栈内存中的残留值（垃圾值）。
- 全局变量和静态变量默认初始化为 0。
- 编译器可能产生 warning（如 `-Wall` 下提示 `uninitialized`），但不报 error。
- 这是 C/C++ 常见陷阱，建议始终显式初始化变量。

## 17. DSP 流水线

**题目：** 若TMS320C6000的流水线深度达到8级时，则器件可同时运行（ ）条指令。

> A. 8　　B. 9　　C. 7　　D. 2

**正确答案：A**

**解析：** 8 级流水线意味着**可同时运行 8 条指令**（每条指令处于不同的流水级）。

**知识点：**

- **流水线深度** = 可同时处理的指令条数 = 流水级数。
- TMS320C6000 系列基于改进的哈佛结构，支持超长指令字（VLIW）和深度流水线。
- 流水线技术通过**时间并行**提高指令吞吐率，理想情况下每个时钟周期完成一条指令。

## 18. 无条件转移指令与寻址方式

**题目：** 若某条无条件转移汇编指令采用直接寻址，则该指令的功能是将指令中的地址码送入（ ）。

> A. PC（程序计数器）　　B. AR（地址寄存器）　　C. AC（累加器）　　D. ALU（算术逻辑运算单元）

**正确答案：A**

**解析：** 跳转指令（JMP）需要改变程序的执行流程，必须把目标地址送入 **PC（程序计数器）**，CPU 根据 PC 值取下一条指令。

**知识点：**

常见寄存器及其作用：

| 寄存器 | 功能 |
|--------|------|
| **PC（程序计数器）** | 存放下一条指令地址，控制指令执行顺序 |

## 19. DMA 控制器的总线控制

**题目：** 计算机系统总线包括①地址总线、②数据总线和③控制总线。若采用DMA方式传送数据，则DMA控制器应对（ ）进行控制。

> A. ①②　　B. ①②③　　C. ①③　　D. ②③

**正确答案：B**

**解析：** DMA 控制器接管 **全部三种总线**——地址总线、数据总线和控制总线，以实现内存与 I/O 设备间的直接数据传输。

**知识点：**

系统总线三部分：

| 总线类型 | 功能 |
|----------|------|
| **地址总线** | 传输内存或 I/O 端口的地址信号（单向，CPU/DMA → 存储器） |
| **数据总线** | 传输实际数据（双向） |
| **控制总线** | 传输控制信号（读/写、中断请求、总线请求等） |

DMA 工作流程：DMA 控制器从 CPU 取得总线控制权 → 直接控制三类总线 → 数据在源地址和目的地址间直接传送 → 传送结束后交还总线控制权。

## 20. 平均周转时间

**题目：** 设有4个作业同时到达，每个作业的执行时间均为2小时，它们在一台处理器上按单道方式运行，则平均周转时间为（ ）。

> A. 1小时　　B. 2.5小时　　C. 5小时　　D. 8小时

**正确答案：C**

**解析：**

单道批处理，按顺序逐个执行：

| 作业 | 执行时间 | 完成时间 | 周转时间 |
|------|----------|----------|----------|
| J1 | 2h | 2h | 2h |
| J2 | 2h | 4h | 4h |
| J3 | 2h | 6h | 6h |
| J4 | 2h | 8h | 8h |

平均周转时间 = (2 + 4 + 6 + 8) ÷ 4 = **5 小时**

**知识点：**

- **周转时间** = 完成时间 - 到达时间
- **平均周转时间** = 所有作业周转时间之和 ÷ 作业数
- **带权周转时间** = 周转时间 ÷ 实际执行时间
- 不同调度算法（FCFS、SJF、RR 等）会产生不同的平均周转时间。

## 24. 死锁

**题目：** 以下关于死锁的叙述中，不正确的是（ ）。

> A. 死锁涉及的资源必须遵循申请、分配、使用和释放的管理模式  
> B. 发生死锁时，系统中一定至少存在一个资源等待的回路  
> C. 死锁是用户之间循环等待资源而引起的僵局  
> D. 死锁只可能在单个进程中发生，不可能在多个进程中发生

**正确答案：D**

**解析：** 死锁是指**两个或两个以上**的进程因竞争资源或彼此通信而造成的阻塞现象，不可能在单个进程中发生。

**知识点：**

- 死锁发生的 4 个必要条件（Coffman 条件）：
  1. **互斥**：资源只能被一个进程独占
  2. **持有并等待**：进程持有资源同时在等待其他资源
  3. **不可剥夺**：资源不能被强行抢占
  4. **循环等待**：存在进程-资源的循环等待链
- 死锁必然涉及至少两个进程，且存在资源等待回路。

## 36. Burst 传输

**题目：** 一次总线事务中，主设备只需给出一个首地址，从设备就能从首地址开始的若干连续单元格实现读取或者写入，这种总线事务方式是（ ）。

> A. 并行传输　　B. 串行传输　　C. burst传输　　D. 同步传输

**正确答案：C**

**解析：** Burst（突发）传输指一次给出首地址后，连续传输多个数据单元（突发长度 BL 个），整个信道专用于该传输，提高了传输效率。

**知识点：**

- 典型应用：EISA 总线有 33Mbps 的突发模式，一次数据移动只需 1 个时钟周期（通常需要 2 个）。
- 与并行/串行/同步传输是不同的维度分类。

## 41. 内存容量计算

**题目：** 内存按字节编址从A5000H到DCFFFH的区域其存储容量为（ ）。

> A. 123KB　　B. 180KB　　C. 223KB　　D. 224KB

**正确答案：D**

**解析：**

容量 = 终点地址 - 起点地址 + 1

- DCFFFH - A5000H + 1 = 38000H
- 38000H = 3 × 16^4 + 8 × 16^3 = 196608 + 32768 = 229376（十进制）
- 229376 ÷ 1024 = **224KB**

**知识点：**

- 十六进制减法计算步骤：
  - 逐位相减，注意借位
  - DCFFF - A5000 = 38000
- 38000H 转十进制：3 × 16^4 + 8 × 16^3 = 3 × 65536 + 8 × 4096 = 196608 + 32768 = 229376
- 按字节编址，1 地址 = 1 字节，故 229376 = 224 × 1024 = 224KB

```
        ┌──────────┐
  创建→ │  就绪态   │ ←──────────────┐

     获得CPU │  失去CPU             │
            ↓                      │
        ┌──────────┐               │
```

## 50. DMA 传送与存储周期

**题目：** 采用DMA方式传送数据时，每传送一个数据都需要占用一个（ ）。

> A. 指令周期　　B. 总线周期　　C. 存储周期　　D. 机器周期

| **机器周期（总线周期）** | CPU 完成一次基本操作（如取指、读/写内存）所需时间 |
| **存储周期** | 存储器完成一次读/写操作所需时间 |
| **时钟周期** | 时钟脉冲的周期（最基本的时间单位） |

## 51. 闪存（Flash Memory）

**题目：** 以下关于闪存（Flash Memory）的叙述中，错误的是（ ）。

> A. 掉电后信息不会丢失，属于非易失性存储器  
> B. 以块为单位进行删除操作  
> C. 采用随机访问方式，常用来代替主存  
> D. 在嵌入式系统中可以用Flash来代替ROM存储器

**正确答案：C**

**解析：** Flash Memory 不是用来代替主存（RAM）的。主存需要快速的随机读写和频繁改写，而 Flash 写入速度慢、有擦写寿命限制（以块为单位擦除），适合作为辅助存储/程序存储器而非主存。

**知识点：**

Flash Memory 特点：
- **非易失性**：掉电后数据不丢失
- **物理结构**：分成若干个独立区块（Block）
- **擦除方式**：以块为单位擦除，不能按字节单独擦除
- **写入特性**：写入前需先擦除，有擦写次数寿命限制（通常10万次以上）
- **应用场景**：嵌入式系统中替代 ROM 存储固件程序、U 盘、SSD

## 52. 磁盘转速

**题目：** 若磁盘的转速提高一倍，则( )。

> A. 平均存取时间减半　　B. 平均寻道时间加倍　　C. 旋转等待时间减半　　D. 数据传输速率加倍

**正确答案：C**

**解析：** 磁盘转速提高一倍 → 转一圈时间减半 → 平均**旋转等待时间**减半。但转速不影响寻道时间，也不会等比例地减少存取时间或加倍传输速率。

**知识点：**

磁盘存取时间组成：**T_access = T_seek + T_latency + T_transfer**

| 组成部分 | 含义 | 是否受转速影响 |
|----------|------|:---:|
| **寻道时间（Seek）** | 磁头移动到目标柱面的时间 | 否 |
| **旋转等待时间（Latency）** | 等待目标扇区旋转到磁头下的时间，平均值 = 转一圈时间 / 2 | **是**（转速↗ → 等待时间↘） |
| **传输时间（Transfer）** | 实际读写数据的时间 | 部分影响 |

## 63. RS-232 波特率与字符速率

**题目：** 某系统用RS-232总线传送ASCII码，数据位8位，奇校验1位，停止位1位。当RS-232的波特率设置为9600时，字符传送的速率是( )字符/秒。

> A. 9600　　B. 960　　C. 1200　　D. 120

**正确答案：B**

**解析：** 每字符传输总位数 = 起始位(1) + 数据位(8) + 校验位(1) + 停止位(1) = **10 位**（注意题目隐含了起始位）。字符速率 = 9600 ÷ 10 = **960 字符/秒**。

**知识点：**

- **字符传送速率** = 波特率 ÷ 每字符总位数
- RS-232 常用配置：9600 bps, 8N1（8数据 + 无校验 + 1停止 = 10位）
- 其中有效数据位占比 = 8/10 = 80%

| **SMTP** | 发送/中转邮件 | 客户端 → 服务器 / 服务器 → 服务器 |
| **POP3** | 下载邮件到本地（通常下载后删除服务器副本） | 服务器 → 客户端 |
| **IMAP4** | 在线管理邮件（邮件保留在服务器上） | 服务器 ↔ 客户端 |
| **MIME** | 扩展邮件格式，支持非文本附件（图片、音频等） | — |
